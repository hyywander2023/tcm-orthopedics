# 免疫组织化学技术

骨组织做免疫组化，难点不在染色本身——那套流程和软组织一样——而在**前面那两道工序都在毁抗原**：固定用甲醛（交联抗原决定簇），脱钙用酸（水解蛋白）。所以骨 IHC 的核心问题不是"怎么染"，是"怎么在把骨头变软的同时保住抗原"。

## 一、先选抗体：多克隆还是单克隆

| | 多克隆 | 单克隆 |
| --- | --- | --- |
| 来源 | 不同细胞克隆，针对多个决定簇 | 单一浆细胞克隆，针对单一决定簇 |
| 常用动物 | 兔（其次山羊、猪、绵羊、马、豚鼠） | 小鼠 |
| 优势 | 亲和力有连续谱，**过度冲洗不易丢染色**；交叉反应可用吸附去除 | 同源性高、无非特异抗体、**批间无变异**、易于描述 |
| 劣势 | 批间差异 | **亲和力单一，低了就掉**；对环境（pH、溶质）要求更严；交叉反应不能靠吸附去除 |

（技术 p.154）

一条对骨切片特别重要的推论：

> 由于抗原-抗体的反应是可逆的……多克隆抗体含有或多或少针对一个抗原几个决定簇从低到高的亲和力连续范围，因此，多克隆抗体在第一抗体孵育后，过度冲洗不会导致任何染色的缺失。另外，单克隆抗体具有一致性的亲和力，并且一旦亲和力较低，会因为抗体与其抗原的分离而导致染色缺失，因此，必须选择高亲和力的单克隆抗体。（技术 p.154）

骨切片往往要加长冲洗（背景高），这时**多克隆更耐操**；但如果要做定量比较（比如比较各组 PEBP1 表达强度），单克隆的批间一致性更重要。二者取舍取决于你是"要看见"还是"要比较"。

## 二、固定剂：骨上最容易踩的坑

固定与抗原是一对天然矛盾：

> 为了起到组织保护的作用，有一些在生活细胞或组织中没有的矫作物会在固定后出现。准确地说，固定过程实际上改变了组织原有的化学成分。（技术 p.158）

不同抗原有各自合适的固定液（技术 p.158）：

| 固定液 | 适用 |
| --- | --- |
| 甲醛 | 胞质抗原、膜结合型免疫球蛋白 |
| 甲醛-丙酮混合液 | 淋巴细胞性标记物 |
| 无水乙醇-丙酮（1～3 分钟） | 白细胞表面抗原 |
| 95% 乙醇或含乙醇的聚乙二醇 | 细胞涂片 |
| 乙醇或丙酮（**冷丙酮最佳**） | 冷冻切片 |

书里对骨 IHC 的推荐很明确：

> FineFIX 固定剂是目前免疫组织化学染色最好的固定剂，详述见附录四。（技术 p.158）

注意这与第 4 章"骨组织最好固定剂是甲醛"（技术 p.55）不矛盾——**看目的**：做 HE 用甲醛，做 IHC 首选 FineFIX。同一块标本如果要兼顾，常规做法是一分为二，或者用中性甲醛 + 充分抗原修复。

还用一句话解释了甲醛为什么伤抗原：

> 甲醛因与连接决定簇的氨基酸反应而改变了构象，构象的改变会破坏决定簇或使其与抗体的反应性减低，从而严重影响免疫组化的染色效果。（技术 p.158）

## 三、抗原修复：把交联"拆回去"

原理（技术 p.158–159）：甲醛固定造成蛋白分子间交联，把抗原决定簇埋起来；加热可以使**部分交联逆转**，恢复免疫化学完整性。但——

> 无论机制如何，由甲醛固定所造成的一些分子交联肯定还会有残留，而抗原修复时的加热也肯定会使蛋白质变性，这看起来似乎是矛盾的现象……有一些分子交联是可逆的，因此，可以恢复蛋白免疫化学的完整性，但另外一些则是不可逆的和无法修复的。（技术 p.159）

**"不是所有抗原都能修回来"** ——这句话决定了抗体筛选必须实测，不能照抄文献。

关键参数（技术 p.159）：

| 参数 | 要求 |
| --- | --- |
| 加热温度 | 接近 100℃（沸水温度） |
| 加热时间 | 一般 20 分钟；按固定时间长短调整 |
| 冷却 | 加热后缓慢冷却 **20～30 分钟** |

### 高压修复（最常用）

操作要点（技术 p.159）：

1. 切片常规至水，蒸馏水洗 2 min × 3
2. 修复液 1500～3000 ml 注入不锈钢压力锅，加热至沸腾
3. 切片上架放入，**组织须在液面以下**，盖锅
4. 开始慢慢喷气时（约加热 5～6 min 后）**计时 2.5～3 分钟**
5. 整锅放入水池冲至室温，再取阀开盖
6. PBS 洗 2 min × 3

隔水式修复要延长到 10 min 以上。

### 微波修复

1. 切片常规至水，蒸馏水洗 2 min × 3
2. 切片放入盛修复液的容器，微波加热使液温保持 **98℃ 左右，持续 1 分钟**
3. **取出容器室温冷却 20～30 min**
4. PBS 洗 2 min × 3

有一条极容易被省的细节：

> 注意：不可将切片从缓冲液中取出冷却，以使蛋白能够恢复原有的空间构型。（技术 p.160）

从液里捞出来晾凉，蛋白在空气中冷却速度过快，空间构型来不及恢复，阳性率会掉——这种"看不见的失败"最难查。

### 关于机制，学界还在吵

书里诚实列了三种对立观点（技术 p.160）：

1. 100℃ 以上会让蛋白变性凝固、抗原活性丧失，"根本无法检测"
2. 高温修复能拆开交联，提高阳性检出率（依据：加温至 120℃ 或强碱处理可使交联恢复）
3. 甲醛改变蛋白质三级结构，使决定簇位点转向；高温使位点恢复方向

不必选边。实操意义只有一条：**修复条件要自己优化，文献参数只是起点**。

## 四、染色方法的演进

从 1969 年的酶标抗体技术到今天，主线只有一个词——**放大**（技术 p.160–161）：

| 方法 | 原理 | 灵敏度定位 |
| --- | --- | --- |
| 直接法 | 酶标一抗直接结合抗原 | 最低，快，非特异少 |
| 二步间接法 | 一抗 + 酶标二抗 | 比直接法高（多个二抗可结合一个一抗） |
| 三步间接法 | 再加一个酶标三抗 | 更高，适合抗原量少的标本 |
| PAP / APAAP | 可溶性酶-抗-酶复合物 | 比前三者更敏感，无需化学耦联 |
| ABC | 卵白素-生物素-酶复合物 | 高于 PAP/APAAP |
| LSAB | 酶标链菌素卵白素 | 与 ABC 相当，步骤更少 |
| **CSA** | ABC + 酪胺放大 | 一抗稀释度可提高 **20～200 倍**，能检出"以前认为在 FFPE 中不反应"的抗原 |
| **EPOS / EnVision** | 酶标葡聚糖聚合物直接连抗体 | 步骤最少（EPOS 最短 10 分钟），**无内源性生物素干扰** |

骨组织最该选后两类。原因很直接：骨标本抗原本来就少（细胞密度低、脱钙损失），用直接法或二步法多半染不出来；而 EnVision 避免了卵白素-生物素系统，正好绕开骨与骨髓中内源性生物素的干扰（技术 p.161：「由于这些方法都避免使用（链菌素）卵白素和生物素，因此，可以消除由内源性生物素所导致的非特异性染色」）。

## 五、骨组织的四条特殊要求

散在故障表里，但都是骨特有的（技术 p.167、p.169）：

1. **脱钙不能过度**——"骨组织脱钙过度"直接列为"染色不足（无着色/弱着色）"的原因，对策是"严格执行骨的脱钙程序，避免脱钙过度"
2. **脱钙后必须充分水洗**——"骨脱钙后流水冲洗不够，含酸量过大"，对策"完全去除组织中的酸类成分"
3. **石蜡熔点要低、包埋温度要控**——"使用熔点低于 58℃ 的石蜡，包埋过程不超过 60℃"；"脱蜡过程温度过高使免疫反应性减弱"，"使用温度不应超过 60℃"
4. **切片要薄**——"组织切片尽量切薄，4～6 μm"

这四条正好是本库前几篇的落点：[[脱钙终点的判断]]（不过度）、[[脱钙后的中和与水洗]]（去酸）、[[骨组织的脱水与透明]]（低温短时）、[[骨组织切片方法]]（薄切）。

## 六、一个反直觉的坑：别用 PBS 稀释抗体

> 尽管磷酸盐缓冲液被广泛用于第一抗体的稀释，但实际上却对大多数单克隆抗体的反应有抑制作用。（技术 p.156）

正规做法用厂家配套稀释液或 TBS。同理，碱性磷酸酶（AP）标记系统不能用含叠氮钠的缓冲液，也不能用普通 PBS（市售 PBS 含添加剂会抑制 AP 活性）（技术 p.167）。

## 七、色原选择

| 色原 | 颜色 | 关键限制 |
| --- | --- | --- |
| **DAB** | 棕 | 不溶于乙醇，可常规脱水封片；加强聚合后可与四氧化锇反应增强电子密度（可用于电镜） |
| **AEC** | 玫瑰红 | **溶于乙醇**，绝不能进乙醇或乙醇性溶液，须用水溶性复染剂与封片剂；对氧化敏感，强光下褪色，避光保存 |

（技术 p.157）

用 AEC 就要牺牲脱水透明这一步，片子的保存期也短。要长期存档，选 DAB。

## 原文摘录

> 「由于甲醛固定导致许多抗原的免疫活性丢失，而使免疫组化染色失败，为了更好的恢复组织细胞的免疫活性，就需采用一些特殊的方法，我们将这种修复免疫活性的方法称为抗原修复。」（技术 p.158）

> 「加热显然对由甲醛固定和石蜡包埋所导致的破坏有非常重要的修复作用……有一些分子交联是可逆的，因此，可以恢复蛋白免疫化学的完整性，但另外一些则是不可逆的和无法修复的。」（技术 p.159）
