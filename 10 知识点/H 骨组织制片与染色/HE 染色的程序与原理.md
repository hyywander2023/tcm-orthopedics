# HE 染色的程序与原理

HE 之所以一百多年没被替代，不是因为它的化学有多精巧，而是因为它把"核"和"质"分成了两种颜色，而这恰好是病理医生判断的第一层信息。理解 HE 的价值在于知道**它每一步在改什么电荷**——想通了电荷，配方和时间就有了调整的依据，而不是照抄别人的表。

## 一、苏木素本身不染色

这是全章最反直觉的一条：

> 我们平时所说的苏木素染色，实际上是不准确的，苏木素本身不是一种碱性染料，与组织的亲和力很弱，而只有将不是染料的苏木素经过氧化变成酸性染料苏木红，苏木红再和媒染剂结合形成一种带正电荷的蓝色色精时，才真正具碱性。（技术 p.70）

三步走：

1. **氧化**：苏木素（C₁₆H₁₄O₆）是无发色团的醌式结构，本身无色。氧化后分子中两个环各失去两个氢，价键重排，形成**醌型苯环（发色基）**，成为苏木红（ Haematin）。氧化后分子既有发色基（醌型苯环）又有助色基（羟基）。
2. **媒染**：苏木红与二价或三价金属盐结合，形成带正电的蓝色色精。
3. **吸附**：带正电的色精与细胞核（带负电）通过极性吸附结合。

氧化的两种方式（技术 p.70）：

| 方式 | 耗时 | 风险 |
| --- | --- | --- |
| 天然氧化 | 长（数周至数月） | 稳定，但等不起 |
| 人工氧化（加氧化剂，如氧化汞、碘酸钠） | 短，配好即可用 | **氧化剂过量会破坏染料分子结构**，染色变差 |

这解释了为什么书里多处配方都强调"加入氧化剂要慢、要控制量"——比如 Harris 液"将火焰熄灭，慢慢加入氧化汞，防止溶液溅出"（技术 p.71）。人工氧化是拿稳定性换时间。

## 二、媒染剂决定染什么

同一支苏木红，换一个媒染剂，染出来的东西就变了（表 5-1，技术 p.70–71）：

| 苏木素液 | 媒染剂 | 主要显色对象 |
| --- | --- | --- |
| Harris 明矾苏木素 | 铝（明矾） | 常规细胞核，**HE 的主力** |
| Ehrlich 明矾苏木素 | 铝（钾矾） | 常规核染色，需长时间自然成熟 |
| Mayer 苏木素 | 铝（钾明矾） | 常规核染色，配方温和 |
| Gill 苏木素 | 铝（硫酸铝） | 常规核，加碘酸钠速成 |
| Carazzi 苏木素 | 铝（钾明矾） | 常规核，1 小时即可用 |
| **Weigert 铁苏木素** | 铁 | 核、**髓鞘**，抗酸性强 |
| **Heidenhain 铁苏木素** | 铁 | 染色质、核仁、**线粒体**，深蓝色 |
| Mallory 磷钨酸苏木素 | 磷钨酸 | **有丝分裂**、纤维胶质、肌胶质、骨骼肌与心肌纹理 |
| Mallory 磷钼酸苏木素 | 磷钼酸 | 纤维素、神经胶质、肌胶质 |
| Verhoeff 苏木素 | 铁 | **弹性纤维** |
| Macconaill / Solcia 铅苏木素 | 铅 | APUD 细胞颗粒 |

**铁苏木素在骨领域特别重要**：Weigert 铁苏木素抗酸性强，染色后不易被后续的酸性染料（如 van Gieson 中的酸性品红）褪掉，所以骨与软骨的特殊染色常以它打底（见 [[骨与软骨的特殊染色]]）。

Harris 液的配方（技术 p.71）：甲液 苏木素 1 g + 无水乙醇 10 ml；乙液 明矾 20 g + 蒸馏水 200 ml；加入 氧化汞 0.5 g + 冰醋酸 10 ml。顺序不能乱：苏木素先溶于乙醇（稍加热）→ 加入已溶的明矾 → 尽快煮沸 → 熄火 → 慢加氧化汞 → 再煮 2 分钟 → 立即冷水冷却 → 冷却后加冰醋酸。

## 三、伊红：一个"酸性染料却呈碱性"的悖论

伊红 Y 是四溴荧光素二钠盐，酸性染料。但：

> 酸性染料伊红 Y 在水中电离时，除带负电荷的有色部分外，还有带正电荷的无色部分，即碱金属钠离子，因此，伊红 Y 虽然是酸性染料，但它的溶液反应中，由于钠离子的存在而都呈碱性。鉴于组织成分的等电点在 3.6～5.2，处于较碱性的环境中则带负电，当然因此不易和带负电的酸性染料伊红进行极性吸着；即使被伊红着色，也仅仅是借助于渗透或弥散作用，因此，着色后的组织容易脱色。（技术 p.73）

推论就是：**伊红液里必须加酸**。

> 如果在伊红 Y 染色液中加入醋酸，使染色造成比胞质等电点略为酸性的环境，抑制了部分氨基酸中羧基官能团，从而使氨基酸中氨基官能团和酸性染料结合。（技术 p.73）

这是"酸化伊红"的化学依据。所以配方里那"冰醋酸 1～2 滴"不是调味，是让胞质从"排斥阴离子染料"翻转成"吸引阴离子染料"。酸化伊红染色快、分化不易脱色、颜色清晰，与蓝色核对比突出（技术 p.74）。

同一逻辑还解释了一条常被忽略的影响因素：**固定液会改变组织的电荷状态**，"不同的固定液对组织成分染色电荷的改善或改变是有重要意义的"（技术 p.73）。所以同一套染色程序，换固定液后色差是正常的，不是染色失败。

## 四、分化与返蓝：也是电荷

- **分化**：苏木素是浓染法，必须先过染再退色。**用酸分化碱性染料**——加酸产生大量 H⁺，组织表面带正电，排斥带正电的苏木素色精，颜色褪下。
- **返蓝**：褪色后放自来水中，水中 OH⁻ 使组织表面重新带负电，恢复与色精的结合，蓝色回来。

操作判据（技术 p.74）：

> 切片在盐酸乙醇中浸渍数秒钟，并不断摇动，颜色由深蓝色褪至深粉红色，充分水洗。

注意是**褪到深粉红**，不是褪到无色。返蓝可用自来水，也可用 **1% 氨水**，且"氨水的浓度要严格掌握，一般不得超过 1%"（技术 p.75）。

## 五、程序的关键参数

原文表 5-2（脱蜡至水）、5-3（染色）、5-4（脱水透明封固）、5-5（全自动染色机程序）在 OCR 中只剩标题，缸序与时间丢失，仅能从正文与零散标签（Hematoxylin / Acid alcohol / Ammonia water / 75%、95%、无水乙醇）推出大框架：**脱蜡至水 → 苏木素 → 水洗 → 盐酸乙醇分化 → 返蓝 → 伊红 → 80% 乙醇 → 95% 乙醇 → 无水乙醇 → 透明 → 封固**。

能确认的具体数值与要求（技术 p.76）：

| 环节 | 要求 |
| --- | --- |
| 脱蜡 | 要彻底；可用 **WaxOut** 替代二甲苯（环保）；室温 <25℃ 时可适当加温 |
| 无水乙醇 | 对 WaxOut 溶解力强，须**保持新鲜、及时更换** |
| 苏木素 | 新液一般 **5 分钟**，按组织不同调整 |
| 苏木素后水洗 | **不宜久留**——染色质变蓝后不易被盐酸乙醇分化 |
| 分化 | 严格控时，组织不同时间不同；分化后立即流水冲洗至核变蓝 |
| 流水冲洗 | 不少于 **5 分钟** |
| 伊红后 | 需经 **80% 乙醇** |
| 核质对比 | 核染得浓，胞质也应浓染；核浅则胞质淡染 |
| 染色后无水乙醇脱水 | **非常重要** |

其中"苏木素染后不宜在水中久留"这条最容易被忽略：很多人习惯染完扔水缸里泡着，结果分化时怎么都褪不掉，误以为苏木素过期。真实原因是组织已经"返蓝"了，再想用酸褪色就要加长分化时间，核的细节反而丢得更多。

## 六、骨组织的特殊问题

第 9 章把骨切片染色最常见的失败现象与病因列成表，其中与 HE 直接相关的是"核浆界限不清"，原因里有一条**脱钙过度、酸液冲洗不净**（技术 p.136）。对策是"严格控制脱钙程序，流水充分洗涤"。

这条把 H 域的几篇串起来了：脱钙过头 → 胶原与核蛋白被水解 → 苏木素着不上或着色发灰 → 分化时一碰就掉 → 核浆界限糊。**HE 染不好，先查脱钙，不要先怀疑染液。** 另一条同源的问题是"脱钙不足"，表现为切片碎裂、有刀痕（技术 p.136）。
