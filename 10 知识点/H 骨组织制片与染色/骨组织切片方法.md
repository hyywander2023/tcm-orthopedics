# 骨组织切片方法

骨切片没有"一种通用方法"，只有**五种方法对应五种标本状态**。选错方法的代价不是慢，是白做——把不脱钙的密质骨塞进石蜡切片机，崩的是刀；把软骨做成骨磨片，磨没的是细胞。

## 一、五种切片

> 骨组织切片可以分为石蜡切片、火棉胶切片、不脱钙塑料包埋切片、冷冻切片及骨磨片五种。其中石蜡、冷冻两种方法主要应用于软骨及脱钙后的骨组织制片，其方法与软组织切片基本相同。（技术 p.66）

| 方法 | 标本状态 | 包埋剂 | 切片机 | 厚度 | 适用 |
| --- | --- | --- | --- | --- | --- |
| **石蜡切片** | 脱钙后（软骨不需脱钙） | 石蜡（60℃ 硬蜡＋蜜蜡 8:1） | 轮转式 | 常规 3～5 μm | 日常病理、科研首选 |
| **冷冻切片** | 新鲜或固定后，不脱钙 | 不包埋（OCT 类） | 冷冻切片机 | 较厚 | **术中快速诊断**、酶组化 |
| **火棉胶切片** | 脱钙后大块 | 火棉胶 | 推拉式（滑动式） | 较厚（10～30 μm） | 大块骨、需要保留完整结构 |
| **不脱钙塑料包埋** | 不脱钙 | 树脂／塑料（MMA 类） | 大型硬组织切片机 | 可薄至数 μm | **骨形态计量**、荧光标记、不能丢钙的课题 |
| **骨磨片** | 不脱钙，手工磨 | 无（粘片后磨） | 磨片机 | 数十至上百 μm | 骨单位、哈佛系统观察 |

关键判断只有一条：**这块骨要不要保留钙**。

- 只要看细胞和基质形态 → 脱钙 + 石蜡，最省事
- 要看钙化前沿、类骨质、荧光标记（如四环素双标）→ 必须不脱钙，走塑料包埋或磨片
- 手术台上要 20 分钟出结果 → 冷冻
- 大块标本（半关节、整段椎体）不能切薄 → 火棉胶

## 二、刀：分界线就是"脱没脱钙"

传统切片刀分 B、C、D 三型（技术 p.61、p.63）：

| 刀型 | 用途 |
| --- | --- |
| **B 型** | **脱钙后**骨组织（石蜡或火棉胶包埋）、软骨冷冻切片 |
| C 型 | 常规，骨上用途有限 |
| **D 型** | **不脱钙**骨组织（钨钢刀）、火棉胶包埋的大块脱钙骨（特制钢刀） |

D 型刀的特点是"只有一面刃"，且可切皮革、橡胶、塑料——本质是一把工业硬料刀（技术 p.61）。这也是为什么 D 型刀的研磨必须外送专业部门：家用磨刀机达不到钨钢的精度（技术 p.39）。

一次性刀片（技术 p.62、p.64）：

| 型号 | 定位 | 适用切片机 |
| --- | --- | --- |
| **N-35** | **骨组织专用型，骨切片最佳选择** | 平推式、轮转式 |
| HP35（珊顿）／818（Leica，宽刀面） | 大剖面蜡块，对硬组织效果较好 | 轮转式（需特殊刀架） |
| A-35（羽毛，加强型） | 韧性钢性较好，**可用于软骨冷冻切片** | 推拉式 |
| R-35（常规）、S-35（软组织） | 常规组织，特殊组织效果差 | 轮转式 |

书里对一次性刀片有一个很实际的成本提醒：骨组织硬，"一个刀片切制的切片数量较一般组织要少几倍，即使使用标明专门切制骨组织的一次性切片刀，也不会有较大的改观"（技术 p.61）。所以骨病理的耗材预算要按软组织的好几倍算。

## 三、切片机

四种，各有对应（技术 p.66）：

| 切片机 | 型号举例 | 用途 |
| --- | --- | --- |
| 轮转式石蜡切片机 | Leica 2135 / 2235 | 脱钙后小块石蜡切片 |
| 推拉式（滑动式） | Sakura VS-410 | 火棉胶包埋 |
| 大型不脱钙切片机 | Leica SM2500E | 塑料包埋 |
| 冷冻切片机 | Leica 1900 / 3000 / 3050s、珊顿 Cryotome SME、Sakura | 软骨冷冻切片、术中诊断 |

注意"不脱钙骨组织直接制片，是骨组织切片技术中最难掌握的技术"（技术 p.66）——难在包埋（塑料渗透慢）和刀（钨钢），不在切片机本身。

## 四、手工磨刀：一段不合时宜的坚持

书里花了整整两页讲手工磨刀，理由不是技术必要，是**传承**：

> 随着磨刀机、一次性刀片的诞生，病理技术界对手工磨刀的重视程度已不复存在……我们认为这是病理界的一大损失……特别是对于我们从事骨组织制片的技术人员，它还是培养技术人员耐心、信心、细心的一种方法。（技术 p.64）

技术要点（技术 p.64–65）：

- **磨石**：天然磨石要先用大理石台面推磨找平；软而涩的做粗磨，硬而细滑的做细磨；平板玻璃（须厚或钢化）配研磨剂可一板三用（粗／中／细）
- **磨剂**：天然磨石用水、肥皂水、液体石蜡、润滑油，后两者最佳；平板玻璃需"研磨剂＋研磨料"，磨料用氧化铝（钢玉）、绿碳化硅、细微分（原文如此，疑为"细金刚砂"），研磨剂以油为佳
- **手法**：右手拇指与示指握刀柄，左手示、中二指抵刀面，拇指按刀背，形成 **"V" 字形**防滑；刀头置于磨石近体侧中间，斜向平推至远端，翻刀，斜向回拉——即"8"字磨刀法
- **鐾刀**：磨快后还要在鐾刀皮上鐾锋利，"已用钝的切片刀是不能直接鐾锋利的"
- **验收标准**（这条最有用）：

> 一把锋利的切片刀要能将石蜡切成 2 μm 的连续不断的蜡带而无压缩……当研磨达到要求时，在实际切割刃上应看不到反射，以手拭之刀锋应有吸附感，而且刃上不应有任何一点偏锋（卷刃）。（技术 p.65）

"2 μm 连续蜡带无压缩"是可以当场验证的硬指标，比"看起来很亮"靠谱得多。

## 五、选型的一张简表

| 你的标本 | 走这条路 |
| --- | --- |
| 常规骨病理、要 HE | 固定 → 脱钙（甲酸或 JYBL）→ 石蜡 → 轮转式 → N-35 |
| 要做免疫组化／原位杂交 | 固定 → **EDTA 脱钙** → 石蜡 → 独立切片机 → N-35 |
| 骨形态计量、荧光双标 | 不脱钙 → 塑料包埋 → SM2500E → 钨钢 D 型刀 |
| 术中快速 | 冷冻 → −30℃ → A-35 或 C-35 |
| 大块骨、半关节 | 脱钙 → 火棉胶 → 推拉式 → B 型／特制钢刀 |
| 只看骨单位、哈佛系统 | 不脱钙 → 骨磨片 |

## 六、缺口

- 各方法的详细操作（火棉胶的梯度、塑料包埋的渗透程序、骨磨片的研磨步骤）不在本章，第 13 章「骨组织病理特殊制片技术」专述，本库另篇整理。
- 石蜡切片的具体厚度、展片水温、烤片时间原文未在本章给数值（表 5-2 处亦丢失）。
- 未涉及当代的振动切片机（vibratome）与激光切割，这两者在不脱钙制片里已较常用。

## 原文摘录

> 「骨组织由于含有钙质，非常坚硬，所以，它是所有组织中最难以制片的组织。」（技术 p.60）

> 「传统切片刀中，骨组织制片时最常用的是 B 型刀和 D 型刀。B 型刀主要用于脱钙后的骨组织制片（石蜡或火棉胶包埋）及软骨的冷冻切片；而 D 型刀主要用于不脱钙的骨组织切片（钨钢刀）或火棉胶包埋的大块骨组织脱钙切片（特制钢刀）。」（技术 p.63）
