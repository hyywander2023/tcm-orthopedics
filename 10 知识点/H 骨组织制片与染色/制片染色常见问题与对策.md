# 制片染色常见问题与对策

骨切片出问题，绝大多数不是"技术不精"，而是**流程里某一步没走对，但错误在几步之后才显形**。切碎了去怪刀，染色差了去怪染液，往往白忙。这一篇按原文整理的故障表来梳理，重点是把"现象"倒推回"工序"。

## 一、原文对这件事的态度

书里开篇不是讲技术，是讲态度：

> 大批新的技术人员在缺乏最基本训练的条件下，却去做一些更难以掌握的染色制片技术……如果连一张普通的 HE 切片都做不好，恐怕其他技术就更难以胜任，这种现象在制作骨组织切片时就更显突出。（技术 p.134）

## 二、制片阶段（表 9-1）

原文表 9-1 的"现象"列在 OCR 中丢失，只剩"原因 → 对策"。以下按可读内容整理，**现象归属无法确定的地方不做推测**。

| 原因 | 对策 | 备注 |
| --- | --- | --- |
| 浸蜡温度过高（**超过 60℃**） | 严格控制浸蜡温度，不超过 60℃ 为佳 | 与"骨用 60℃ 硬蜡"呼应，是上限不是目标 |
| 对组织及蜡的性质不熟悉 | 掌握各种组织特点及其与浸蜡的关系 | — |
| 浸蜡机器温控装置失控 | 定期校验温控 | 隐性问题，最容易被忽略 |
| 切片后未及时烤片和附贴 | 切片后**立即**烤片、附贴 | — |
| 切片在空气中长时间暴露干燥 | 未处理的切片放入**湿润、低温**条件 | — |
| 取材过厚、过大 | **取材厚度不得超过 2.5 mm** | 注意：此处 2.5 mm 比脱钙章的"≤5 mm"更严 |
| 固定不够、脱水透明不够 | 严格按要求进行 | — |
| 蜡温过高或过低 | 恒定蜡温 | — |
| 脱水、透明时间过长致组织变脆 | 掌握好脱水、透明时间 | — |
| 捞片水温太高／过低 | 严格控制捞片水温，有条件用自控 | 水温过低切片展不平 |
| 切片刀有缺口、卷刃、刀锋有异物 | 制片前检查，不合格刀片不得使用 | — |
| 组织内混有毛发、骨质、钙化 | 发现异物要想办法去除 | 骨标本的钙化灶是硬伤 |
| 附贴剂应用不当 | 合理使用附贴剂 | 可用 **30% 乙醇液面张力**作展平剂 |
| 玻片、盖片不净 | 玻片经酸液浸泡 | — |
| 显微镜头污染 | 注意清洁镜头 | 假象而非切片问题 |

## 三、染色阶段（表 9-2）

与 HE 直接相关的是这几组（技术 p.135–136）：

| 问题 | 原因 | 对策 |
| --- | --- | --- |
| **核浆界限不清** | 脱钙过度、酸液冲洗不净 | 严格控制脱钙程序，流水充分洗涤 |
| 细胞核发灰、染色淡 | 脱钙过度、酸液冲洗不净 | 同上 |
| 核染色过深、胞质也着色 | 苏木素染液中钾明矾含量过高；染色时间过长、分化时间短 | 调配明矾与冰醋酸比例，控制染色与分化时间，及时换新液 |
| 核染色不匀／偏蓝紫 | 苏木素配制不当、成熟不够；盐酸分化过度；自来水含次氯酸 | 用标准化成熟苏木素，掌握分化程度 |
| 胞质过红、与核争艳 | 伊红染后未分化 | 伊红后过 80% 乙醇 |
| 切片整体发暗、有雾 | 脱蜡不净；染色后脱水透明不够 | 保证脱蜡时间；最好用免清洗盖片及玻片 |
| 组织碎裂、有刀痕 | 脱钙不足 | 掌握好脱钙程度 |
| 组织弥散、结构松散 | 冲水时间过长 | **冲水时间不得超过 12 小时** |
| 组织坏死、自溶 | 组织未固定、坏死、自溶 | 组织及时固定 |
| 背景着色、有沉淀 | 脱蜡不净；脱钙不足；冲水时间过长 | 注意更换脱蜡剂；掌握脱钙程度；严格控冲水时间 |

这张表最有价值的是三条**时间上限**：

1. **取材厚度 ≤2.5 mm**（比脱钙章的 5 mm 严，实际按这个做）
2. **冲水时间 ≤12 小时**——注意这与第 3 章"流水冲洗过夜"（技术 p.51）表面冲突：过夜通常 8～16 小时，卡在边缘。**冲水过夜可以，但别拖到第二天中午。**
3. **浸蜡温度 ≤60℃**

## 四、冷冻切片（表 9-3）

骨肿瘤标本冷冻切片是另一套故障谱（技术 p.136）：

| 现象 | 原因 | 对策 |
| --- | --- | --- |
| 细胞过度收缩 | 固定液使用不当 | 选用适合冷冻切片的固定液 |
| 冰晶大、组织被挤压 | 冷冻速度过慢（细胞外形成大冰晶） | 采用辅助方法提高冷冻速度（如半导体制冷机） |
| 细胞皱褶变形 | 冷冻温度过低（**低于 −40℃**） | **冷冻温度最好在 −30℃ 左右** |
| 切不下来、组织发软 | 冷冻不足（**−10℃ 以上**）；组织含脂质过多 | 提高冷冻温度／预冷后再冻 |
| 切片碎裂 | 切片刀不快或不冷；组织冷冻硬度不够 | 更换刀片；提高冷冻温度 |
| 切片机工作异常 | 室内温度过高；制冷故障 | 提高散热能力 |

温度窗口很窄：**−10℃ 以上冻不住，−40℃ 以下细胞收缩，−30℃ 是甜点**。另外"组织含脂质过多"在冷冻切片里同时是"冻不住"和"切不好"的原因，骨标本里的脂肪髓要特别注意。

## 五、一条贯穿全篇的判据

把所有条目按"最先该查什么"重排，会得到一条很实用的排查顺序：

1. **先查脱钙**——碎裂、刀痕、核发灰、界限不清，四条现象都指向脱钙不足或过度
2. **再查固定**——自溶、结构松散，多半是固定不及时
3. **再查脱水透明**——组织变脆、发暗，是时间过长或脱蜡不净
4. **最后才查染液与刀**——染液是可换的耗材，刀是新旧问题

书里那句"如果连一张普通的 HE 切片都做不好，其他技术就更难以胜任"，落到实处就是这个顺序：HE 是整条流程的体检，它不好，先怀疑前处理，别怀疑染料。
