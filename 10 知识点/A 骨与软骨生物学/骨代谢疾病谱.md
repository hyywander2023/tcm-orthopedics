# 骨代谢疾病谱

命名分三层，混用会直接写错诊断：**低骨量**（影像描述，无病因信息）→ **骨质疏松**（单位体积内矿化骨基质减少）→ **骨软化**（基质矿化障碍）。三者的区别不在"骨多不多"，而在"矿化全不全"。

## 一、三个术语的严格定义

> 低骨量是一个常用来描述 X 线片上骨密度减小的词汇。低骨量既不是什么疾病也不是什么症状，它并不带有任何病源学的信息。而骨质疏松是一专有名词，指每单位体积（密度）的正常骨基质矿化的减少状况……骨软化是指骨基质矿化障碍，可能导至骨量增加、不变或减少。（基础 p.330–331）

关键在最后一句：**骨软化可以不伴骨量减少，甚至骨量增加**（矿化的类骨质堆着但没钙化）。所以"X 线上骨密度不低"不能排除骨软化。

## 二、佝偻病与骨软化：同一机制，年龄不同

> 骨基质（类骨质）矿化不足或矿化障碍是骨软化症状的一个诊断特征。佝偻病与骨软化症相反，指青少年因软骨基质（类软骨质）矿化障碍导致原发性海绵状基质形成障碍。骨软化症可在任何年龄出现，而佝偻病则只见于儿童少年。（基础 p.331）

差别在**受累的是骨基质还是软骨基质**：儿童骨骺未闭，软骨基质矿化障碍表现为骺板增宽、生长受阻（佝偻病）；成人骺板已闭，只有骨基质矿化障碍（骨软化）。

直接病因只有一个：

> 造成骨软化的最主要因素是血磷酸钙的含量较低，不足以满足新形成的类骨质矿化。（基础 p.331）

注意是"血磷酸钙"——**钙磷乘积不足**，不是单看血钙。这解释了一个临床困惑：血钙正常的骨软化病人并不少见，因为低磷同样能让乘积不够。

## 三、五类病因

基础书的概览表 2（p.332）把佝偻病／骨软化成因归为五类：

| 类别 | 举例 |
| --- | --- |
| 膳食性 | 钙摄入不足、草酸盐（菠菜）、高剂量磷酸盐 |
| 吸收不良 | 胃次全切除、胆病（影响脂溶性维生素 D 吸收）、急性腹泻综合征、谷胶过敏性肠病、克罗恩病 |
| 肾小管病 | 肾磷漏、X 连锁低磷酸盐血症、范康尼综合征Ⅰ／Ⅱ／Ⅲ型、抗维生素 D 性佝偻病 |
| 维生素 D 代谢病 | 维生素 D 依赖性佝偻病Ⅰ型（1α 羟化缺陷）、Ⅱ型（受体缺陷） |
| 后天性／其他 | 肾性骨营养不良、肿瘤分泌因子（肿瘤性骨软化）、纤维性发育不良、抗惊厥药、铝制剂 |

两处值得单独记：

- **抗惊厥药**（苯妥英、苯巴比妥、扑米酮）通过诱导肝 P450 微粒体酶加速维生素 D 代谢物分解
- **铝**：过去用含铝的磷结合剂治疗尿毒症高磷，铝沉积于骨则引起骨软化，沉积于脑则可能致痴呆（基础 p.331）

## 四、肾性骨营养不良：一条完整的病理链

> 肾性骨营养不良症是一种常见的慢性肾病，也是导致骨软化的最常见的原因……主要的变异为 1,25-二羟维生素 D 合成不足和尿毒症引起的磷酸盐潴留。这两种症状会导致低钙血症，继而引起继发性甲状旁腺功能亢进，出现纤维骨炎。（基础 p.331）

链条写成一行：

**肾衰 → ①1α 羟化受阻（活性 D 不足）＋②磷潴留 → 低钙 → 继发甲旁亢 → 纤维骨炎（＋骨软化＋骨硬化＋转移性钙化）**

它同时可以出现**相反方向**的骨改变：佝偻病、骨软化、纤维骨炎、骨质疏松、骨硬化、转移性钙化（基础 p.331）。这就是"肾性骨营养不良"不叫"肾性骨质疏松"的原因——它不是单一病变。

两个量化点：

- 肾小球滤过率降至 20 ml/min 时，持续性酸中毒进一步增加钙丢失（基础 p.331）
- 血钙与血磷的溶解度积过大时，会发生结膜、血管、关节周围组织和皮肤的钙化（基础 p.331）

## 六、缺口

- 本书完全没有 FGF23、硬化素抗体、地舒单抗等内容，全部是 2001 年前的诊疗框架。作为疾病谱的"分类骨架"可用，作为治疗方案不可用。
- 中国人群的维生素 D 缺乏流行病学数据缺失。
