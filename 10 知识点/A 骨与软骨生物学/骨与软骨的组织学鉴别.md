# 骨与软骨的组织学鉴别

切片上真正需要分辨的其实不是"骨 vs 软骨"，而是**三种软骨之间**以及**纤维软骨 vs 骨**这两组——前者决定病理诊断的方向（退变、炎症、肿瘤），后者决定"这是不是已经骨化"。

## 一、三种软骨

| | 透明软骨 | 弹性软骨 | 纤维软骨 |
| --- | --- | --- | --- |
| 外观 | 乳白浅蓝、半透明 | 黄色、不透明 | 乳白、不透明 |
| 力学 | 抗压性强，有一定弹性韧性 | 可屈性强、弹性明显 | 有一定伸展性 |
| 纤维成分 | 交织排列胶原原纤维（Ⅱ型） | 分支弹性纤维，互连成网 | 大量平行交叉排列的胶原纤维束 |
| 细胞 | 圆形，散在 | 圆形，散在，形似透明软骨 | 较小而少，卵圆，**成行**分布于纤维束间 |
| 基质 | 大量水分；纤维细且折光率与基质相同，**HE 不能分辨** | 中心弹性纤维密集，近软骨膜处疏松 | 基质少，**弱嗜碱性** |
| 分布 | 喉、气管、支气管、肋软骨、关节软骨 | 耳廓、外耳道、咽鼓管、喉、会厌 | 椎间盘纤维环、关节盘、半月板、股骨头韧带、耻骨联合、肌腱韧带附着处 |

（技术 p.22）

四个可操作的鉴别点，按可靠性排序：

1. **细胞排列**：纤维软骨的细胞成行夹在纤维束之间，这是最不会看错的一条
2. **基质染色**：纤维软骨基质少且弱嗜碱性；透明软骨基质强嗜碱性（因蛋白多糖多）
3. **纤维可见性**：透明软骨的胶原在 HE 上"看不见"（折光率与基质相同），纤维软骨的胶原束粗大明显
4. **特殊染色**：弹性软骨用弹性纤维染色可确诊；透明软骨用番红 O 或阿利新蓝显示蛋白多糖（基础 p.404 提到番红 O 染关节软骨）

## 二、软骨 vs 骨

| 特征 | 软骨 | 骨 |
| --- | --- | --- |
| 基质矿化 | 无（除钙化软骨层） | 有骨盐沉积 |
| 陷窝 | 有（软骨陷窝），无骨小管 | 有（骨陷窝）＋**骨小管** |
| 骨板 | 无 | 有（板层骨） |
| 细胞间连接 | 无突起相连 | 骨细胞突起经骨小管以缝隙连接相通 |
| HE 染色 | 透明软骨嗜碱（基质）、纤维软骨弱嗜碱 | 嗜酸性（胶原占多数） |
| 血管 | 无 | 丰富 |

（技术 p.22、p.25–26）

其中最硬的一条判据是**骨小管**：只要看到陷窝之间有细管相通，就是骨。软骨细胞虽也有突起，但技术书未描述软骨陷窝之间的管状连通结构。

## 三、非板层骨与板层骨

还有一层鉴别常被忽略：同是骨，成熟度不同。

| | 非板层骨（原始骨） | 板层骨（次级骨） |
| --- | --- | --- |
| 别名 | 编织骨、粗纤维骨 | 细纤维骨 |
| 胶原排列 | 编织样，粗细差异大（最粗 13μm） | 成层，相邻骨板纤维互成直角 |
| 骨细胞 | 分布无规律、体积大、数量多 | 较小，长轴与胶原长轴平行 |
| 蛋白多糖 | 较多 | 较少 |
| 出现 | 胚胎、儿童；**骨折修复期** | 青春期后全部骨组织 |
| 染色 | 嗜碱性 | 嗜酸性 |

（技术 p.25–26）

骨折修复区看到嗜碱性的编织骨是**正常过程**，不是肿瘤——这是病理读片最常被问的问题之一。编织骨要到青春期才完全被板层骨取代（技术 p.25）。

## 四、一个易混点：钙化软骨 vs 骨

生长板的钙化区、关节软骨的钙化层、以及"过渡性骨小梁"，三者都同时含钙化软骨与骨：

- **钙化软骨**：细胞退化死亡、基质钙化，但仍是软骨基质，无骨板、无骨小管
- **过渡性骨小梁**：以钙化软骨基质为中轴，表面附以骨组织（技术 p.28）——**同一结构上两种组织并存**

看到"软骨核心外面包着骨"就是过渡性骨小梁，这是骨化正在进行的标志。

## 五、缺口

- 三种软骨的Ⅱ型胶原免疫组化鉴别（Ⅱ型 vs Ⅰ型）本书未涉及；技术上见库内 H 域的免疫组化笔记（待写）。
- 软骨陷窝之间是否存在类似骨小管的连通，技术书未明确否定，属可查证点。

## 原文摘录

> 「纤维软骨主要分布于椎间盘的纤维环、关节盘、半月板、股骨头韧带、耻骨联合以及某些肌腱、韧带附着于骨的部位。纤维软骨的软骨细胞较小而少，成行分布于纤维束之间，基质较少，为弱嗜碱性。」（技术 p.22）
