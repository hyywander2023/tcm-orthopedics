# 软骨内成骨与膜内成骨

两种成骨方式的差别不在"有没有软骨"，而在**骨化前是否先有一个软骨模板**。膜内成骨直接在原始结缔组织里成骨（颅面扁骨、锁骨）；软骨内成骨先造一个软骨雏形再逐步替换（四肢骨、骨盆、脊柱）。两者共用同一套细胞逻辑：类骨质 → 钙化 → 破骨吸收重塑。

## 一、两种方式的分配

| 方式 | 部位 | 起点 |
| --- | --- | --- |
| 膜内成骨 | 额骨、顶骨、枕骨、颞骨、锁骨等扁骨（胚胎期） | 原始结缔组织膜直接成骨 |
| 软骨内成骨 | 四肢骨、盆骨、脊椎骨、部分颅骨 | 先形成软骨雏形 |

（技术 p.27）

## 二、膜内成骨：六步

1. 间充质分化为原始结缔组织膜
2. 间充质细胞 → 骨原细胞 → 成骨细胞
3. 成骨细胞生成骨组织，最先成骨的部位称**骨化中心**
4. 骨小梁形成；成骨细胞在骨小梁表面不断分泌新类骨质，小梁增长加粗
5. 成骨细胞由骨原细胞不断补充，范围扩大成松质骨
6. 松质骨外侧区域改建为密质骨，周围结缔组织转变为骨膜

（技术 p.27）

值得留意第 6 步：**密质骨是松质骨"改建"来的**，不是一开始就存在的。这解释了一个常见的影像现象——婴幼儿颅骨的板障结构尚不清晰，随年龄增长才分层。

## 三、软骨内成骨：五步 + 六站

技术书把基本方式概括为五步（p.27），这五步在每个骨化中心都会重复一遍：

> ①软骨细胞增生并分泌骨细胞间质。②软骨细胞成熟并分泌碱性磷酸酶，软骨基质钙化。③钙化的软骨基质阻断了弥散性营养供应，致使软骨细胞退化死亡，钙化的基质崩溃溶解。④血管和大量生骨细胞侵入，围绕着钙化的软骨残片。⑤生骨细胞不断分化形成成骨细胞，并贴附于钙化的软骨残片，形成骨组织。

第 ③ 步是理解整个过程的钥匙：**软骨细胞是被自己钙化的基质"饿死"的**。基质钙化后弥散受阻，营养进不去，细胞死亡、基质崩解，才腾出空间让血管和骨组织进入。所以钙化不是结果，而是清除软骨的手段。

六个里程碑（技术 p.27–28）：

| 阶段 | 内容 |
| --- | --- |
| 软骨雏形 | 间充质聚集分化，形成与未来骨外形相似的透明软骨，周围变成软骨膜 |
| 骨领 | 雏形中段软骨膜内骨原细胞分化为成骨细胞，形成领圈状薄层原始骨组织；骨领表面的软骨膜改称骨膜 |
| 初级骨化中心 | 中央软骨细胞停止分裂、体积变大、分泌碱性磷酸酶，基质钙化、细胞死亡；骨膜血管穿骨领进入；破骨细胞消化退化软骨形成隧道；成骨细胞贴残存软骨基质成骨 → **过渡性骨小梁** |
| 骨髓腔 | 过渡性小梁之间为初级骨髓腔；造血干细胞进入成为骨髓；小梁被破骨细胞吸收，形成贯通的大腔 |
| 次级骨化中心 | 出现于雏形两端软骨中心；**供血动脉来自软骨之外**，骨化由周围向中心扩展 |
| 骨骺与骺板 | 骨骺在次级骨化中心处形成；骨骺与骨干之间保留骺板，骺板只参与骨干加长，不参与骨骺形成 |

两处细节值得记住：

- **骨领→骨膜**的改名，说明骨膜在发生上就是"骨领外表面剩下的那层软骨膜"。这是骨膜成骨能力的胚胎学来源。
- **次级骨化中心的血供来自软骨外**（后动脉），而初级骨化中心的血供是穿骨领进入的。这决定了骨骺缺血与骨干缺血的病理表现不同：骨骺以"全或无"的梗死为主，骨干则先出现骨内膜坏死。

## 四、共同点：形成与吸收同时存在

> 事实上骨组织的形成和吸收同时存在，处于动态平衡。成骨细胞与破骨细胞通过相互调控，共同完成骨组织的形成和吸收。（技术 p.27）

这句话在两种成骨方式里都成立。所以"成骨"这个词本身容易误导——**没有一处骨组织是只靠成骨细胞造出来的，每一处都在同时被吸收塑形**。

## 五、缺口

- 两种方式在分子层面的差异（如 Runx2、Sox9 的作用时序），本书未涉及。
- 膜内成骨向密质骨改建的具体时程（什么年龄段完成分层），书中只说"以后"。

## 原文摘录

> 「虽然发生方式不同，但骨组织发生的过程基本相似，都包括了骨组织形成与骨组织吸收两个方面。」（技术 p.27）
