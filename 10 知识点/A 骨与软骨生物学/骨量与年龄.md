# 骨量与年龄

骨量的一生是一条"慢升—平台—快降"的曲线，但两个拐点的性质完全不同：**峰值是"矿化追上生长"的结果，下降是"吸收超过形成"的结果**。前者是几何与矿化的时序问题，后者是细胞耦联失衡问题。

## 一、曲线

| 阶段 | 变化 |
| --- | --- |
| 青春期早期 | 纵向生长快，骨矿物含量增长相对滞后 |
| 青春期中后段 | 纵向生长减缓，骨矿物质含量快速增多 |
| 30 多岁 | 骨质量达峰值 |
| 40 岁后 | 形成率不变，吸收率上升 |
| 50 岁起 | 骨量开始下降 |
| 数十年后 | 松质骨可减至峰值 50%，骨质量减至峰值 25% |

（基础 p.329–330）

这里有一个容易读错的点：基础书原文写"骨质量则会减至其峰值的 25%"，句中"骨质量"与前面"骨矿物质含量"混用，**很可能指骨量（bone mass）而非骨质量（bone quality）**。按上下文（与松质骨含量 50% 并列）应理解为骨量。引用时最好写"骨量降至峰值约 25%"，并注明原文用词。

## 二、为什么青春期会"先长个、后长矿"

> 在青春发育早期，骨骼经历了快速的纵向生长，而骨矿物含量只……25(OH)D 转化为 1,25(OH)₂D 有中度的增加。骨内孔性间隙的增加与骨内外膜层的骨板层增加处于平衡。骨代谢转换率的增高为骨的新生提供了所需的矿物质。到青春发育后期，骨的纵向生长减缓，但骨的矿物质含量才会快速增多。（基础 p.329）

机制是**几何与矿化的速率不同步**：长度增加靠骺板软骨替换，速度快；矿化靠晶体在水化基质中沉积，速度慢。所以青春期早期骨"长大但没长实"，骨折率在这个阶段偏高并非偶然。

## 三、性别差异

> 到 50 岁时，骨量开始下降，在骨丢失方面因性别的不同而存在差异。男女的密质骨丢失率相同，然而女性在更年期后松质骨含量丢失加快。局部骨丢失率在整个骨骼中并不相同。（基础 p.330）

要点拆开：

- **密质骨**：男女丢失率相同 → 男性也会丢，只是没有"加速期"
- **松质骨**：女性绝经后加速 → 椎体压缩骨折的女性优势由此而来
- **局部差异**：全身骨丢失率并不一致 → 不能用一个部位的骨密度代表全身

## 四、遗传与代偿

> 遗传因素很大程度上决定了骨矿物质含量和骨骼大小。（基础 p.330）

另一处代偿现象更值得注意：

> 流行病学研究提示骨密度随年龄增长而降低并不伴随出现老年人骨干骨折的明显增加，这可能与上述代偿机制有关。然而，这种自身平衡和代偿机制并不能足以保护发生在其他部位的老年性骨折，如髋部、脊柱和桡骨远端的骨折。（基础 p.310）

代偿的机制是**长骨横断面几何形状随年龄增大**（骨外膜下成骨使外径增加），从而在骨密度下降时维持截面惯性矩。这解释了为什么"骨密度低"与"骨干骨折多"不平行——**皮质骨靠几何代偿，松质骨没有这个退路**。

## 五、四种调节机制

基础书的概览表 1 把骨量调节归成四类（p.330），这个框架比"成骨/破骨"二分更好用：

| 方向 | 手段 |
| --- | --- |
| 刺激成骨细胞 | 间歇性 PTH／PTHrP 疗法；负重运动 |
| 抑制成骨细胞 | 缺少负重运动；肾上腺皮质功能亢进 |
| 抑制破骨细胞 | 适宜的维生素 D 摄取；适宜的钙摄取 |
| 刺激破骨细胞 | 缺乏负重活动；甲状旁腺功能亢进；肾上腺皮质功能亢进；甲状腺功能亢进 |

注意"肾上腺皮质功能亢进"同时出现在"抑制成骨"和"刺激破骨"两栏——糖皮质激素是双向的，这正是激素性骨质疏松进展快的原因。

## 六、钙吸收的年龄衰减

> 在年轻人中，15%～25% 的营养钙可被消化吸收。而这一比例随年龄增大而不断降低。由于年老后肾脏内 25-羟维生素 D 转化成活性 1,25-二羟维生素 D 的效率降低，从而老年人有必要增加饮食钙而保持有足够数量的钙通过肠道进入血液。（基础 p.329）

所以老年人的钙问题**不在摄入量，而在转化效率**。单补钙而不改善 1α 羟化，效果有限——这与 [[钙磷代谢与PTH]] 里的维生素 D 代谢链是同一件事。

## 七、缺口

- 峰值骨量的具体年龄（"30 多岁"）书中未给精确值，不同文献有 25～35 岁之别。
- 中国人群的骨量曲线数据本书没有，全部引用的是西方文献。

## 原文摘录

> 「骨代谢动力学研究方面的证据表明，40 岁后，骨的形成率保持不变而吸收率上升。」（基础 p.330）
