# 肌肉的力—长度与力—速度关系

肌肉有两条基本曲线，它们决定了人体所有运动的力学边界：

- **力—长度曲线**：肌肉在什么长度下能出最大的力（有解剖学基础）
- **力—速度曲线**：肌肉收缩多快时能出多大的力（没有解剖学基础，纯经验规律）

原文对这两条曲线的定位很有意思：前者能用肌丝重叠解释，后者"并没有解剖学结构基础"。这句提醒很重要——不要把双曲线当成某种结构投影，它只是一个拟合得很好的现象学规律。

## 一、Hill 三元素模型：把肌肉拆成三个部件

| 成分 | 位置 | 代表什么 |
| --- | --- | --- |
| **收缩成分（CE）** | 肌节 | 主动产生力 |
| **串联弹性成分（SEC）** | 肌腱 + 横桥 | 与收缩成分串联的弹性 |
| **并联弹性成分（PEC）** | 肌纤维周围结缔组织、肌膜 | 与收缩成分并联的弹性 |

关键关系：**并联成分产生的张力独立于收缩成分**，主要代表肌肉结缔组织的张力；串联成分则位于"肌腱及肌球蛋白和肌动蛋白之间的横桥里"。

原文对这个模型的评价很实在：它"为剖析肌肉活动的一般性提供了有用的模型，但是它过于模型化"。而且有一个具体的限定——"一块肌肉的动力学表现主要由肌纤维和腱膜的特性所决定，而肌腱虽然也是串联弹性成分，但可能是过于坚韧所以对肌肉动力学的表现影响不大"。

即：**日常动力学看肌腱-腱膜，不看肌腱本身**。这解释了为什么跟腱很硬（E 约 1.2～1.8 GPa）却不主导动力学——它几乎不"让"。

## 二、力—长度：一条曲线，两个来源

把肌肉拉长并记录张力，会得到两条叠加的曲线：

1. **被动张力**（PEC 贡献）：起始平缓，随后非线性上升
2. **主动张力**（CE 贡献）：先升后降，呈倒 U 形
3. **总张力** = 两者之和

两个必须记住的特征：

**第一，"被动张力的上升起点接近于主动张力的峰值位置"。** 这不是巧合，而是设计：肌肉在最能出力的长度上，被动结构刚好开始"接手"。于是总张力曲线在峰值附近形成一个宽阔的平台，肌肉在略长于最优长度的区间仍能维持高张力。

**第二，被动张力可以非常大：**

> 「在肌肉断裂之前肌肉产生的被动张力可达到主动收缩产生的最大张力的数倍。」（基础 p.621）

这条的临床含义被原文直接点出——**被动张力限制关节活动**，尤其跨两个关节的肌肉：

- 髋屈曲 > 90° 时，**腘绳肌限制膝关节伸展**
- 伸膝时，**腓肠肌限制踝背屈**

这解释了一个临床常见现象：直腿抬高受限，不一定是腘绳肌"紧"，可能只是它被髋屈曲拉到了被动张力陡升的区间。同理，伸膝位踝背屈受限（Silfverskiöld 试验的生理基础）也在此。

**结构的解释**（原文给了很干净的肌丝重叠逻辑）：

| 状态 | 肌丝关系 | 张力 |
| --- | --- | --- |
| 过度拉长 | 粗、细肌丝**不重叠** | 无法产生力 |
| 最优长度 | 重叠适度 | **最大** |
| 缩短 | 邻近肌节靠近 | 下降 |
| 进一步缩短 | 收缩成分**拥挤碰撞** | 最终丧失 |

"拥挤碰撞"这个描述比"重叠过多"更直观：不是没地方抓，是机器挤在一起转不动了。

被动张力的来源也在更新："主要是源于肌纤维周围的结缔组织以及肌腹的肌膜成分。近来研究表明某些被动张力可能是源于肌原纤维蛋白质本身。"后者指的就是**肌联蛋白（titin）**——它是肌节内的分子弹簧。

## 三、从"力"到"力矩"：三因素

人体运动产生的不是力，是力矩：

```
T = r × F     （T 力矩，r 力臂，F 肌力）
```

改变力矩只有三条路：

1. 肌肉产生的力变化
2. 力臂变化
3. 肌肉长度-张力曲线与关节夹角的对应关系变化（其实也改变了力臂）

由此得到一个临床上很常见的"错位"：

> 「对于某些肌肉，例如肘关节的屈肌和伸肌，最大的力矩是在关节位于其活动范围中间位置时获得，而当关节全屈或全伸状态时，力矩下降。在屈或伸的任一状态，屈肌或伸肌的收缩力可能实际上最大，但力臂可能为最小。」（基础 p.622）

即：**"肌肉最有劲"和"关节最有劲"不是同一件事。** 等长测力时病人说"这个角度最有力"，与肌肉真正产生最大张力时的角度可能相差很多。做等速测力、评定肌力时必须固定角度，原因就在这里。

原文还用一个步态例子说明向心/离心的衔接：摆动早期髋屈由髂腰肌向心收缩产生，力臂随屈曲增加而增加；摆动末转为腘绳肌离心收缩带动伸髋，此时髂腰肌力臂减少。"肌肉工作产生的力矩大致反映肌肉全部收缩过程的活动。"

## 四、力—速度：Hill 双曲线

核心事实：**负荷越低，收缩越快；负荷越高，收缩越慢；速度为零时力最大（等长）。**

Hill 用双曲线描述：

```
(F + a)(V + b) = (Fmax + a)·b
```

其中 F 为张力，V 为收缩速度，Fmax 为最大等长收缩力，a、b 为常数（原文提到"a+b 通常为 0.25"，指的是归一化后的常数关系）。

原文对这个公式的限定条件写得很谨慎，值得完整保留：

- 反映的是肌肉**由等长状态作迅速收缩**时的关系
- **不能**用来描述从等长状态作**缓慢**收缩时的关系
- 数据来自**两栖动物**的肌纤维，用于临床与人体肌肉系统"仍然有局限性"

这是很好的科学态度示例：一个被引用了几十年的公式，自己标明了适用边界。

**实践印证**：等速训练仪上，膝关节肌肉在 **60°/s 时的力矩大于 360°/s** 时的力矩。注意原文的提醒——"在恒定的关节角速度下运动并不代表肌肉的收缩速度是恒定的"。所以等速仪测的是"角速度设定"，不是"肌纤维速度设定"。

## 五、离心：被低估的一半

这是本章最有实用价值的部分。三条事实：

**第一，同等速度下离心能出更大的力、做更多的功。** "实际上是负功"——肌肉在拉长中吸收能量。

**第二，离心是步态中的主力模式。**

> 「步态研究显示许多下肢肌肉的活动是离心的，并起减低和控制关节运动的作用。四头肌活动主要出现在足跟着地而膝关节屈曲时，而不是在之后的膝关节伸直时。」（基础 p.623）

即股四头肌在**落地缓冲**时最活跃，而不是蹬伸时。这与很多人的直觉相反，也是为什么下楼梯比上楼梯更"伤膝"——离心负荷更大。

**第三，离心有四个优势：**

| 优势 | 数据/机制 |
| --- | --- |
| 机械效率高、耗氧低 | 适合"不能给肌肉分配太多能量"的病人 |
| 肌电活动低 | 同样最大力矩下只有**次最大**肌电，即"力大而主观费力小" |
| 抗 DOMS 能力提升 | 反复离心训练可增加对抗延迟性肌肉疼痛的能力 |
| 力量增益快 | 高负荷低重复即可 |

**一个非线性拐点**值得单独记：

> 「当收缩力大于最大收缩力的 50% 时，力量-速度之间的关系发生突然的变化。」（基础 p.623）

即双曲线不是全程光滑的，在 50% P₀ 以上存在一个折点。做康复处方时（尤其等速训练），这个阈值附近是"安全与损伤"的分界区之一。

关于离心还有一个术语层面的澄清（与上一篇呼应）：离心时肌肉在**激活状态下被拉长**，所以严格说应叫"离心性活动"。用"离心性收缩"会让"收缩=变短"的直觉与之冲突。

## 六、两条曲线怎么用

| 目标 | 用哪条曲线 | 具体做法 |
| --- | --- | --- |
| 评估肌肉力量 | 力—速度（等速） | 固定角速度，比较力矩；注意 60°/s 与 360°/s 不可直接比 |
| 判断关节活动受限来源 | 力—长度（被动段） | 双关节肌的被动张力可能才是限制因素 |
| 设计康复负荷 | 力—速度 + 50% P₀ 拐点 | 高负荷低速偏力量，低负荷高速偏功率；离心训练效率高但需控制 |
| 解释"有力却动不了" | 力矩 = r × F | 查力臂与关节角度，别只查肌力 |

## 七、缺口

- 未给出人体主要肌肉的力—长度曲线族与最优长度对应的关节角度，无法直接用于建模。
- 未讨论肌纤维类型对力—速度曲线的影响（快肌 Vmax 更高，曲线更"外扩"）。
- 未涉及肌腱顺应性对力—速度关系的调制（顺应性高的肌腱会"吃掉"速度），而这是当前运动生理的热点。
- 27 章关于肌纤维收缩力学（p.642 起）的实验细节未引用，本篇以 26 章的生物力学小节为主。
- 未讨论疲劳对两条曲线的改变（Fmax 下降、Vmax 下降、曲线内移）。

## 原文摘录

> 「通常肌肉被动张力上升的起点接近于肌肉主动收缩产生的张力的峰值位置。各肌肉之间在此表现方面有极大的变异性，但是肌肉的主动收缩力通常在肌肉不被显著拉长的长度下最高。」（基础 p.621）

> 「低负荷肌肉的收缩速度快于高负荷的肌肉。Hill 用双曲线来描述肌肉收缩力与速度之间的关系。」（基础 p.622）

> 「在同样的运动速度下，离心收缩的肌肉可以比向心收缩的肌肉产生更大的力和做更多的功（实际上是负功）。」（基础 p.623）
