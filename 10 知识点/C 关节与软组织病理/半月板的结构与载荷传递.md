# 半月板的结构与载荷传递

半月板常被当成"膝关节里的两块垫片"，这是一个很深的误解。垫片的作用是缓冲，半月板的真实作用是把**点接触变成面接触**——它把股骨髁的凸面与胫骨平台的平面之间的高压强，通过自身变形摊平。所以半月板切除的后果不是"少了个缓冲垫"，而是"接触面积少一半、压强翻几倍"。

## 一、它是纤维软骨，不是透明软骨

| 参数 | 半月板 | 关节软骨（对照） |
| --- | --- | --- |
| 水 | 65%～75% | 70%～85% |
| 蛋白多糖（占干重） | **约 1%** | 约 5%（占总重） |
| 主要胶原 | **Ⅰ型**为主（Ⅱ、Ⅲ、Ⅴ、Ⅵ型亦有） | Ⅱ型为主 |
| 压缩模量 | 约为关节软骨的 **1/2** | — |
| 渗透性 | 约为关节软骨的 **1/6～1/10** | — |
| 剪切模量 | 约为关节软骨的 **1/10** | — |

蛋白多糖只有关节软骨的 1/5，这一条决定了它的一切力学特性：**它不能像关节软骨那样靠渗透压吸水膨胀来承压，它的承压主要靠胶原网的几何结构与组织液的挤出阻力。**

"低压缩刚度 + 低渗透性"这个组合，正是理想的减震器：刚度低所以会变形、贴合；渗透性低所以液体挤不快，能量被逐步耗散。原文的结论是"半月板的低压缩刚度和低渗透能力，使其具有高效吸收震动的能力"。

## 二、胶原的三层编织

这是理解撕裂类型的关键。原文描述了三个编织层（基础 p.481）：

| 层 | 纤维走向 | 力学角色 |
| --- | --- | --- |
| 浅表层 | 网状细纤维，编织进网状基质 | 抗剪切、抗表面磨损 |
| 表层（浅表下） | 部分不规则排列的胶原束 | 过渡 |
| 中间层 | **大的、粗的、平行与环行的纤维** | 抗张力、传递负荷 |

再加上一套**放射状纤维**："从理论上讲，放射状纤维的作用就像'辫子'一样，使半月板结构更加坚韧，并可对抗由于过度压力所造成的半月板纵行撕裂。"

这就解释了两种最常见的撕裂为什么形态不同：

- **纵行／桶柄状撕裂**：沿环行纤维方向裂开，是"顺着纹理"的裂。临床上桶柄状撕裂之所以能翻转进髁间窝，就是因为裂口沿着环行纤维走了一条长弧。
- **水平撕裂**：原文明确把水平撕裂与"该部水平面剪切力较弱"对应起来——"半月板平均剪切模量大约只是关节软骨的十分之一"。层与层之间靠的是Ⅵ型胶原与核心蛋白聚糖的连接，这是最薄弱的界面。

放射状撕裂则相当于把"辫子"剪断，环行纤维失去横向约束，半月板受力时会被"拉扁"（即挤出），承载能力骤降。

## 三、两种蛋白多糖，功能完全不同

| | 可聚蛋白聚糖（aggrecan） | 核心蛋白聚糖（decorin） |
| --- | --- | --- |
| 大小 | 大，约 100 个硫酸软骨素链 + 少量硫酸角质素链 | 小 |
| 位置 | **内侧无血管区**，与Ⅱ型胶原共存 | 全半月板 |
| 功能 | 结合 Na⁺ 与水，像"分子海绵"，受压时分配液体 | 把Ⅰ型与Ⅱ型胶原束缚在一起，**调节原纤维直径** |

"分子海绵"这个比喻很重要：它说明半月板内侧区（无血管、偏软骨样）的承压依赖液体，而外周区（纤维样）的承压依赖胶原。**一块半月板内部其实是两种材料**，这也是为什么内侧区的撕裂愈合能力最差——它既没有血供，又是最依赖水合的那部分。

## 四、细胞：内外不同，能力不同

两种形态：梭形细胞（浅表带）与卵圆形/多边形细胞（其余部分，即纤维软骨细胞）。两者都富含内质网与高尔基体，线粒体少见——提示"在无血管环境中的软骨细胞可能是以无氧糖酵解为主要途径产生能量"。

更关键的是内外差异：

> 「在组织内部中央区域的细胞愈合能力很差，对生长因子，如血小板衍生生长因子的应答亦比组织周缘区域的细胞弱。」（基础 p.480）

所以半月板的愈合能力差异是**双重**的：外周有血供 + 外周细胞对生长因子敏感。这解释了为什么把血管引到中央区（血管通道技术）也只能部分解决问题——**血供来了，细胞还是不太响应**。

## 五、承载：数字最能说明问题

| 状态 | 通过半月板传递的负荷 |
| --- | --- |
| 膝关节伸直 | 至少 **50%** |
| 膝关节屈曲 90° | **85%** |

切除半月板后：**关节接触面积减少近 50%，接触压力增加 350%**（基础 p.483 图 9 说明）。

减震方面：正常膝关节的震动吸收能力比半月板切除后**高约 20%**。

这是一条很干净的因果链：接触面积减半 → 压强增 3.5 倍 → 软骨承受的应力超过其疲劳阈值 → 软骨退变 → OA。这解释了 Fairbank 在 1948 年就描述的"半月板切除后股骨髁关节面变得平而无光泽、关节间隙变窄、骨赘形成"。

也解释了为什么现在极力提倡**尽量保留半月板组织**：哪怕只保留一个边缘环，接触面积也不至于掉一半。

## 六、活动度：内外侧差别很大

| | 内侧半月板 | 外侧半月板 |
| --- | --- | --- |
| 平均活动幅度（屈 0°～120°） | 5.1 ± 0.96 mm | **11.2 ± 3.27 mm** |
| 前后移动比（P/A） | 1:1.3 | 1:2.4 |

原因有三：外侧半月板周缘游离、束缚少；附着点相近；外侧半月板的存在减少了骨间对抗，允许更大移动。而**胫侧副韧带中后部斜行纤维限制内侧半月板移动**，这"增加了其发生撕裂伤的风险"——内侧半月板撕裂更多，不只是因为它更固定，也因为它在负重区被"钉"住。

## 七、稳定与本体感觉

- **稳定**：单纯切除内侧半月板不显著增加膝关节前后移位；但**内侧半月板切除 + 前交叉韧带功能不全**时，向前位移显著增加。这说明半月板是"次级稳定结构"，在主力（ACL）完好时作用不显，主力失效后它的价值才暴露。单纯外侧半月板切除（或合并 ACL 不全）未显示松弛增加——内外侧不对称。
- **本体感觉**：半月板前后角有丰富的有髓与无髓神经纤维，含三种机械感受器——**Ruffini 终末、神经腱梭（Golgi 腱器官样）、Pacini 小体**，集中在角部尤其后角。这使半月板成为关节位置觉的传感器之一。

这一条对康复有直接含义：半月板切除（尤其全切）不只是力学损失，也是**本体感觉输入的损失**，术后神经肌肉训练不是可选项。

## 八、年龄与退变

- 水含量随年龄**不变**（与关节软骨不同）
- 糖胺聚糖含量变化：硫酸软骨素-6 与硫酸软骨素-4 比例增加
- 胶原含量增至 **30 岁**后维持，**80 岁以后**开始减少
- 非胶原蛋白从婴儿期 20% 降至 50～70 岁的约 10%
- 钙焦磷酸盐二羟化物结晶沉着增加

ACLT 模型中的半月板变化：水容量增加、GAG 初期下降（有报道硫酸软骨素减 30%、硫酸角质素减 70%），但**慢性期 GAG 浓度总体升高**——"纤维软骨细胞具有补充丢失蛋白多糖的特殊能力"。这一点与关节软骨不同：半月板有一定代偿能力。

## 九、缺口

- 未给出半月板各区的定量力学参数（如环行方向抗张模量的具体数值），只有相对比较。
- 未涉及半月板根部（root）撕裂——这是当代研究热点，力学后果接近全切。

## 原文摘录

> 「在膝关节伸时至少有 50% 的压力负荷是通过半月板传递的；当膝关节屈曲 90° 时，半月板承载的负荷达到 85%，当半月板被切除，关节的接触面减少了近 50%，从而显著增加相连骨关节面的负荷。」（基础 p.483）

> 「半月板的内在弹性系数相当于关节软骨的 1/2，渗透性相当于关节软骨的 1/6～1/10。」（基础 p.482）

> 「半月板平均剪切模量大约只是关节软骨的十分之一……（临床病例中常观察到水平撕裂和纵行桶柄状撕裂半月板的出现，这与该部水平面剪切力较弱是相吻合的）。」（基础 p.483）
