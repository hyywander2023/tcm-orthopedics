# 关节软骨的修复反应

同样一个"缺损"，在骨里能长好，在软骨里长不好；在骨软骨交界处能长出东西来，但长出来的不是软骨。这三句话几乎概括了软骨修复的全部困境，也解释了为什么软骨修复手术的疗效总是"短期尚可、长期不敢承诺"。

本章把修复失败的原因归结为两条（基础 p.429）：**缺乏血供**、**缺乏未分化细胞**。这两条都不新鲜，但这本书把它们推到逻辑终点：修复不是"再生能力弱"的问题，而是**根本触不到修复反应的启动开关**。

## 一、修复的启动开关是纤维蛋白凝块

带血管组织的修复有一条固定链条：

```
出血 → 纤维蛋白凝块 → 炎性细胞与未分化细胞自血管迁入
     → 增殖、分化 → 合成新基质 → 塑形改建
```

受损细胞和血小板释放的介质负责启动这条链。骨、肌腱、韧带、关节囊，甚至**半月板外周 1/3**，都走这条路。

软骨没有血管，所以：

- 不出血，不形成纤维蛋白凝块
- 血小板**不与受损软骨结合**（原文这一点写得很具体）
- 炎性细胞、毛细血管、未分化间充质细胞都不出现

所以软骨损伤不是"修得慢"，而是**修复程序从未启动**。这是"缺血管"的真正含义——不是营养供给问题，而是启动信号的缺失。

## 二、第二重障碍：细胞既搬不过去，也产不够

关节软骨只有一种细胞：高度分化的软骨细胞。它们被困在致密的胶原-蛋白多糖基质里，增殖与迁移能力都有限。

正常软骨基质构成：Ⅱ型胶原 10%～20%、聚合蛋白多糖 5%～10%、水 70%～85%。

三个随年龄恶化的因素：

1. 细胞分裂速度下降，成熟软骨"几乎很少有软骨细胞显示有丝分裂活动的征象"
2. 合成能力不足以填补"重要的组织缺损"——维持基质够用，修复缺损不够
3. 合成的基质分子本身在变差：可聚蛋白聚糖（aggrecan）与蛋白多糖集聚体随年龄变小、变异增大；细胞对促合成生长因子的反应也减弱

即使损伤深达软骨下骨、血管长进来，进来的细胞也"不能够总把损伤组织修复成为具有独特组成、结构和材料特性的正常关节软骨基质"。原因是软骨基质需要三样东西同时到位：Ⅱ型纤维胶原、大而精巧的软骨蛋白多糖、软骨特异性非胶原蛋白。少了任何一样，都只能是纤维软骨或瘢痕。

## 三、三类损伤，三种结局

这是本章最实用的部分——临床上"软骨损伤"不是一个诊断，至少是三个。

### 1. 浅表撕裂：不愈合，但也不扩大

关键分界是**潮线**（钙化软骨与未钙化软骨的分界）。

> 「关节软骨的浅表撕裂伤，如果不越过潮线，通常不能愈合。」（基础 p.429）

过程：邻近细胞死亡 → 周围细胞增生、基质合成增加 → 在表面形成薄薄一层新基质 → **几周后活动消失**。缺损终生存在，但**不进一步扩大**。

原文还顺带否定了三种"刺激愈合"的手段：关节镜下软骨内修补、开放手术、刨刀/激光/烧灼——「一样不能刺激软骨愈合」。

这里有一个很重要的推论：**孤立的浅表软骨撕裂本身不会导致 OA**。动物实验证明局限性实验性损伤通常不发展为全层软骨丢失。所以临床上看到软骨损伤 + OA，要分清谁是鸡谁是蛋。

### 2. 钝性撞击：表面没破，里面坏了

亚骨折撞击（subfracture impact）的阈值，原文给了具体数字：

| 模型 | 峰值撞击力 | 后果 |
| --- | --- | --- |
| 成熟兔髌股关节 | 600 N | 软骨生物力学减弱 |
| 猪髌股关节 | 6000 N | 软骨生物力学减弱；界面剪切骨折（在潮线处） |

撞击的后果清单：软骨细胞死亡、基质破坏、表面撕裂、**潮线增厚或扩展**、钙化层增加、潮线前移、**双倍潮线**、非钙化软骨变薄、软骨-骨联结区硬化。

这条链条被作者明确串成假说：非钙化软骨变薄 + 软骨下骨硬化 → 变薄的软骨在正常活动中应力改变 → 若干年后出现 OA。**"潮线前移"于是成了创伤后 OA 的形态学前哨**，也是一个可以在动物模型里定量的指标（钙化层厚度 / 全层厚度比）。

对做撞击或 ACLT 模型的人，这条尤其值得记：真正决定远期结局的可能不是撞击瞬间的软骨损伤，而是**钙化层与软骨下骨的重塑**。

### 3. 骨软骨缺损：能长，但长错

穿过软骨下骨后，一切条件都有了：出血、凝块、炎性细胞、骨髓来源的间充质细胞、骨基质与血小板释放的生长因子（PDGF、TGF-β）。

修复的时间表（基础 p.431）：

- **2 周**：间质细胞形成软骨细胞样环形结构，开始产生含Ⅱ型胶原与高浓度蛋白多糖的基质
- **6～8 周**：软骨部分以软骨细胞样细胞为主，基质含Ⅱ型胶原、蛋白多糖与部分Ⅰ型胶原；骨部分形成未成熟骨、纤维组织与透明软骨
- **6 个月**：软骨下骨基本恢复原有水平，但**软骨部分极少恢复**
- **1 年**：多数修复组织出现原纤维形成征象

修复组织的成分"介于透明软骨与纤维软骨之间"，且**与周围软骨不连接**（留下间隙），软骨下骨也不再是不可渗透的屏障。少数病例可以长期维持功能，甚至重塑得接近正常——但为什么少数能成、多数不能，原文坦承"尚不知道"。

## 四、为什么修复组织注定不耐用

这一段是全书对"纤维软骨为什么不行"讲得最透的地方（基础 p.431–432）。修复组织的材料特性有三个偏差：

| 偏差 | 数值/表现 | 后果 |
| --- | --- | --- |
| 固体基质弹性模量低 | 低于正常软骨 | 液压负重能力下降 |
| 渗透性高 | 高于正常软骨 | 间质水易被挤出，流体压支撑失效 |
| 膨胀性增加 | 在生理盐水中过度膨胀 | 说明约束膨胀的胶原网不足 |

膨胀性增加的四个可能原因，原文列得很清楚：

1. 形成的是 **Ⅰ 型胶原**，不是Ⅱ型
2. **胶原网状组织缺乏**（正常软骨的胶原网提供外形、张力强度、限制蛋白多糖膨胀）
3. 必需的黏附分子（如 **Ⅸ型胶原**）浓度不足
4. 出现干扰正常基质聚集的分子

还有一条几何层面的原因：正常软骨的胶原走向在浅表层、中层、深层各不相同（各向异性），而修复组织中**交界区胶原走向与关节面随机排列**。方向错了，力学就错了。

最后是整合问题：修复组织"不能良好地融入周围组织，而是留下间隙，易导致非正常液性渗出"。这条与临床影像上看到的"修复区与原生软骨之间的高信号带"是同一件事。

## 五、改善修复：所有方法都在做同一件事

把书里列的方法排一下，会发现它们其实都在补同一个缺口——**让修复程序启动，并让启动后的组织别长成瘢痕**。

| 方法 | 补的是哪个缺口 | 结果 |
| --- | --- | --- |
| 钻孔/微骨折（穿透软骨下骨） | 启动（出血 + 骨髓细胞） | 形成纤维软骨修复组织，疼痛短期缓解，疗效个体差异大 |
| 磨削关节成形 | 同上 | 同上 |
| 截骨术 / 关节牵引 | 改变负重 | 可刺激纤维软骨形成，但**无长期持续效果** |
| 骨膜 / 软骨膜移植 | 提供软骨源性祖细胞 | 有限临床研究显示有促进作用 |
| 软骨细胞 / 间充质干细胞移植 | 提供细胞 | 同上，未能恢复耐磨损表面 |
| 合成基质 / 生长因子 | 提供支架与信号 | 实验中有效，临床未确立 |

原文的结论毫不客气：「上述的方法中没有一种能够如所预期那样恢复骨关节炎关节的耐磨损表面，也没有一种能够始终成功地恢复关节面。」

作者提出的替代思路不是找更强的技术，而是**改变决策顺序**：先分析受累关节的结构与功能异常、分析患者未来对关节的使用需求，再制定一个组合方案（纠正力线/稳定性的力学异常 → 清除退变软骨 → 有限穿刺软骨下骨 → 生长因子或含细胞/因子的基质移植），并且**术后限制活动与负重**，以保证修复组织形成与成熟。

最后这条常被低估。修复组织在成熟期最怕负荷，而临床上"做完就想早点动"的诉求与生物学需求是直接冲突的。

## 六、缺口

- 没有给出各术式的适应证边界与疗效数据，属于机制层面的书，不做临床推荐。
- 未涉及现代的自体软骨细胞移植（ACI/MACI）分代、支架型软骨修复（如胶原膜）、以及 PRP/BMAC 的具体证据等级。
- 未讨论修复组织与原生软骨界面整合的分子机制（只有"留下间隙"这一形态学描述）。
- 潮线增厚、双倍潮线这些指标没有给出定量方法，做组织形态计量时需自行定义（如钙化层厚度占比）。

## 原文摘录

> 「限制关节软骨对损伤反应的因素包括缺乏血管和能迁移到损伤部位的细胞，而这些部位的内源性细胞对缺损无修复意义。」（基础 p.429）

> 「在猪试验模型中，6000 牛顿的峰值撞击力可使软骨-骨界面发生剪切骨折（也就是在潮线）。」（基础 p.430）

> 「修复组织具有比正常组织弹性模量低和渗透性高的固体基质。这两个特点使该组织的液压负重能力降低。」（基础 p.431）
