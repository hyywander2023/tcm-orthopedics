# 类风湿关节炎的病理

RA 与 OA 最根本的差别不在"炎症轻重"，而在**破坏的发起者是谁**。OA 是软骨自己先退变，滑膜炎跟着来；RA 是滑膜先变成一种侵袭性组织（关节翳），主动去吃掉软骨和骨。把这个顺序弄反，就会把 RA 当成"严重的 OA"来治。

原文给 RA 的定性很清楚：「慢性和进行性，在炎性过程中，关节所有的组织结构都发生很大改变，最后出现全关节破坏和关节功能丧失」（基础 p.444）。

## 一、滑膜的四步演变

| 阶段 | 变化 |
| --- | --- |
| 早期 | 血管生成明显，**内皮细胞破坏** |
| 随后 | 滑膜层细胞成分增加 |
| 数月后 | 滑膜增生显著，**细胞层数达 10～20 层**（正常 1～2 层） |
| 慢性期 | 滑膜下层积聚 T 细胞（CD4⁺ 记忆型）、B 细胞、巨噬细胞、浆细胞；血管增生明显 |

两个反直觉的细节：

**第一，血管多了，组织反而更缺血。** 「毛细血管形态计量学研究显示，与正常组织相比，关节炎组织的血管树结构紊乱，因此尽管血管较多，滑膜组织仍相对缺血」（基础 p.449）。这解释了为什么增生滑膜中央常见纤维素样坏死、为什么药物难以渗透到滑膜深层。也提示"抗血管生成"在 RA 中的逻辑不是"饿死滑膜"这么简单。

**第二，细胞增多不全是增殖。** B 型细胞靠局部增殖，A 型细胞靠骨髓移行，另外"细胞死亡（凋亡）率的异常下降也可能导致局部细胞成分增加"。三条路一起走，所以滑膜增生极难逆转。

## 二、关节翳：RA 的病理签名

> 「类风湿性关节炎滑膜可侵蚀软骨、骨和韧带，滑膜的侵袭区称为'关节翳'。」（基础 p.449）

关节翳的细胞构成值得注意：**大量巨噬细胞、原始间充质细胞，极少量淋巴细胞**。而"关节翳细胞"（pannus 来源的成纤维细胞）有一个非常突出的表型——**血管细胞黏附分子-1（VCAM-1）表达极高**。

为什么这条重要？因为关节翳不是靠炎症细胞"泡"坏软骨的，而是一块**有血管、有黏附分子、有降解酶的自给组织**。它一旦形成，就像贴在关节面上的一个异位器官，能持续侵蚀，与全身炎症活动度可以脱钩。这正是"临床缓解但影像仍在进展"的病理基础。

破坏由酶介导：MMP-1、MMP-2、MMP-3，以及半胱氨酸组织蛋白酶 B 和 L。酶主要来自**滑膜层的成纤维细胞样滑膜细胞**（而不是淋巴细胞）。OA 滑膜也有同样的基因表达，只是水平较低——又一次说明 RA 与 OA 的差别是**量级加上组织侵袭性**，不是"有无"。

## 三、软骨被侵蚀的两个部位

这一点很多人只记住一个：

1. **关节边缘（侧方）**：关节翳与软骨交界处。炎性细胞因子与趋化因子形成网络，刺激关节翳和邻近软骨细胞产酶。
2. **软骨下骨侧（深部）**：原文明确写道「炎症起始于软骨下骨，进而引起局部细胞活素的释放和软骨细胞的激活」（基础 p.445）。用新表位抗体做的原位检测证实，胶原裂解"不仅发生于关节翳交界处，也发生在远离交界处以及邻近软骨下骨的部位"。

第二点有重要的方法学后果：**只切关节面中部的软骨看病理，会低估 RA 的破坏**。取材要包含软骨-骨交界。

还有一条时间顺序：**可聚蛋白聚糖（aggrecan）先丢，胶原后降解**。体外研究显示"胶原纤维降解发生于软骨内蛋白聚糖和可聚蛋白聚糖丢失的后期"，推测是"大分子的聚合体被降解后，蛋白酶才能到达胶原纤维"——蛋白多糖原本是挡在胶原前面的物理屏障。

## 四、骨：被系统性掏空

RA 的骨丢失是全身性的，不只是关节周围：

- 长骨骨干与干骺端 X 线透亮度增高，源于**骨内膜骨吸收致皮质变薄**；哈弗管内破骨细胞、成骨细胞与高内皮血管（HEV）增多
- 动物模型（角叉菜胶诱导兔胫股关节炎）中股骨皮质骨强度明显下降，与 800～1200 μm 的巨大吸收腔有关；**给二磷酸盐不仅防骨吸收，还能防骨强度下降**
- 软骨下骨在慢性期可断裂：股骨头塌陷、髋臼内陷、胫骨负重面塌陷

一句很实用的临床警告：「骨量丢失高达 30% 以上时才可通过 X 线检查发现……临床医生在对 RA 患者进行关节置换或内固定时必须考虑到骨质疏松是 RA 病变的重要组成部分」（基础 p.451）。**X 线看着还行，不等于骨量还行。**

破骨细胞的激活链条也在这里讲得最完整：M-CSF 促进前体增殖分化；IL-1α、IL-1β、IL-6、IL-11、LIF、TNF-α 促进前体形成；成骨细胞通过膜表面 **ODF（即 RANKL）** 与破骨细胞前体的 **RANK** 结合，直接完成分化与激活信号——"细胞间相互作用就可完成这一过程，而不需要其它因子的参与"。

## 五、免疫机制：一个"各部分都对、整体讲不通"的故事

这一节值得单独说，因为它是全书里少见的**对主流假说提出反证**的段落。

**支持 T 细胞主导的证据**：滑膜中大量 CD4⁺ T 细胞浸润；动物模型（胶原诱导、佐剂性关节炎）由 T 细胞介导；特定 HLA-DR 单倍型易感。

**反证**：

- 抗 CD4、抗 CD5、抗 CD52 单抗治疗"疗效差，或完全无效，即使将 T 细胞从血液或滑膜组织中清除出去，也是如此"
- RA 关节内 T 细胞的蛋白与 mRNA 水平显示其**合成和分泌能力相对不足**，可能与局部 TGF-β、IL-10 等内源性抑制因子有关
- 与之相反，滑膜与滑液中的 IL-1、TNF-α 浓度很高，主要来自**滑膜层巨噬细胞与成纤维细胞**，而不是 T 细胞

于是原文给出一个折中的、分阶段的模型：

```
起始：T 细胞特异性反应（针对某个关节抗原）
  ↓
放大：巨噬细胞与成纤维细胞的细胞因子网络成为主力
  ↓
慢性期：局部氧自由基造成 DNA 损伤 → p53 / H-ras 突变
        → 滑膜细胞"部分转化" → 获得一定自主侵袭性
```

"部分转化"的证据相当硬：把 RA 滑膜细胞与软骨移植物一起植入 **SCID 大鼠**，1～2 个月后 RA 滑膜细胞迁入软骨基质，而 OA 或正常滑膜细胞**不发生迁移**。培养的 RA 滑膜细胞还有非锚定生长、丧失接触抑制等转化特征。p53 蛋白过度表达与体细胞突变在侵蚀性滑膜炎患者的滑膜层中都能查到。

但原文很克制地加了一句：这些突变"可能并非导致关节炎的原因，相反，炎性关节长期处于基因毒性环境可导致突变"。即**突变是结果**，是慢性炎症的副产物，但它一旦发生，就把疾病推进到一个新的、更难逆转的阶段。

## 六、自身抗原：一条有力的间接证据

软骨无血管，其特有成分在免疫系统成熟过程中"可不被识别为自身抗原"。能诱发侵蚀性关节炎的候选抗原有：**Ⅱ型胶原、可聚蛋白聚糖 G1 区、COMP、HCgp30（软骨糖蛋白 39）**。

最有力的临床证据是一条"治疗性实验"：**一旦软骨被完全侵蚀或在关节成形术中被切除，清除了自身抗原，炎性反应随之明显减轻。** 这几乎等同于在人体上做了一次抗原删除实验。

## 七、治疗靶点与病理的对应

| 靶点 | 依据 | 效果 |
| --- | --- | --- |
| TNF-α | 关节内浓度高，诱导 MMP 与其它细胞因子 | 抑制剂明显改善 RA（成功） |
| IL-1 | 诱导 MMP、抑制基质合成 | 阻断有效，临床前景好 |
| IL-6 | 促破骨细胞前体形成、急性相蛋白 | 阻断有效 |
| T 细胞（CD4/CD5/CD52） | T 细胞假说 | 临床对照研究"令人失望" |
| 破骨细胞（二膦酸盐） | 骨丢失由破骨细胞介导 | 动物实验可防骨强度下降 |

原文的收尾一句话很到位：「关节炎是一个复杂的过程，多种机制相互重叠，因此，治疗也应该在多个层面上展开。」

还有一个尚未解决的悬念：抗细胞因子治疗"除可改善患者主观症状外，能否改变关节进行性破坏的进程"，当时还不清楚。

## 八、缺口

- 未涉及抗 CCP 抗体、类风湿因子在诊断与预后中的具体作用（只在章节开头提到类风湿因子作为历史研究方向）。
- 未讨论吸烟、牙周炎等环境因素与黏膜起源假说。
- 关节翳的血管生成机制、缺氧（HIF）通路未展开。
- 未区分血清阳性与血清阴性 RA 的病理差异。

## 原文摘录

> 「类风湿性关节炎滑膜可侵蚀软骨、骨和韧带，滑膜的侵袭区称为'关节翳'。含有巨噬细胞、原始间充质细胞和极少量的淋巴细胞。」（基础 p.449）

> 「将类风湿性关节炎滑膜细胞与软骨移植物一同植入 SCID 大鼠，1～2 个月后，类风湿性关节炎滑膜细胞发生移栖，进入软骨基质，而骨关节炎或正常关节的滑膜细胞则不发生移栖。」（基础 p.450）

> 「一旦软骨被完全侵蚀或在关节成形术中被切除，从而清除了自身抗原，炎性反应随之明显减轻。」（基础 p.446）
