# 骨关节炎的病理进程

骨关节炎（OA）最容易被误解的一点，是它名字里的"炎"字。它的主体不是炎症，而是**软骨的退行性丢失加骨的重建反应**；滑膜的炎症是继发的、晚期的、程度轻的。反过来，类风湿关节炎（RA）才是以炎症为主、骨与软骨被"消化"掉的病。这两条路最终都走到关节破坏，但沿途的机制完全不同，所以治疗逻辑也不同。

本章（基础 第18章）把 OA 拆成五个并列的形态学改变：软骨原纤维形成与溃疡、关节囊与滑膜增厚、骨重建与硬化、骨赘、骨囊肿。这五件事不是五个并发症，而是**同一场力学失衡在五种组织上的投影**。

## 一、原发病变：从表面原纤维化到象牙化骨

OA 的起点在软骨最表层。原文的描述顺序很值得注意（基础 p.433）：

1. **表层磨损**，先是最表面 10%～15%；扫描电镜下可见"短的成簇或成片的胶原纤维从浅表剥脱"
2. **垂直缺口与裂缝**，进行性加深，肉眼可见表面粗糙、暗淡——这就是"原纤维形成"（fibrillation）
3. **蛋白多糖丢失**，番红 O 染色减弱可以证实，而且**染色改变早于形态改变**
4. **软骨细胞成簇增生**（克隆样），加速合成基质，但"不能迁移到缺损区域，其合成的基质也不能填充缺损"
5. 软骨碎片剥脱入关节腔，深层暴露
6. 软骨下骨暴露、**骨质象牙化**（eburnation）

第 4 步是理解 OA 的关键。软骨细胞不是"死光了"，恰恰相反——早期它们高度活跃。问题在于**活跃的细胞被困在致密基质里，产物只能堆在自己周围**。所以 OA 的早期不是细胞衰竭，而是"有产能、无投送"。

终末期的组织学只剩一句话：「只留下小片的软骨附着于剥脱的象牙化硬化的软骨下骨」（基础 p.434）。

## 二、软骨下骨：被忽略的主角

多数人把 OA 记成"软骨磨没了"，但原文给了骨同等甚至更重的篇幅：皮质骨增厚、骨小梁按主应力线重排、软骨下骨血管过多、硬化带出现板层线、甚至有小岛状死骨。骨赘被覆盖的常常是"貌似正常的透明软骨"——这说明骨赘不是垃圾堆，而是**病变关节面的一种生物学重建途径**。

囊肿则位于软骨下骨内，边缘硬化（这一点有鉴别意义：**OA 的囊肿边缘硬化，RA 的囊肿不是**）。囊液呈胶样，镜下是稀疏无定型区。

这里有一条对影像判读有用的推论：软骨下骨硬化 + 囊肿 + 骨赘这三件套，在 X 线上是 OA 的"骨性签名"。它们出现时，软骨的丢失早已不是早期。

## 三、滑膜与关节囊：继发、且偏晚

「骨关节炎关节的滑膜内衬可表现为轻到中度的炎性改变，与类风湿性关节炎的炎性改变相比较常被认为是继发性的」（基础 p.435）。演进顺序是：接近正常 → 滑膜下层增厚、滑膜层折叠 → 显著增厚、绒毛形成、炎性改变、新生血管。**这些改变一般在疾病晚期发生。**

关节囊则增厚，有时与下方变形的骨粘连——原文直接点明"这很可能就是活动受限的原因"。所以 OA 的活动受限有两个来源：骨性阻挡（骨赘、变形）与关节囊挛缩，后者常被忽视。

对动物模型研究来说，这条时间线有直接后果：**在 MIA 或 ACLT 模型的早期取材，滑膜炎症可能先于软骨形态改变出现，但这不代表 OA 是炎症病**。滑膜炎在 OA 里既是结果（软骨碎屑、晶体刺激滑膜）也可能是加速器，但不是始动因素。

## 四、病因：不是磨损，也不只是衰老

原文对"磨损说"的否定相当坚决（基础 p.436）：

- 正常关节终生适度使用**不增加** OA 风险；
- 老年人软骨的改变与 OA 的改变**不同**（表 2 专门对比）；
- 儿童不发生 OA，但青壮年创伤后可发生——所以年龄相关改变"增加了危险性，但本身并不导致疾病"。

流行率数据：15～44 岁 <5%，45～64 岁 25%～30%，65 岁以上 >60%，部分人群可达 90%。

病因分两类：

| 类型 | 占比 | 代表原因 |
| --- | --- | --- |
| 原发性（特发性） | 多数 | 多因素叠加，无单一病因 |
| 继发性 | 少数 | 创伤、感染、发育异常、代谢病（褐黄病、血色病、Gaucher）、神经源性关节病（夏尔科关节）、骨坏死塌陷、关节对合不良 |

继发性 OA 的价值在于**时间尺度**：踝关节骨折复位不良"短时期内就会导致 OA"，而原发性要几十年。这提示 OA 的机制是同一套，只是加载速度不同。

原文还提到一个不太好归类的机制：软骨基质蛋白掉入滑液后被局部淋巴细胞识别为抗原，可能解释"微小损伤激发局部自身免疫性滑膜炎"。但同时明确"这些关节也不会发生 OA"——即自身免疫反应在这里是伴发现象，不是主因。

## 五、分子层面：合成在加速，分解更快

这一段是本章最有价值的部分，也是最容易被简化掉的。

**水含量最先升高**，只升高几个百分点，但意义重大。为什么蛋白多糖明明在减少、水反而增多？原文给了三种解释，最终落在"胶原网抵抗蛋白多糖膨胀的刚度下降"上——即**水多不是因为有更多亲水物质，而是因为约束膨胀的网破了**。

**负重支持机制的转移**是全章最漂亮的一条链（基础 p.439）：

1. 正常软骨通透性极低（1～5×10⁻¹⁵ m/Ns），间质水很难流过
2. 所以受压时 **90%～95% 的负重由间质水承担**，固体基质被保护
3. OA 软骨水含量升高、通透性升高（且通透性随孔隙率呈**四次方**增长，不是线性）
4. 水被挤走，流体压支撑失效
5. 负荷转由胶原-蛋白多糖固体基质承担
6. 固体基质被压坏 → 进一步退变

这是一个正反馈环，也是"为什么 OA 一旦启动就难逆转"的力学解释。它同时解释了为什么**减重、改变负重**能延缓病程——不是"少磨一点"，而是把负荷重新交回给流体压机制。

**酶与抑制剂失衡**：MMP、胶原酶、明胶酶、基质降解酶升高，组织蛋白酶 B、D 升高；而 **TIMP 不升高，甚至降低**。原文的结论很干脆：「OA 中基质降解是这些酶失衡的结果」。IL-1 是这个级联的上游放大器——它能上调胶原酶原、基质降解酶、明胶酶、组织纤溶酶原激活物。注意原文特意说明 IL-1 **也可由软骨细胞自身产生**（旁分泌），这意味着软骨可以在没有明显滑膜炎症的情况下自我降解。

**代谢状态**：OA 软骨细胞的蛋白多糖与 DNA 合成速率都高于正常，且随病情加重而升高，"直到衰竭点，然后速率减慢"。所以 OA 是一个**高转换、净丢失**的状态——很像骨科的"高转换型骨丢失"。这也解释了为什么单纯抑制分解不够，因为合成侧也在异常运转，产物质量不对（硫酸软骨素链偏长、聚集能力下降）。

## 六、和 RA 的分界

| 维度 | OA | RA |
| --- | --- | --- |
| 主体过程 | 退行性变 + 修复/重建 | 炎症性破坏 |
| 起始组织 | 软骨（及软骨下骨） | 滑膜 |
| 滑膜炎 | 轻中度、继发、偏晚 | 重度、原发、早期 |
| 骨表现 | 硬化、骨赘、囊肿（边缘硬化） | 骨侵蚀、骨质疏松 |
| 软骨表现 | 原纤维化、垂直裂隙、象牙化 | 血管翳侵蚀、边缘性破坏 |
| 主要介质 | 力学 + IL-1 + MMP/TIMP 失衡 | TNF-α、IL-1、IL-6、免疫复合物 |

## 七、缺口

- 原文未讨论**滑膜炎症在 OA 中的因果权重**（是加速器还是旁观者），而这正是当前 OA 研究的核心争议之一，也直接关系到"抗炎能否改变 OA 病程"。
- 疼痛机制几乎未涉及——OA 的疼痛与影像分级常常不匹配，原文只把它列在"临床综合征"里。
- 表 2（衰老与 OA 的软骨区别）OCR 后错行严重，只能读出部分条目（合成活性、集聚体丢失、纤维化范围、细胞丢失、修复组织出现、渗透性与硬度），无法逐条对应，此处不作引用。
- 关节液、影像分级、疗效评价均不在本章范围。

## 原文摘录

> 「OA 包括普遍的进行性的关节软骨丢失，伴随关节软骨的修复、重塑形、软骨下骨硬化以及许多病例中有软骨下骨囊肿和边缘骨赘的形成。」（基础 p.433）

> 「当正常软骨受压时，90%～95% 的负重支持是由间质水提供的。这个机制使得胶原-蛋白多糖固体基质有效地避免了负担重负。」（基础 p.439）

> 「TIMP 的水平并不增加，甚至在骨关节炎软骨中有降低。这个现象支持如下假设，即酶和抑制物水平的平衡决定基质的降解速度。」（基础 p.440）
