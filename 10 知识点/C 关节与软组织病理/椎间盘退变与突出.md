# 椎间盘退变与突出

椎间盘是人体最早老化的组织之一，"最大的变化发生在 20 岁以后"。但老化不等于退变，退变也不等于疼痛——这三件事在临床上被反复混为一谈，而本章最扎实的贡献，恰恰是把它们分开，并给出了分开的依据。

## 一、老化与退变：不是同一件事

原文的表述很谨慎：

> 「尽管所有的椎间盘都将经历由于年龄而发生的变化，但是并非都会退变。」（基础 p.502）

退变的终末形态是：椎间盘几乎消失，只剩"薄薄的一层纤维组织与相邻的椎体分隔"。而老化的终末形态是：纤维环以内整个椎间盘变成"僵硬的纤维软骨"，髓核与内纤维环"非常困难"区分。

两者的界线问题，原文承认得很直白：**"还没有建立能够被广泛接受的椎间盘退变的诊断标准以及椎间盘老化和退变之间的鉴别诊断标准"**。而"晚期的椎间盘退变通常发生在无症状的中老年人群"——这就直接否定了"退变 = 病"的等式。

## 二、一生的时间线

| 阶段 | 髓核状态 | 血供 | 关键事件 |
| --- | --- | --- | --- |
| 出生 | 占椎间盘近一半，脊索组织（多核索状物 + 脊索细胞簇） | 丰富 | 胶原纤维直径几乎一致且小 |
| 生长 | 仍有近一半，脊索细胞减少，出现软骨样细胞 | 椎间盘体积增数倍，**中心到血管的距离大增**；纤维环与终板血管变小变少 | 大蛋白多糖聚合体消失 |
| 青少年 | 蛋白多糖"几乎全由短可聚蛋白聚糖分子和非聚合体的蛋白多糖构成" | 外周血管大量消失 | 内纤维环膨胀压迫髓核 |
| 成熟 | 髓核纤维化、变硬、发白、半透明 | — | 层间出现裂隙，由外周向中心延伸 |
| 老年 | 与内纤维环无法区分 | — | 中央极少活细胞；高度进一步降低 |

**"体积增大 → 中心到血管距离增大 → 血管变小变少"** 这三步是理解椎间盘退变的几何基础：它不是"血管病了"，而是**组织长大了，把血管甩在了外面**。

## 三、细胞死亡：一组很硬的数据

电子显微镜下的髓核细胞坏死比例：

| 年龄 | 坏死细胞比例 |
| --- | --- |
| 胎儿与婴儿 | < 2% |
| 青少年 | **> 50%** |
| 中老年 | **> 80%** |

青少年就过半，中老年超八成。这个数字说明：**椎间盘的细胞密度在生命很早的阶段就已经崩塌**。所谓"椎间盘修复能力差"，不是细胞不努力，而是没有细胞了。

## 四、退变的核心机制：营养—pH—细胞

原文把"营养运输能力降低"列为首要因素：

```
椎体增大 + 终板钙化 + 外周血供减少
        ↓
营养输入 ↓、代谢废物清除 ↓
        ↓
乳酸堆积 + 低氧 → pH 降低
        ↓
细胞代谢与生物合成 ↓ → 细胞死亡
        ↓
基质降解分子堆积 + 亲水性 ↓ → 弥散对流进一步受阻（正反馈）
```

这个链条的每一环都有可干预点，也解释了那些"加速因素"为什么起作用：

| 加速因素 | 作用环节 |
| --- | --- |
| 强制体育活动、脊柱变形 | 负荷增大 → 间接改变营养运输 |
| 制动 | 失去机械泵，运输停滞 |
| **振动（如驾驶）** | 负荷反复 → 营养运输受损 |
| **吸烟** | 直接降低血供 |
| 血管性疾病、糖尿病 | 直接降低血供 |

"振动（如驾驶）"这一条值得单独提：职业司机椎间盘退变发生率高，机制不只是姿势，还有振动本身对营养运输的干扰。

## 五、基质层面的三条独立损伤路径

除了营养，还有三条并行的机制，它们互相加强：

**路径一：蛋白多糖聚合体丢失。** 新生儿椎间盘有类似关节软骨的大聚合体，发育过程中消失，可聚蛋白聚糖变短，浓度下降。结果是保水能力下降 → 高度维持与负荷分散能力下降 → 中央纤维化变硬。原文特别指出："蛋白多糖浓度**首先**降低，**然后**出现椎间盘退化"——即生化改变在前。

**路径二：胶原的老化与变性。** 胶原交联量增加、纤维结构损坏、胶原变性；非酶促糖基化（Maillard 反应）与脂质过氧化增加交联，形成褐色素沉积。更值得注意的是：

> 「同一个体的纤维环和髓核的Ⅱ型胶原（丧失三螺旋结构）的变性超过关节软骨的变性。这种差别缘于椎间盘降解分子的堆积。」（基础 p.504）

即**椎间盘的胶原变性比关节软骨更严重**。原因不是负荷更大，而是"降解分子排不出去"——无血管组织的共同困境。

**路径三：非酶糖基化产物（AGEs）的双重作用。** 一方面增加交联、让组织变脆；另一方面"可刺激细胞，包括软骨细胞，释放细胞活素和蛋白酶从而引起椎间盘组织退变"。即 AGEs 不只是"老化痕迹"，它还是**主动的促炎信号**。这为"糖尿病加速椎间盘退变"提供了分子解释。

最后是**疲劳性衰竭**：反复形变 → 胶原纤维疲劳 → 肉眼可见的裂缝、裂隙、粘液样退变，或微观的纤维断裂。原文将其列为独立机制，因为它可以在成分完全正常的情况下发生。

## 六、力学改变：从"液体"到"固体"

这是全章最关键的一段，与第 21 章形成闭环。

| 特性 | 正常髓核 | 退变髓核 |
| --- | --- | --- |
| 行为 | 类似粘性液体 | 类似固体弹性 |
| 切应力参数 | 低 | **增加（变僵硬）** |
| 硬度 | 低 | 升高 |
| 透散作用 | 高 | 降低 |
| 流体静力压 | 高 | **降低** |
| 应力分布 | 各向同性 | **各向同性丧失** |

原文的因果句写得很清楚：

> 「这种类似液体方式向类似固体方式的转换是与液体静力压的减小密切相关的，并导致椎间盘分散负荷的能力减弱。这样可能引起椎间盘内应力状况的显著改变，出现髓核和纤维环病灶区的压力和张力异常增高。」（基础 p.504）

即：**液体承压时应力均匀（各向同性），固体承压时应力集中。各向同性的丧失，就是"局部过载"的来源。**

**渗透性的方向性改变**是另一个精妙的指标：

| | 正常 | 退变 |
| --- | --- | --- |
| 放射状（轴向营养通路） | **最大** | **减弱**（水分减少、分子碎片填塞小孔） |
| 轴向与环状 | 低 | **增加**（层间裂隙） |
| 总体 | 各向异性 | 趋于各向同性 |

正常椎间盘的渗透性是"定向"的：营养从终板沿放射状方向进来最顺。退变后这个方向被堵（分子碎片填塞），而层间裂隙让其它方向变得通畅——**营养进不来，废物却能乱窜**。这一条把"结构破坏"和"营养障碍"直接连在了一起。

**终板的角色**同样重要：退变终板变薄、细微破裂，渗透性明显增加，"让软骨终板在受力时将液体快速挤出"。好处是营养运输改善，坏处是"损害了终板提供的流体力学压力负荷支撑机制"——液体被挤走，压力支撑就没了。

原文最后给了一个很有用的二分法：

> 「退变可以在下列两种情况下发生：（1）椎间盘异常物质特性时受到正常负荷；（2）椎间盘正常物质特性时受到异常负荷。在创伤的情况下，后者则更多见。」（基础 p.505）

## 七、疼痛：三条机制，一条关键证据

原文列了三条（基础 p.505）：

1. **结构与力学特性丧失** → 神经末梢敏感介质释放 + 神经血管向退变椎间盘内生长
2. **力与排列改变** → 椎体、椎间关节、韧带、肌肉的神经末梢受刺激增加
3. **吸能分散能力降低** → 上述结构承受的载荷增加

第 1 条的证据最硬：

> 「虽然正常情况下神经纤维和血管不能渗透入外环的表层，但在退变椎间盘的纤维环内甚至髓核都已发现神经和血管，而且这些改变是和腰背痛密切相关的。」（基础 p.505）

**正常椎间盘无神经，退变的椎间盘长神经。** 这就是"盘源性腰痛"的解剖学基础，也是为什么椎间盘造影能诱发一致性疼痛——造影剂刺激的是新长入的神经末梢。

但原文同时承认关系"非常复杂"：有些人轻微退变却慢性腰痛，有些人晚期退变却几乎无症状。

## 八、突出：机制与一个实用的时间规律

定义为"髓核组织从有缺陷的纤维环突出"。机制是"裂缝贯穿很厚的纤维环而形成的缺陷"。

三个值得记住的细节：

**第一，裂缝的位置。** "最常见于纤维后侧环和椎体的结合处"——注意是**结合处**，不是纤维环中部。所以突出物的路径是：从靠近骨连接部 → 进入后纵韧带前方与椎体、纤维环后侧之间的空隙 → 向上或向下在椎管内延伸。这解释了为什么有些"突出"在矢状位 MRI 上表现为沿椎体后缘上下走行的条状影（即所谓的"经骨突出"或游离迁移），而不是正对椎间隙的团块。

**第二，诱发动作。** 实验证实"充分的屈伸、旋转的压力可引起纤维环裂缝增加"。屈曲 + 旋转（而非单纯屈曲）是最危险的组合。

**第三，一天中的时间规律**——这是本章最实用的一条：

> 「由于长时间的卧床休息使液体向椎间盘中央流动，导致流体压增大，或者说椎间盘的体积增加，一旦病人起床直立，椎间盘的压力会突然增加，因此椎间盘突出通常多发生在早晨。」（基础 p.506）

机制与第 21 章的昼夜水化完全一致：夜间再水化 → 体积与内压最大 → 晨起加载 → 最易突破。这条对临床有直接含义：**急性腰痛/坐骨神经痛常在晨起发病，不是"睡姿不对"，而是"椎间盘在一天中压力最高的时刻遇上了加载"**。

## 九、预后：两个必须知道的比例

> 「有症状的椎间盘突出病人中 90% 以上在三个月内疼痛减退。许多人（28%～35% 的无症状病人）无任何症状而发生椎间盘突出。」（基础 p.506）

第一个数字支持保守治疗优先；第二个数字是对"影像即诊断"的警告——无症状人群中 28%～35% 有突出。任何把 MRI 结果直接等同于病因的推论，都会在这个比例上翻车。

## 十、缺口

- 未给出椎间盘退变的影像学分级（Pfirrmann 分级在本章写作之后才普及），也未涉及 Modic 改变。
- 未讨论椎间盘突出的分型（膨出/突出/脱出/游离）的术语体系，原文只作概念性描述。
- 未涉及炎症机制在神经根痛中的具体介质（TNF-α、IL-1β 在突出组织中的表达），而这已是当代主流认识。
- 未讨论遗传因素（如 COL9A2、CILP 多态性）对椎间盘退变易感性的影响。
- 细胞治疗、生长因子、基因治疗等干预方向未涉及。

## 原文摘录

> 「在胎儿和婴儿的椎间盘中髓核细胞的坏死不超过 2%，而青少年中髓核细胞的坏死超过 50%，中老年则超过 80%。」（基础 p.503）

> 「渗透性对于正常椎间盘标本是定向依赖的（各向异性），但对退变椎间盘则不然。在正常椎间盘标本，其渗透性在放射状方向为最大，而退变标本其放射状渗透减弱。」（基础 p.505）

> 「光纤环破裂和症状性突出的最常见部位是在外纤维环进入椎体的地方。」（基础 p.506，原文"光纤环"应为"纤维环"之误）
