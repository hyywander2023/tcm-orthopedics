# 肌腱损伤与愈合

肌腱的损伤有一个反直觉的规律：**它很少"被拉断"，多数是"本来就有病"。** 中年人打羽毛球跟腱断裂、肩袖撕裂、网球肘——这些"意外"的组织学检查几乎都能找到断裂前的退变证据。所以肌腱损伤更像是一个**慢性过程在某个瞬间的结算**，而不是一次纯粹的机械事故。

## 一、断裂点在哪：薄弱环节决定损伤类型

原文给了一条很干脆的判断原则：

> 「肌肉-肌腱-骨整体受力如果超出了此结构的生理范围，则会在连接的薄弱环节上发生断裂。大多数肌腱能承受的张力比肌肉或骨骼上能承受的张力要大得多，所以，撕脱性骨折在肌肉、肌腱连接处发生的撕裂比在肌腱内发生的撕裂伤要多得多。」（基础 p.527）

即：**肌腱本身往往是最强的一环，所以断裂常发生在两端的"接口"——肌腱交界或骨附着处。**

两个具体例子：

- 青年运动时手屈肌腱损伤，常为**骨附着处撕脱性骨折**，其中**无名指占 75%**；原因之一是"无名指屈肌腱明显比中指、食指肌腱要弱一些"
- 跟腱断裂则例外地发生在腱内——因为跟腱中段存在相对乏血管区

## 二、断裂之前：退变已经在进行

> 「当肌腱发生间接性损伤时，常在过度负荷之前就已存在腱的病变。」（基础 p.527）

典型场景描述得极准：跟腱撕裂"常见于参加剧烈运动的中年人。损伤时常为意外伤，患者有受打击的感觉，许多患者以前无受伤史或不适感觉"。组织学检查发现"纤维中血管增生，表明肌腱组织在断裂前已经处于进行性退变的过程或失代偿的阶段"。

**"无受伤史、无不适感"** 这一点很重要：肌腱退变在相当长的时间里是**无症状**的。这与椎间盘退变在无症状人群中高发是同一类现象。

局部因素也有三类：

1. **缺血**（跟腱中段、肩袖"临界区"）
2. **炎症**（类风湿患者拇长伸肌腱在骨突处磨损）
3. **骨性磨损**（肩袖与肱二头肌在肩峰前内侧的磨损）

注意第 3 条的机制：不是"用多了磨坏"，而是"通道变窄，肌腱每天被锯"。所以肩峰下减压的逻辑是改变通道，而非"消炎"。

## 三、有腱围覆盖的肌腱：一条可以背下来的时间线

以兔、大鼠跟腱为模型，过程如下：

| 时间 | 事件 |
| --- | --- |
| 伤后即刻 | 伤口充满炎性物质、血细胞、细胞核残留物与纤维；组织失去张力 |
| 第 1 周 | 腱围增生组织自两侧侵入肌腱残端，被未分化、无定向的成纤维细胞充填；毛细血管芽 + 成纤维细胞构成肉芽组织 |
| 第 3 天起 | 胶原合成启动：先 GAG 浓度升高，随后胶原单体聚合（内质网合成前体 → 三螺旋靠羟脯氨酸羟基与酮亚胺基的氢键稳定 → 聚合成纤维） |
| 第 2 周 | 残端间形成纤维性连接；**新胶原纤维垂直于肌腱纵轴**；Ⅰ型胶原标记量达正常 **15～22 倍** |
| 第 3～4 周 | 在应力作用下，**靠近肌腱**的成纤维细胞与胶原开始沿纵轴重排（远离肌腱的尚未重排） |
| 数月至 **第 20 周** | 重建持续；血管与细胞差异逐渐接近正常 |

这里有两个必须注意的点：

**第一，"先垂直，后平行"。** 第 2 周胶原是横着长的（垂直于腱轴），第 3～4 周才转向纵轴，而且只有靠近肌腱的那部分转。这意味着**力学加载必须在这个窗口介入**——早了没有可定向的基质，晚了则已固化成瘢痕。原文说"只有靠近肌腱的胶原才进行重新排列方向的过程，而远离肌腱的胶原则尚未重新排列"，这句描述了一个梯度，也提示康复负荷应当是从小到大、逐步向内传导的。

**第二，强度提升靠"减重"而不是"增重"。** 原文写得很精炼：

> 「愈合肌腱所承受的负荷渐增加而总质量却渐减少。这种抵抗较大张力而横截面积缩小的情况意味着腱本身承受张力的能力增加很快。」（基础 p.529）

即愈合后期的关键不是"长更多组织"，而是**塑形与吸收**——把多余的瘢痕去掉，把剩下的排列整齐。这与骨痂改建是同一个逻辑（见[[骨折愈合的过程与分期]]）。

而这一切都依赖负荷：

> 「胶原单体的产生、纤维的方向重排及十字交联均依赖于腱上承受的负荷。缺乏负荷的情况下，胶原合成减少，重建过程、愈合肌腱的质量增加速度也同时减慢。」（基础 p.529）

**完全制动 = 主动放弃重建。** 这是现代腱修复术后早期活动理念的生物学基础。

## 四、有腱鞘的肌腱：内源与外源之争

手指屈肌腱泡在腱鞘里，愈合能力长期被认为很差（"无人区"）。历史上的争论是：

- **外源愈合说**：靠腱鞘长出的肉芽组织包裹、桥接
- **内源愈合说**：腱细胞（腱内膜细胞）自身参与修复

原文的结论是**两者都有，且内源是真实的**：

- 屈肌腱细胞培养能在撕裂末端形成"帽状结构"，由腱鞘与腱内膜衍生细胞增生移行而成
- 兔屈肌腱横切 90% 后：3 周时腱鞘细胞移向伤口、分化为吞噬细胞/巨噬细胞，通过**桥粒**连接；6 周吞噬细胞增多；9 周细胞活动仍在继续
- 结论句："在合适的环境中，带腱鞘的肌腱具有修复能力"

而"合适的环境"取决于活动模式：

- **控制下被动活动**：以内源性反应为主（腱鞘细胞增生）
- **制动**：靠腱鞘膨大部分的连接组织向内生长 + 腱内膜细胞增生（偏外源）

这条对照极其重要：**活动模式改变了愈合的细胞来源**。制动时靠外源长入 → 粘连多；活动时靠内源修复 → 粘连少。这就是"早期控制性被动活动"能在临床上减少粘连的机制解释。

## 五、缝合：四个力学原则

原文把缝合技术的演进讲成了力学问题，很清晰：

| 原则 | 做法 | 原因 |
| --- | --- | --- |
| 增加强度 | 垂直穿过肌腱缝一次 + 平行通过断端；多股、多处缝合 | 垂直缝合增强"腱-线-腱"结构强度；但单靠垂直缝合易因缝线撕脱失败，说明**线-腱界面强于线本身** |
| 减少间隙 | 外周腱鞘缝合 | 即使很小的间隙也显著影响预后；抗间隙能力是一个独立的力学参数 |
| 保护血供 | 在**掌侧**缝合，避开背侧纵行血管 | 背侧是腱内血供主干 |
| 保证滑动 | 低位纵向缝合，结埋在腱鞘外 | 结在外会与鞘摩擦、形成粘连 |

原文对"只考虑强度不够"的提醒也很到位："能存活的受损组织的力学强度会影响修复结果"——**强度是活组织才有的属性**，缝得再牢，组织坏死也白搭。

## 六、康复：一个窄窗口

动物实验的结论是双向的：

- **渐进性早期活动或早期负重** → 可导致撕裂与间隙形成
- **严格控制下早期被动活动** → 刺激修复、前几个月提高肌腱力量、减少粘连

所以存在一个"最佳负荷"：既能促进愈合，又不增加再断裂风险。原文坦承这个方案"目前仍是一个难题"，因为动物实验有个体愈合差异、长期追踪成本高、康复过程难控制等限制。

实践中可以提炼出三条原则（本节为归纳，非原文）：

1. **被动可以早，主动抗阻要晚**——被动活动提供定向信号而不产生高张力
2. **负荷要沿腱轴**——因为重排是靠力线引导的
3. **保护期长度看血供**——腱鞘内屈肌腱、跟腱中段这类乏血管区需要更长的保护期

## 七、缺口

- 未讨论肌腱附着点（enthesis）损伤与撕脱骨折的界面重建。
- 未涉及腱病的退变分级（如 Bonar 评分）与影像（超声、MRI）对应。
- 未讨论生物增强手段（PRP、干细胞、支架）的证据，虽然提到"缝合材料、方法、打结、CPM、负荷、损伤性质与位置均影响修复质量"，但未展开。
- 未涉及腱鞘内注射糖皮质激素对肌腱强度的影响——这是临床高频操作，与"激素降低胶原合成"直接相关。
- 未讨论肌腱-骨愈合（tendon-to-bone healing）与肌腱-肌腱愈合的差别，前者慢得多。

## 原文摘录

> 「在动物模型中，伤口处出现Ⅰ型胶原，用脯氨酸进行放射性标记显示，其数量为正常组织中的 15～22 倍。胶原的合成速率在以后的几个月中逐渐减少。」（基础 p.528）

> 「肌腱残端之间胶原纤维的生长及移动最初是垂直于肌腱纵轴。」（基础 p.528）

> 「严格控制下进行早期被动活动可刺激修复并在修复后的前几个月提高肌腱力量。此外，早期进行少量运动可减少肌腱愈合过程中形成粘连的程度。」（基础 p.530）
