# 围手术期肺窘迫与血栓栓塞

骨科大手术后的死亡，一半以上来自肺。而"肺的问题"在骨科有两套完全不同的机制：

- **脂肪栓塞综合征（FES）**——与**操作**有关（扩髓、加压、骨水泥），发生在**术中到术后 72 小时**；
- **静脉血栓栓塞（VTE）**——与**制动和高凝状态**有关，发生在**术后数天到数周**。

**两者的临床表现可以一模一样（低氧、呼吸困难、意识改变），但处理方向相反。** 分清它们是这一域的核心。

## 一、先看数量级：VTE 有多常见

第 12 章 p.292 给了一组极有冲击力的美国数据：

> 「静脉血栓栓塞是导致**成人下肢骨科手术术后病重和死亡的主要原因**。在美国，每年约有 **70 万**患者患有**无症状**的肺栓塞（PE），其中 **20 万**患者死于该并发症。约 **7 万**患者在症状出现 **1 小时内**死亡。」

```
70 万 无症状 PE / 年
   ├─ 20 万 死亡（约 29%）
   └─ 其中 7 万 在症状出现后 1 小时内死亡
```

**"7 万人在 1 小时内死亡"这一条决定了防治策略的方向**：这部分病人**没有抢救窗口**。所以 VTE 的处理不能靠"早发现早治疗"，只能靠**预防**。原文的判断与此一致：

> 「**大多数死于肺栓塞的患者若原有情况得以改善，其预后可能得到改观，从这个角度讲，肺栓塞是一种可以预防的并发症。**」（p.292）

### 分手术类型的风险

| 手术 | 无抗凝时 DVT（放射学标准） | 进展为 PE | 致死性 PE |
| --- | --- | --- | --- |
| **髋部手术** | **75%** | **20%**（有临床表现） | **1%**（死亡率） |
| **膝部手术** | **80%**（无症状） | 8%（无症状） | **< 1%** |
| **骨盆骨折 / 长骨骨折** | **接近 80%** | — | — |

（出处：p.292）

**三个必须读出来的信息：**

1. **"75%～80%"是放射学诊断的无症状 DVT**。这个数字如此之高，说明**术后形成小腿静脉血栓几乎是"生理现象"**，而不是"并发症"。真正决定后果的是"它有没有长到近端、有没有脱落"。
2. **髋部手术死亡率最高**——"骨科文献对发生血栓栓塞的风险因素的严重程度有明确的报道，**髋部手术术后的死亡率最高**"。
3. **膝关节术后致死性 PE < 1%**，低于髋部。这与"膝部手术 PE 更少但 DVT 更多"的经典观察一致：**膝部血栓多在小腿，髋部血栓更易累及近端。**

## 二、为什么骨科是 VTE 的"高发区"

p.292 讲了病理生理，核心是三个因素叠加（Virchow 三要素的骨科版本）：

| 因素 | 骨科的具体来源 |
| --- | --- |
| **血流淤滞** | 制动、卧床、患肢抬高、止血带 |
| **内皮损伤** | 手术操作、锯骨、扩髓、假体置入、止血带释放的再灌注 |
| **高凝状态** | 创伤本身、组织因子释放、术后炎症反应 |

> 「**纤维蛋白的形成是凝血的必要条件**，而它的形成是通过十几种蛋白相互之间的链式（反应）……」（p.292）

而风险因素清单在 p.292 给出：

> 「创伤患者发生深静脉血栓的风险因素包括**老龄，需手术或输血，下肢骨折以及脊髓损伤**。」

第 7 章 p.218 补了更完整的一份：

> 「这些危险因素包括**血栓病形成前、血管或骨科手术前、高龄、恶性肿瘤、充血性心力衰竭、静卧、肥胖、使用口服避孕药和过度失血后输血**。」

**"肥胖"与"口服避孕药"这两条在骨科常被忽略**——它们不在骨科医生的常规问诊里，但直接改变预防方案的选择。

## 三、预防：四种药，一个未解决的问题

第 7 章 p.218 列了当时的药物选择：

> 「最常用的药物是**阿司匹林、华法林（warfarin）、低剂量和可调剂量肝素（heparin）和低分子量肝素**。」

但同一页的措辞非常谨慎：

> 「目前**理想的药物预防方案尚待建立**，有几种方案可对血栓性疾病进行初步预防。」

以及一段更值得注意的观察：

> 「（死亡率）的降低与**总死亡率减低之间的关系还不明确**。此外，关于**抗凝治疗引起的并发症的争论越来越多**。骨科手术后的死亡对患者来说是一个悲剧，但是总有一些患者在全关节成形术后突然死亡。药物在其中所起到的作用也因为**抗凝治疗的利弊难于分辨**而不易明确。」

**这段话说的是：降低 DVT 发生率 ≠ 降低死亡率。** 因为抗凝本身带来出血风险，而出血也可能致命。

**这是一个"替代终点 vs 硬终点"的经典问题**，也是这一域最值得记住的方法学教训：**DVT 是替代终点，死亡才是硬终点。而两者之间的关系并不自动成立。**

（今天这一问题仍未完全解决——现代指南用"症状性 VTE + 严重出血"的净获益来权衡。）

## 四、脂肪栓塞：机制在"压力"，不在"脂肪量"

第 12 章 p.290 给了 FES 的关键机制，这条比任何临床表现都重要：

> 「**髓腔内压力（IMP）必须超过静脉压时骨髓脂肪才可能进入血循环。** 股骨的 IMP 在正常生理情况下为 **30～50 mmHg**，扩（髓则显著升高）……」

```
髓腔压力 > 静脉压  →  骨髓脂肪进入静脉窦  →  肺循环 → 肺脂肪栓塞
```

**这条机制直接给出了预防策略**：

| 措施 | 力学原理 |
| --- | --- |
| **避免过度扩髓** | 降低髓腔压力峰值 |
| **扩髓时缓慢推进** | 给静脉回流留出时间 |
| **髓腔冲洗/排气孔** | 释放压力 |
| **骨水泥加压时排气** | 防止"骨水泥植入综合征"（同一机制） |

原文对扩髓的态度是矛盾的，也是诚实的（p.292）：

> 「尽管如此，扩髓在生理上仍有缺点。虽然很多临床研究表明对多发创伤患者进行扩髓**可能会抑制肺功能**，但治疗时**很难确定哪些患者肺功能状态不宜扩髓**而应采用不扩髓髓内针。」

**"很难确定"**——这四个字是本章最有价值的一句。它说明：**机制清楚，但无法个体化预测。** 这类"知道原理但用不上"的处境，在临床上远比"不知道原理"更常见。

### 为什么只有一部分人发生 FES

> 「至今仍无法解释为何脂肪栓塞综合征**只在某些创伤患者中发生**。很大一部分创伤患者（**30%～50%**）出现低氧血症……这种暂时性的低氧血症极有可能是**亚临床型的肺脂肪栓塞**所致。有理论认为患者发生脂肪栓塞综合征首先必须有诸如**休克、低血容量、弥散性血管内凝血、败血症或原有心肺功能异常**等风险因素的存在。」（p.290）

**这个解释很关键**：脂肪入血是"普遍现象"（30%～50% 有低氧），而 FES 是"少数事件"。**区别在于"储备"**——同样的栓塞负荷，在心肺功能正常的人身上是亚临床的，在休克/低血容量的人身上就是显性的。

**推论：FES 的预防重点应放在"纠正休克与容量"上，而不只是"减少脂肪入血"。**

### 诊断：没有确诊检查

> 「……化验室检查可协助诊断脂肪栓塞综合征，但**不存在任何确诊性的检查**。其中 **ABG 最具实用性，72 小时内 Po₂ 降至 50 mmHg 以下**是患者发生脂肪栓塞综合征的重要指标。」（p.290）

| 检查 | 价值 |
| --- | --- |
| **血气分析（ABG）** | **最实用**；72 h 内 PaO₂ < 50 mmHg 为重要指标 |
| 血细胞压积、血小板、血清脂肪酶 | 辅助 |
| 痰/尿找脂肪小球 | 特异性差（"肺泡组织内仅存在脂肪组织并不是可靠的诊断依据"） |
| 支气管肺泡灌洗、肺动脉采血 | 研究用，临床不实用 |

**"不存在任何确诊性的检查"** ——所以 FES 是**临床诊断 + 排除诊断**。必须先排除气胸、血胸、容量过载、肺炎、PE（p.290 明确列出这五项鉴别）。

### 治疗：支持为主，激素有争议

> 「对于脂肪栓塞综合征**没有特异性的治疗方法**，主要为**支持性疗法**，旨在确保复苏、正确处理创伤以及支持肺功能。」（p.291）

> 「对脂肪栓塞综合征的预防和治疗缺乏有效的药物。**类固醇激素应用较广泛**，常用于治疗高危患者……一些预期性随机研究探讨了甲泼尼龙作为脂肪栓塞综合征的预防性治疗的作用，数据表明激素疗法可**降低发生脂肪栓塞综合征和肺功能异常的风险性，但**（对死亡率的影响不明确）……」（p.291，末句被版面切断）

**"降低发生率但死亡率影响不明确"——与抗凝药那段是同一个方法学问题**：替代终点改善，硬终点不明。

## 五、两套机制的鉴别表

| | 脂肪栓塞（FES） | 静脉血栓栓塞（VTE） |
| --- | --- | --- |
| **机制** | 髓腔脂肪入血（机械） | 血栓形成并脱落（血流+内皮+高凝） |
| **诱因** | **操作**（扩髓、加压、骨水泥） | **制动、高凝** |
| **时间** | **术中～术后 72 h** | 术后数天～数周（可持续数月） |
| **典型表现** | 低氧 + **意识改变 + 瘀点疹**（三联征） | 呼吸困难、胸痛、单侧下肢肿胀 |
| **诊断** | 无确诊检查；ABG + 排除 | 超声（DVT）、CTPA（PE）、D-二聚体 |
| **治疗** | **支持治疗**（无特效） | **抗凝**（有特效） |
| **预防** | 降低髓腔压力 | 药物 + 机械预防 |

**最实用的鉴别点是"时间"和"有没有下肢症状"**：
- 术后第 1 天低氧 + 意识模糊 + 结膜/腋下瘀点 → 想 FES；
- 术后第 5 天突发呼吸困难 + 单侧小腿肿 → 想 VTE。

**而"给 FES 病人抗凝"和"给 VTE 病人只做支持治疗"都是可致命的错误**，因为两者的处理方向完全相反。

## 六、缺口

- 未涉及 **D-二聚体的诊断价值与年龄校正阈值**（本书时代的 D-二聚体应用尚不成熟）。
- 未讨论**机械预防**（间歇充气加压、梯度压力袜、下腔静脉滤器）——这是与药物同等重要的支柱，本章几乎未提。
- 未涉及**抗凝疗程的具体时长**（现代：髋膝置换 10～35 天）。
- 未讨论**新型口服抗凝药（DOACs）**——本书成书时尚未上市，这是本领域最大的变化。
- 未涉及**止血带对 VTE 的影响**这一骨科特有问题。
- 未讨论 **FES 三联征（低氧、意识改变、瘀点疹）** 的完整描述（原文在图片与断句中散落）。
- 未给出**中国人群的 VTE 发生率数据**，全部数据来自美国。
- 未涉及**快速康复（ERAS）**理念对 VTE 预防的影响（早期活动是最有效的措施之一）。

## 原文摘录

> 「（脂肪栓塞）但并不出现反映气体交换等肺功能指数的改变，因此提示由**中性脂肪转变为游离脂肪酸**这一过程的重要性。」（基础 p.290）

> 「在严重创伤后一些体液因子的释放（**血栓素、前列腺素及儿茶酚胺**等）也支持生物化学理论，这些因子调动循环中以及体内储存的游离脂肪酸，产生血管活性反应并激活凝血通道，从而**直接损伤肺组织**。」（基础 p.290）

> 「也许最重要的治疗是**认识到导致患者趋于脂肪栓塞综合征的风险因素**，从而保证早期诊断以及正确的系统性治疗。」（基础 p.291）

> 「约 **7 万**患者在症状出现 **1 小时内**死亡。」（基础 p.292）
