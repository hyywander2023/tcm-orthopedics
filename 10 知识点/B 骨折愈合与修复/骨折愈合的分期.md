# 骨折愈合的分期

中文教材常见的"血肿炎症期—软骨痂期—硬骨痂期—塑形期"四阶段，是**教学简化**。基础书用的是**六期**，而且强调愈合不是一条线，而是**四个部位的反应并行**：骨髓、皮质、骨膜、周围软组织。

## 一、四个并行的反应

> 可通过四种不同的反应来了解骨折愈合的各个阶段，包括发生在骨髓、皮质、骨膜和周围软组织的反应。根据骨折的类型、位置及治疗方法，这一过程中的一种或几种反应可以同时进行。（基础 p.347）

这句话解决了一个常见的困惑：为什么同一张切片上能看到处于不同阶段的组织？因为它们本来就不是同一条时间线。**骨膜反应最快、皮质反应最慢**，所以切片上"外层已有板层骨、断端还在吸收"是正常的。

## 二、六个时期

| 期 | 内容 |
| --- | --- |
| 初始期 | 血肿形成，同时出现炎症改变 |
| 血管生成与软骨形成期 | 血管长入，软骨形成 |
| 软骨钙化期 | 软骨基质钙化，基质小泡参与 |
| 软骨消散期 | 钙化软骨被破软骨细胞／破骨细胞吸收 |
| 骨形成期 | 编织骨替代 |
| 塑形期 | 最漫长，编织骨改建为板层骨 |

（基础 p.348）

六期是在**不作坚强固定**的前提下总结的——书里明确说"对于多数骨折的处理或是不进行治疗，或是以允许一定范围的活动的方式进行治疗（悬吊制动、石膏管型、外固定、髓内固定）。因此骨折愈合主要是通过膜内骨化和软骨内骨化两种过程联合的形式进行的"（基础 p.348）。若用加压钢板做到绝对稳定，走的是一期愈合，不经这六期，见 [[一期愈合与二期愈合]]。

## 三、血肿不是"垃圾"，是信号源

旧教科书的说法是血肿提供纤维蛋白支架、给早期机械稳定。本书明确修正：

> 现在认为凝血块的功能是作为一种分子信号源，以启动骨折愈合中至关重要的各种细胞水平的链式阶梯反应。例如，炎症细胞分泌的细胞刺激素如白细胞介素-1 和白细胞介素-6（IL-1、IL-6）在骨折愈合中对早期反应起着重要的调节作用。除此之外，凝血块中脱颗粒血小板可以释放信号源分子，诸如生长转换因子（TGF-β）和血小板衍生生长因子（PDGF）。（基础 p.348）

临床推论（**书中未直说，属推理**）：既然血肿是信号源，那么反复抽吸、过度冲洗骨折端、过早手法揉捏，逻辑上都在削弱启动信号。这条在中医骨伤"早期不宜过多扰动"的经验里能找到对应，但本书没有做这个连接。

## 四、时间轴（实验鼠／家兔数据）

| 时点 | 事件 |
| --- | --- |
| 伤后 24 小时 | 骨髓细胞演变为成骨细胞并开始成骨 |
| 第 1～7/10 天 | 膜内骨化与软骨内骨化开始成骨 |
| 第 9 天前后 | 增生的软骨细胞有丝分裂达峰 |
| 第 2 周中期 | 骨折处被大量软骨覆盖，为钙化做生化准备；肥大细胞成为主体 |
| 伤后 3 天 | 碱性磷酸酶达峰 |
| 伤后 14 天 | 各类蛋白酶活性定量表达达峰 |
| 第 2 周末 | 钙化软骨被吸收，编织骨替代，可认为骨折愈合（组织学意义） |

（基础 p.348–349）

注意两个"峰值"错位：**碱性磷酸酶在第 3 天就达峰，而蛋白酶活性要到第 14 天**。这说明矿化的"准备"远早于"执行"。做动物实验取材时若只取 2 周一个点，会漏掉最早的成骨启动信号。

## 五、骨痂的两半

> 此时骨痂可以被分为进行膜内骨化的硬骨痂和进行软骨内骨化的软骨痂。（基础 p.348）

- **硬骨痂**：膜内骨化直接成骨，无需先有软骨，因此早期即可在其中检出结构蛋白
- **软骨痂**：软骨内骨化，先有软骨原基，再钙化、再被骨替代

两者在切片上的鉴别要点是**有没有软骨中间态**。这一点在 [[骨痂的形成与改造]] 和 [[骨折愈合的组织学观察]] 里展开。

## 六、缺口

- 各期的持续时间，书中只给了动物数据，没有人类的分期时限。
- "软骨消散期"的细胞学细节（破软骨细胞是否独立存在）书中一笔带过，只写"破软骨细胞，破骨细胞"。

## 原文摘录

> 「骨折软骨骨痂的钙化与生长板中软骨钙化的机制是一样的。」（基础 p.348）
