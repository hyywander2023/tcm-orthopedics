# 实验性骨折模型

选模型的第一件事不是选动物，是决定**要不要固定**。不固定→走二期愈合（有骨痂，可观察膜内与软骨内成骨）；固定→走一期愈合（无骨痂，只能看哈弗系统改建）。技术书给的经典家兔桡骨模型是**不固定**的，所以它产出的是骨痂数据。

## 一、经典模型：家兔桡骨中上 1/3 3mm 缺损

技术书的完整参数（技术 p.268–269）：

| 项目 | 参数 |
| --- | --- |
| 动物 | 健康成年家兔，体重 1.6～2.1kg |
| 数量 | 70 只（首批 40＋重复 30） |
| 术前 | 复合饲料喂养 2 周适应环境；术前 3 天剪净双前肢毛 |
| 麻醉 | 3% 戊巴比妥钠静脉注射，1ml/kg |
| 入路 | 沿桡骨前外侧纵行切开，钝性分离，暴露中上 1/3 骨干 |
| 骨膜 | 在桡骨弧形顶部切开骨膜 |
| 造缺损 | 改制三角形双锯片电动摆锯（锯片间距固定 2mm），锯成 **3mm 宽完全横断缺损** |
| 冲洗 | 生理盐水 |
| 关闭 | 逐层缝合 |
| **固定** | **术后肢体不需内外固定** |

几个设计上的狡猾之处：

1. **选桡骨而非尺骨**：兔桡骨与尺骨并行，切除桡骨 3mm 后尺骨仍维持肢体长度，形成"临界尺寸缺损"而不会短缩——这是它能作为标准模型的结构基础（本书未明说，属推论）。
2. **锯片间距固定 2mm 却锯出 3mm 缺损**：说明实际缺损由两刀叠加造成，不是一刀。复制模型时这个细节决定成败。
3. **切开骨膜**：主动破坏骨膜血供，使模型更接近临床的"软组织损伤型"骨折，而不是单纯的骨断裂。

## 二、不固定的后果：模型自带"二期愈合"属性

因为不固定，这个模型必然产生外骨痂、内骨痂、连接骨痂三种结构，正好对应 [[骨痂的形成与改造]] 里的三条时间曲线。若要研究一期愈合，必须改用加压钢板或外固定架模型（基础 p.352 提到狗的截骨加压钢板模型）。

## 三、异位诱导成骨模型

技术书还提到另一类模型：

> 植入一批实验动物的皮下，使得诱导性骨形成的过程开始于同一时间，并且可以选择性地研究全过程中某一阶段的变化，本模型的软骨细胞分化期具有类似于骨骺板软骨细胞分化成熟过程的特点，可以用来研究骺板软骨这方面的问题。（技术 p.265）

这个模型的价值在于**时间起点完全同步**——原位骨折的愈合起点受手术创伤、血肿大小影响，而异位植入的时间零点很干净。缺点是脱离了力学环境，只能研究生物学序列，不能研究应力影响。

## 四、对照组织

> 取家兔桡骨骨折模型标本（术后第 9、13、17、21 天），以小鼠肝作对照组织。（技术 p.265）

用小鼠肝作对照，是为了排除染色方法的非特异性背景（肝富含酶，是酶组化的通用阳性对照）。这个做法在今天的论文里已不常见（多用同种属阴性对照），但在方法学上仍成立。

## 五、选模型的三条判据

从本书材料可以归纳（**属整理，非原书直述**）：

| 研究目的 | 应选模型 |
| --- | --- |
| 骨痂形成、膜内/软骨内成骨序列 | 不固定模型（家兔桡骨 3mm 缺损） |
| 一期愈合、哈弗系统改建 | 加压钢板／截骨模型（狗） |
| 软骨细胞分化、骺板机制 | 异位诱导成骨模型 |
| 固定刚度的影响 | 可调刚度的外固定架模型（狗胫骨） |

## 六、缺口

- 小鼠、大鼠模型的参数本书未涉及（本书全部用家兔与狗）。
- 模型的伦理与样本量估算未讨论。
- 开放性骨折、感染性骨不连的模型未涉及。
