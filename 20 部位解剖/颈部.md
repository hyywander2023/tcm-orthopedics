# 颈部

颈部解剖的全部难点，可以压成一句话：**在一个直径十几厘米的柱状空间里，塞进了脊髓、椎动脉、臂丛、颈动脉、气管、食管、甲状腺、喉返神经和膈神经——而它们之间的相对位置，会随着仰头、转头、牵引而改变。**

**所以颈部手术的核心不是"记住层次"，而是"知道哪个动作会把哪个结构推到刀下"。**

## 一、骨：颈椎的三处特殊构造

### 横突孔与椎动脉的走行

> 「**椎动脉一般由第 6 横突孔进入**，向上经各颈椎横突孔，再经寰椎后弓的椎动脉沟入颅。横突孔内尚通过**椎静脉丛及交感神经网**。颈 7 的横突孔**只有椎静脉通过**。」（p.26）

三条实用推论：

| 事实 | 临床含义 |
| --- | --- |
| 椎动脉自 **C6** 横突孔进入（可有变异，可起于 C5、C4 或直接起于主动脉弓） | 颈椎前路手术在内侧剥离时，**C6 以上**要格外小心 |
| 横突孔内有**椎静脉丛** | 出血汹涌且难以电凝（静脉丛无瓣），是前路手术"莫名大出血"的常见来源 |
| **C7 横突孔只有椎静脉** | C7 横突可作为"安全参照"，但椎动脉若变异上行至此则不安全 |

### 钩突：既是"挡板"也是"压迫源"

> 「颈椎间盘因为**钩突的阻挡不易向外突出**。如钩突斜度过大，可向外使**横突孔狭小**，影响椎动脉的通过；如同时伴有上关节突过分前倾、颈椎假性滑脱、后纵韧带骨化、黄韧带增厚发生皱褶，就**更易引起血管与神经损害**。」（p.24）

这是颈椎病解剖学最精彩的一段因果链：

```
钩突阻挡 → 椎间盘不易向外侧突出（好）
钩突增生 → 横突孔变窄 → 椎动脉受压（坏）
        + 上关节突前倾 / 假性滑脱 / OPLL / 黄韧带皱褶
        → 血管 + 神经同时受损（更坏）
```

同页还给了一个定量观察：退变钩突可呈**尖刺状（32.6%）、蜂状（30%）、角块状（13.9%）**。**"尖刺状"占比最高**——这解释了为什么钩椎关节骨赘最易刺入椎间孔。

### 寰椎与枢椎：两个"不典型"的椎骨

- **寰椎**："前、后弓均上下扁平、**较为脆弱**"；侧块紧后方有**椎动脉沟**（p.28）。
- **枢椎**："上、下关节突呈前后位……两者以**峡部**相连，其间横突孔有椎动脉穿过，**峡部亦是骨折易发部位**"（p.30）。

**"寰椎前后弓脆弱"** 解释了 Jefferson 骨折（爆裂骨折）为什么表现为前后弓多处断裂——**环被压扁时，最薄的地方先断，而前后弓正是最薄处。**

**"枢椎峡部是骨折易发部位"** 解释了 Hangman 骨折（创伤性枢椎滑脱）——**而椎动脉恰从峡部旁的横突孔穿过**，所以这种骨折有合并椎动脉损伤的风险。

## 二、进钉：一个"四周都是禁区"的操作

p.25 给了一段极具体的参数，是本章最有操作价值的内容：

> 「关节突滋养血管在其内 **1～3 mm**，进钉时宜**由后内向前外倾 10°～15°，水平或向前上倾 10°～30°，或下倾 30°**。颈椎关节突负荷小，由此部位进钉其**抗旋转稳定性明显优于棘突钢丝固定**。但此处解剖关系复杂，**内侧有脊髓，前方有椎动脉及颈神经根**，操作时必须严格遵循解剖定位。」

把它画成一个"三面墙"的模型：

| 方向 | 墙是什么 | 距离 |
| --- | --- | --- |
| **内侧** | 脊髓 | 极近（椎弓根内侧壁） |
| **前方** | 椎动脉（横突孔）+ 颈神经根 | 数毫米 |
| **钉道内** | 关节突滋养血管 | **1～3 mm** |

**"滋养血管在钉道内 1～3 mm"这一条最容易被忽略**：它意味着**即使没有穿出骨皮质，也可能大出血**——血来自骨内，不是来自血管壁。**这类出血无法通过"看到血管再避开"来预防。**

而"抗旋转稳定性优于棘突钢丝"这半句说明了**为什么值得冒这个风险**：颈椎的旋转稳定性是内固定失败的主要模式，侧块/关节突螺钉在力学上确实更优。**风险与收益都写在同一段里，这是本书难得的诚实。**

## 三、软组织与分区：颈部的"三层信封"

第 1 章把颈部按**分区**讲（第四节），而不是按层次讲——这个选择本身有临床意义：

| 分区 | 主要内容 | 手术相关性 |
| --- | --- | --- |
| **颈前区** | 甲状腺、气管、食管、颈动脉鞘 | 前路颈椎手术的"通道" |
| **胸锁乳突肌区** | 颈动脉鞘、副神经、颈丛 | 颈淋巴结清扫 |
| **颈后区（项部）** | 枕下小肌群、椎动脉 V3 段 | 后路手术、枕颈融合 |
| **颈外侧区** | 臂丛、膈神经、前斜角肌 | 臂丛阻滞、锁骨上入路 |

**枕下三角**（由头后大直肌、头上斜肌、头下斜肌围成）是椎动脉 V3 段的所在地——**第 1 章专设"一、枕下小肌群"一节**，原因就是这块区域的解剖直接决定枕颈融合与椎动脉减压的安全边界。

## 四、体表标志：一条"中线偏右"的危险线

甲状腺手术与颈椎前路的经典安全线是"**从甲状软骨上缘到胸锁关节**"的切口路径，而这条路径上：

- **喉上神经**（在甲状腺上极附近）——损伤导致音调降低、误吸；
- **喉返神经**（在甲状腺下极附近，右侧绕过锁骨下动脉，左侧绕过主动脉弓）——损伤导致声音嘶哑；
- **膈神经**（前斜角肌表面，由外上向内下）——损伤导致同侧膈肌麻痹。

**注意左右不对称**：左喉返神经路径更长、更靠内，所以**左侧甲状腺手术的神经风险略高**；而右侧喉返神经更靠外，**在颈前路下颈椎手术中更容易被牵拉**。

## 五、手术显露的解剖约束

第 1 章第八节专讲"颈部手术显露途径"。前路（Smith-Robinson 式）的解剖约束可以归为四条：

| 约束 | 解剖基础 | 规避 |
| --- | --- | --- |
| **不能越过中线太多** | 对侧喉返神经、食管 | 保持在胸锁乳突肌前缘内侧 |
| **不能盲目向外剥离** | 颈动脉鞘、交感干（Horner 综合征） | 钝性分离、辨认颈长肌 |
| **C6 以上要防椎动脉** | 椎动脉自 C6 横突孔进入 | 术前辨认横突孔位置，必要时 CTA |
| **不能过度牵拉气管食管** | 喉返神经、术后吞咽困难 | 间歇放松、避免长时间持续牵拉 |

**"Horner 综合征"是前路颈椎手术最典型的"看不见的并发症"**：交感干位于颈长肌表面、颈动脉鞘后方，损伤后表现为上睑下垂、瞳孔缩小、面部无汗——**病人自己常先发现"一只眼睛变小了"。**

## 原文摘录

> 「横突孔由椎弓根、横突前后根及肋横突杆围成，多呈卵圆形。」（解剖 p.26）

> 「在颈椎椎弓板上缘与上关节面后下缘交界处有一骨性压迹，称为**椎板阻止沟**，系由于脊柱完全后伸时由上位椎骨的下关节突压迫所致。」（解剖 p.27）

> 「在此情况下，该水平同侧的上关节突可出现骨赘，使相邻横突孔变窄，而致**椎动脉和颈神经根受压**。」（解剖 p.27）
