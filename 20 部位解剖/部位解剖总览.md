## 这一部分的读法

**1. 先读那一句"核心矛盾"。** 每篇的引言都在给一句话——不是概述，而是**这一部位"最贵的那个约束"**。例如膝部"三个关节一个囊"、小腿"骨筋膜室是不能扩张的盒子"、足部"桁架"。**记住这一句，后面的数字才有归宿。**

**2. 再看表格，不看段落。** 部位笔记里所有可比的数值（角度、距离、百分比、发生率）都放在表格里。**段落负责解释"为什么"，表格负责回答"是多少"。**

**3. 每节末尾的"可执行规则"是全书最实用的部分。** 它们通常以"所以""因此""这条给出"开头，直接对应一个临床动作或一条手术禁令。

**4. 缺口一定要读。** 每篇末尾的"缺口"列出三件事：**原书在这一章哪里被切断了（页码与 OCR 硬伤）、哪里自相矛盾（并给出判断）、以及这一章完全没有讲什么（通常是一整个时代的技术空白）**。**引用前先看缺口，能避免大量误引。**

**5. 摘录只作"证据"，不作"结论"。** 所有 `> 「…」（解剖 p.N）` 形式的引文，页码均已回到 `#### p.N` 锚点核实；凡 OCR 破损、被版面切断、或明显有误处，均以 ⚠️ 标注并说明判断依据。

## 三条贯穿全书的线索

这三条线索在十七篇里反复出现，可以把它们当作"纵读"的索引：

### 线索一：血供的"入口位置决定命运"

| 部位 | 关键血管 | 后果 |
|---|---|---|
| 股骨头（[[髋部]]） | 支持带动脉（尤其外骺动脉） | 头下型骨折 → 坏死 |
| 股骨干（[[大腿]]） | 滋养动脉**逆血流上行**，供皮质内 2/3～3/4 | 中 1/3 骨折最易不连 |
| 距骨（[[踝部]]、[[足部]]） | **三角支是唯一能保命的动脉** | Hawkins Ⅲ 型坏死率 84%～100% |
| 足舟骨（[[足部]]） | 背部 3～5 支 + 跖内侧吻合 | Köhler 病多在 3～5 岁 |
| 第 2 跖骨头（[[足部]]） | 关节囊韧带内血管，**终支垂直、无侧支** | Freiberg 病 |
| 胫骨（[[小腿]]） | 三系统（髓内、骨膜、骨骺干骺）→ 骨折后"三套变一套" | 骨不连、骨筋膜室 |

**共同的模型**：**"终支供血 + 无侧支 + 骨内血管垂直走行 = 一旦栓塞即坏死"**。凡符合这三条的部位，都是骨坏死的经典位置。

### 线索二："不能扩张的盒子"

| 部位 | 盒子 | 后果 |
|---|---|---|
| 小腿（[[小腿]]） | 四个骨筋膜室，"类似颅骨腔" | 胫前间隙综合征（**足背动脉仍可触及**） |
| 踝（[[踝部]]） | 踝管（跗管） | 跗管综合征 |
| 腕（[[腕部]]） | 腕管 | 腕管综合征 |
| 肘（[[肘部]]） | 肘管 | 肘管综合征 |
| 大腿（[[大腿]]） | 收肌管、股神经的"纤维骨性隧道" | 隐神经/股神经绞扼 |
| 足（[[足部]]） | 跖骨深横韧带下、趾短屈肌内 | Morton 趾、趾足底神经卡压 |

**共同的规则**：**"切开顶盖即松解"**——踝部篇原话是"切开屈肌支持带即可松解"，七个字，适用于全部六个盒子。

### 线索三：三把"钥匙"与"总开关韧带"

每一个"联合关节"都有一条**切断后整个复合体就散开**的韧带：

| 关节复合体 | 钥匙 | 出处 |
|---|---|---|
| 膝（旋转稳定） | **内侧副韧带**（不是 ACL） | [[膝部]] |
| 跗横关节 | **分歧韧带**（跟舟部分） | [[足部]] |
| 距下关节 | **距跟骨间韧带**（+ 颈韧带） | [[足部]] |
| Lisfranc 关节 | **楔跖骨间内侧韧带** | [[足部]] |
| 腕（腕骨排列） | 舟月骨间韧带 | [[腕部]] |

**共同的规则**：**"钥匙"受伤 = 整个复合体失稳，而不是"一个关节松动"。** 这也是为什么"单一韧带损伤不引起旋转不稳"（膝部 p.947）——**只有"钥匙"级别的韧带断裂，才产生复合层面的不稳。**

## 关于引用纪律

以下四条是整理这十七篇时反复踩过、并已固化的规则：

1. **页码必须回到 `#### p.N` 锚点核实**，不得按上下文估算。历史上估算页码曾偏差 5～10 页，涉及数十处引文。
2. **引文被版面切断时不得补全**——只引到切断处，并加 ⚠️ 说明"主语/宾语在上一页"。
3. **临床通用说法（如"倾倒茶杯"、"Finkelstein"、"Thompson 试验"、"琼斯骨折"）若原书未使用，必须标明"非本书原文"。**
4. **同一部位多作者数据冲突时，必须带作者引用**，不可只给单一百分比；若原书并列两个不相容值，则两个都写并注明"原文如此"。

## 已知的整体缺口（适用于全部十七篇）

- **图片未搬入 vault**：原书插图（约 400 幅）仍在 `30 原文` 的扫描 PDF 中，笔记只保留了图号（如"图 16-3 距骨"）。
- **表格未还原为 Markdown 表格**：原书表格在 OCR 中多为图片或纯数字列，笔记中的表格是**从正文叙述重组的**，不是原表。
- **原书年代下限约 2000 年**：无关节镜、无导航、无 3D 打印、无生物制剂；多数部位笔记的"缺口"一节都列出了该部位对应的技术空白。
- **儿童内容普遍薄弱**：骨骺时间表虽全，但 Salter-Harris 分型、儿童特有骨折（Tillaux、三平面）几乎全无。
