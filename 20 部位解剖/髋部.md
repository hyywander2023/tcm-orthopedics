# 髋部

髋关节的设计可以用一句话概括：**它用"深"换稳定，用"长杠杆"换力量，代价全部记在血供和载荷上。**

> 「髋关节本身比较稳定，在尸体上即使**除去周围肌肉，也不易使股骨头脱位**。」（p.785）

肩关节靠肌肉，髋关节靠骨与韧带——这就是为什么"髋脱位"几乎总是高能量损伤，而"肩脱位"可以只是一次摔倒。但这份稳定有三张账单：

1. **血供账单**。股骨头的血管必须**贴着股骨颈、从关节囊反折处进入**。颈一旦断，血管随之断——"至股骨颈的动脉大部在关节囊的后方附着部进入，只有极少部分由股骨头韧带进入"（p.786）。这是股骨颈骨折后缺血性坏死的全部解剖学根源。
2. **载荷账单**。外展肌杠杆臂与重力杠杆臂之比约 **1:2.5**，所以单腿站立时外展肌要发出 **2.5 倍体重** 的力，而股骨头承受"至少为体重的 3 倍"（p.797）。**股骨颈、股骨距、假体柄，全都是为抗这个弯矩而存在的结构。**
3. **活动度账单**。"因髋臼很深，同时股骨头的关节面并非过大，故活动受限制，与盂肱关节相比，其运动范围相去远甚"（p.795）。所以髋的活动范围一旦丢失，人会用腰椎和骨盆去补——这也解释了为什么髋关节融合后"代偿机制为骨盆额状及矢状旋转增加"（p.797）。

下面每一节，都在这三张账单上做加减法。

## 一、髋骨：三块骨拼出来的一个臼

| 部分 | 构成髋臼的份额 | 力学角色 |
| --- | --- | --- |
| 髂骨 | 髋臼**顶**，占整个面积 **2/5** | 直立位的负重支点 |
| 坐骨 | 后壁和底，"同等大小" | 坐位时的负重支点 |
| 耻骨 | **1/5**，构成前壁 | 支撑点，防止两块髂骨向内靠拢 |

（p.731）

> 「坐位时，虽然身体的重量由坐骨结节支持，但**耻骨体及耻骨弓有固定坐骨结节的功用**，防止向内靠拢或向外分开。站立时，虽然身体的重量经髂骨传达到股骨，但**耻骨上支及耻骨体可以作为 1 个支撑点**，防止两块髂骨向内靠拢，在某些方面，**其功用与锁骨有些相似**。」（p.731）

这个"环"的比喻很有用：**骨盆前环（耻骨支）不是承重结构，是抗张结构**——它像锁骨一样，把两侧撑开、维持环的完整性。所以耻骨支骨折本身不威胁负重，但**双侧耻骨支骨折 + 后环完整 = 环还能用**，而**后环一旦失稳，前环再完整也没有意义**（与 [[骨盆及骶部]] 一节互补）。

### 髋臼的三等分与骨折风险

| 部位 | 厚度 | 功能 | 骨折所需暴力 |
| --- | --- | --- | --- |
| 上 1/3（臼顶） | 厚而坚强 | **主要负重区** | 相当暴力 |
| 后 1/3 | 较厚 | **维持关节稳定** | 相当暴力 |
| 下 1/3（内壁） | 最薄，"对着阳光观察，几乎透明" | 无 | 暴力较小 |

（p.731～732）

> 「髋关节后面与**坐骨神经**贴近，此部骨折移位或在手术时，神经易遭受损伤。」（p.732）

**三句话就把髋臼骨折的处理优先级排完了**：臼顶与后壁要解剖复位（负重与稳定），内壁可以保守（"对以后髋关节功能影响较小"），而后壁的每一毫米都关系到坐骨神经。

**Otto 骨盆**是一种极端情形："如髋臼呈弧形突入盆腔和股骨头深入髋臼，髋臼可向盆腔内突出"（p.732）——本质是髋臼软化 + 压力超出骨强度，与青少年的运动负荷或成人的骨质疏松相关。

### 髂骨为什么是取骨首选

> 「由于髂嵴**位置表浅，骨质厚而松，又具有肌肉附着多及血供丰富**等特点，常用于植骨取材。」（p.729）

三条量化支撑：

- **最厚处在髂前下棘与弓状线交点**，"髂骨截骨面最厚处，达 **2～3 cm**"；而"成人自髂前下棘到坐骨大切迹的距离，一般为 **6.4～7.4 cm**"——**截骨宽度不能超过这个数，否则植骨块无处安放**（p.730）。
- **滋养孔位置固定**：骶盆面与臀面各一个，"少数可为双孔、三孔或无孔"，位于弓状线内侧端的外后方，距髂前上棘、髂前下棘分别为 **7.98±0.71 cm** 与 **6.72±0.96 cm**；臀面者距髂前上棘和髂结节 **7.64±1.17 cm** 与 **5.88±1.3 cm**（p.730）。
- **两个供区各有主力血管**：髂骨翼主要由**髂腰动脉的髂支**供血，髂嵴前部由**臀上动脉深支上支、旋股外侧动脉升支及旋髂深、浅动脉**供血；"其中**旋髂深动脉**是施行游离髂骨移植比较理想的滋养血管"（p.730）。

### 髂骨骨髓炎：为什么"破坏出现晚、却容易蔓延到髋关节"

这是全书把"扁平骨"与"长骨"讲得最清楚的一段。

> 「不同之处是：**髂骨皮质甚薄，容易穿孔**，但因内外有**两层骨膜**，髂骨血管由髂骨内面进入后，向前、向下抵达髋臼形成簇状分支，具有**丰富的侧支循环**，所以**髂骨骨髓炎可蔓延至髋关节，但常无大块死骨形成**，即使有死骨也较易吸收。」（p.730）

"两层骨膜 + 侧支丰富" 导致三个临床后果：**① 无大块死骨（与长骨相反）；② 容易穿孔到髂窝、臀部或髋臼；③ X 线出现典型骨破坏和死骨的时间晚，常被误诊**（p.730）。

> 「相当于长骨的干骺端」的位置是"邻**髂嵴骨骺**的髂骨翼和**髋臼上缘**"（p.730）。**记住这两个位置，就记住了髂骨骨髓炎的好发部位与"为什么能进关节"。**

### 一个"骨性标志即综合征"的例子

> 「髂骨翼后外侧可出现圆锥形骨性突起，形成**髂骨角（iliac horn）**……也有时伴发中、外胚叶组织各种异常，称为 **Fong 病**。表现有**双侧拇指发育不良或不发育，髂骨和桡骨头发育不良**，髂骨上下径减小，骶骨呈弓形，**双侧髋外翻**，有些患者可出现**虹膜增宽**。」（p.729）

**指甲-髌骨综合征（Fong 病）的诊断，可能就始于一张骨盆片上的一块多余骨角。** 这与"看到髂骨角就想到拇指"是同一个动作。

## 二、颈干角与前倾角：两个"测不准"的角度

### 颈干角

| 项目 | 数值 |
| --- | --- |
| 幼童 | **160°** |
| 成人 | **125°**（范围 110°～140°） |
| 国人（孙启福） | 128.36°±0.34°（98.5°～146.0°） |
| 男性 / 女性（张怀韬） | 128.46° / 130.52°，**约 90% 在 121°～140°** |
| X 线测量（吴祖尧） | 男 131.4° / 女 134.3° |
| 髋外翻 | **>140°** |
| 髋内翻 | **<110°** |

（p.737～738）

> 「国人测量结果，各作者报告均较**欧美人稍高**。从生物力学观点来看，**男性由于通过骶股弓传来的负重力大于女性，股骨颈干角小于女性**。」（p.738）

**这是"同一参数，不同人群不同正常值"的典型例子**：直接套用欧美假体设计参数，在国人身上会偏内翻。

**床边判读法**（p.738）：自大转子尖端画水平线向内——与股骨头关节面交点**在股骨头凹之上 = 髋内翻**（颈短、大转子上移、股骨干上移）；**在股骨头凹之下 = 髋外翻**（颈长）。

### 前倾角：一个 50° 到 −20° 的"正常范围"

| 来源 | 数值 |
| --- | --- |
| 一般 | 平均 **13.14°**（男 12.20° / 女 13.22°） |
| 李学愚（1957） | **7.44°±0.5°** |
| 雷琦（1963） | 男 7.66° / 女 8.88° |
| Dunlap（1953，1524 具标本） | **+50°～−20°，平均 +11.2°** |
| Fabry（452 例正常儿童） | 1 岁 **32°** → 16 岁 **16°**，平均 24.14°±7.3° |
| 20 岁 | **8.02°** |
| 先天性髋关节脱位 | 平均 **+51°**，有的 **>+70°**，**健侧也增大** |
| 扁平髋 | 平均 **27.6°** |

（p.740～742）

> 「根据上表，可见**各家对股骨颈前倾角测量的数值有较大差异，系由于测量方法不一，特别是股骨颈轴的测量方法不同所致**。」（p.741）

> 「前倾呈 5°～10° 者占 25%，凡**超过 10° 即算不正常**，如**超过 15°，肯定为病理性**。」（p.742）

**两个必须记住的方法学陷阱：**

1. **前倾角随体位变化**。"股骨**内旋**时，股骨颈轴变水平位，**前倾角消失**；股骨**外旋**时，前倾角增大"（p.738）。所以任何前倾角的测量，本质上都是在测"当时的旋转位置"，不是测"骨头的形状"。这也解释了为什么"拍摄 2 张（尽量外旋/内旋）前后位片，正常时两张的颈干角仅稍有差别，应**小于 30°**；如前倾角超过 45°，两张的颈干角会明显不同，**此法不甚准确**"（p.765）。
2. **先髋的"前倾角增大"可能是结果，不是原因**。书里对股骨头骨软骨病做了这个反向推理："患儿的前倾角，有小部分（20%）高出 10° 或较多，**很难以此作为股骨头骨软骨病的原因**。相反，可能因为先有此病，随后引起前倾角轻度增高"（p.741）。**同样的谨慎应推广到先髋。**

**临床意义一句话**（p.742）："先天性髋关节脱位或早期严重婴儿瘫的患儿，股骨颈不再支持身体的重量，前倾角增大"——**前倾角是"负重史"的记录，不是固定的解剖常数**。

杨定焯的观察还给出了一个步态层面的解释："前倾角特大者，其股骨处于内旋位，很可能是'**内八字**'步态，而后倾角特大者，股骨处于外旋位，很可能是'**外八字**'步态"（p.740）。

## 三、股骨距：一条被反复误认的骨板

> 「**股骨距（calcar femorale）**是股骨上段大、小转子间的一块纵行骨板，上起于股骨颈后内侧，向下止于小转子下股骨内侧皮质，前附于股骨前内侧，向后外行于大转子，最后融合于大转子松质骨内。纵向上略呈弧形，突向髓腔，自上而下约呈 **16° 扭转角**。」（p.744）

**先解决一个"它到底是什么骨"的争论**：

> 「对股骨距的显微结构，文献上有不同描述，**戴克戎等曾认为是皮质骨结构，而 Stilcr 则认为是一种致密的松质骨**。横切面上，股骨距可分为 3 个区域：**近端**附着于股骨上段前内侧部分属于**皮质骨**……由此向外延伸，与股骨颈分离，其结构**介于皮质骨与松质骨之间**，可视为较致密的松质骨，**远端则完全为松质骨**。」（p.744）

**"两端不同"就是这场争论的答案**——不是谁错，是取样位置不同。这是读解剖文献时最常见的一类"矛盾"。

### 尺寸

| 参数 | 数值 |
| --- | --- |
| 纵向长度 | **5.1±0.7 cm**（4.5～6.1） |
| 宽度（三角形底边，小转子上方 1.0 cm 处） | **4.1±1.7 mm** |
| 上 / 中 / 下 宽度 | 4.7±1.8 / 3.2±1.5 / 3.0±1.2 mm |
| 相应厚度 | 8.6±3.2 / 7.2±1.9 / 5.2±1.4 / 4.0±1.6 mm |
| 距髁角（股骨距板状面轴线与内外髁轴线投影夹角） | **29.1°±12.4°**，与股骨颈前倾角**显著相关** |

（p.745）

### 为什么它能"减少弯矩"

> 「股骨距作为**股骨干后内侧骨皮质的延伸**，大大**缩短了股骨颈的实际长度**，明显减少了股骨颈干连接部的弯距……股骨距相当于**悬臂梁的根部**，是股骨上段偏心受载的着力点，为直立负重时**最大压应力部位**，同时也受到弯矩和扭矩的作用。」（p.746）

> 「力学测试显示，**保留股骨距的压缩强度 Σ 为 31.164×10.7 N/m²，去除后 Σm 为 23.912×10.7 N/m²，降低 40%，呈 45° 螺旋形断裂**。」（p.745）

⚠️ 原文"31.164×10.7 N/m²"的单位写法在 OCR 后已不可靠（指数形式混入），**只能引用"降低 40%、45° 螺旋形断裂"这两个定性结论，不要引用绝对数值。**

### 三条手术规则，全部从股骨距推出来

1. **内固定要贴股骨距**："股骨颈骨折，不管应用何种内固定物，应尽量**靠近股骨距**，以获得更大支持"（p.746）。
2. **假体要保留股骨距**："进行股骨头假体置换时，一般宜在**小转子上方保留股骨颈 1.0～1.5 cm**，并在**小转子偏前 1.0 cm 插入**，使**前倾角维持 10°～15°**，如此可完整保留股骨距，以避免股骨头假体下沉"（p.746）。
3. **它会在 X 线上"藏起来"**："股骨距在一般髋部前后位 X 线片上不容易看到，但如在投照时将**股骨外旋 30°**，即股骨距与 X 线片匣呈 **60° 以上交角**（外旋 30° + 距髁角 29.1°），由于股骨距的切面厚度明显增加，**股骨距可明显看出**"（p.745）。

**第 3 条是一个"用几何把结构转出来"的漂亮例子**：不是它不显影，是它平行于射线。**拍不到，不等于没有。**

### 一个反常的事实：骨质疏松"绕开"股骨距

> 「随年龄增大……Singh 根据压力骨小梁和张力骨小梁的不同分布，将骨质疏松分为 6 度，但**股骨距疏松出现较晚也较轻**。老年人及绝经后妇女股骨颈骨折虽然发病率很高，**但多发生在股骨距的上下方，股骨距多保持完整**。」（p.746）

**所以"负重大的骨反而疏松慢"**——这直接支持"内固定贴股骨距"的策略：全髋周围都疏松了，只有它是可靠的锚点。

## 四、骨小梁：是桁架，不是起重机

传统比喻是"路灯架"（Ward）或"起重机"（Culmann），书里明确反对：

> 「根据股骨颈额状面推论，内负重系统存在压应力及拉应力，但这与路灯架或起重机的静力不同，**经髋关节负重的应力在不同运动及姿势中必然存在变化**，同时**股骨并非牢固地固定在 1 个部位**……对髋关节的运动机制来说，**螺旋拧紧较喻为杠杆更为合适**。」（p.747）

更本质的批评：

> 「**将骨骼这样的弹性结构分成压应力及拉应力是人为因素。**所谓拉应力及压应力板层均承受改变的压力或张力，不管骨是否在压力之下，如压力去除，被一种弹回过程代替，则**压力与张力关系倒置**，内、外侧板层均主要为压力性。」（p.747）

**这不是修辞上的挑剔，而是读片陷阱的来源**：

> 「在**髋外翻**时，通过 X 线检查，压力曲线变为致密而张力曲线减少甚至消失；但在**髋内翻**时，压力曲线减少而张力曲线显然增加，甚至超过压力曲线，**这并不代表板层数目实际的增减**……这种板层数目的变异**仅为错觉**，其在 X 线下的表现，**取决于股骨颈的旋转程度**。」（p.747）

**换句话说：X 线上的"骨小梁增粗/消失"，有一半是在看旋转，不是在看骨量。** 这与前面"前倾角随体位变化"是同一类错误。

### 拱结构

> 「裘世静通过偏光显微镜及电镜观察，发现**大量骨小梁呈拱结构，其杆轴为曲线**……**拱结构无弯距或很小，更为合理**。在纵向载荷下可产生水平推力（反力），能减少拱体所受弯距，而**主要承受轴向压力，并使剪应力转化为压应力**。股骨头颈部拱结构有的为双曲或多曲……**无论是正中或偏心受力，都会在拱状骨小梁中转化为均匀分布的压应力**。」（p.742）

> 「股骨头软骨下的拱结构主要为**朝向关节面的多向排列**构筑，其远侧即使骨小梁呈纵向排列，也是朝向关节面……**多方向相互连接形成的拱结构，犹似建筑工程上的桁架结构，但更为复杂**，是以交叉编织、相互套叠的方式将骨端松质骨连成一体。」（p.743）

**"偏心受力也变成均匀压应力"这一句是理解股骨头为什么能承受 3 倍体重的关键**——它不是一根柱子，是一组互相套叠的拱。

配套的一条关节力学观察：

> 「髋关节……呈**轻度不吻合**状态。在最初承载时，股骨头仅**周缘部与髋臼接触**，只是随载荷增加而使股骨头与髋臼完全吻合，从而使压应力均匀传导，说明**只有在无载荷下呈轻度不吻合才能更好传导载荷**。」（p.743）

**"松的时候接触面小，加载后接触面变大"**——这与"关节面对称、完全吻合才最好"的直觉相反。**不吻合是设计，不是缺陷。**

## 五、血供：一套贴着骨面走的血管

### 来源与"环"

> 「供应股骨头、颈的血管主要有**旋股内、外侧动脉，闭孔动脉，臀上、下动脉及股深动脉第 1 穿动脉**等……自股深动脉发出，围绕股骨颈根部，共同组成**囊外动脉环**。这两条动脉是供应股骨近端的一级血管，**旋股内侧动脉组成环的内侧、后侧和外侧部，旋股外侧动脉组成环的前部，此环仅有 1/10 的人是完整的**。」（p.747）

**"只有 1/10 完整"** 是后面所有"血供脆弱"论述的前提。

### 三组支持带动脉

| 组 | 起源 | 位置（从内侧看，钟点） | 特点 |
| --- | --- | --- | --- |
| **后上** | 旋股内侧动脉 | **11 及 2 点钟之间** | **最大、最重要**，"偶而为骨骺的仅有血供来源" |
| **后下** | 旋股内侧动脉 | **5～7 点钟** | 与后上"大小一致" |
| **前** | 旋股外侧动脉 | 股骨颈前面 | **最小，最不恒定** |

（p.753）

> 「支持带动脉**位于滑膜之下，有时位于滑膜反折皱襞内**，在其行程中发出许多支至股骨颈，与骨干滋养动脉相吻合……**后上支持带动脉不穿入骺软骨，但在其周围越过骺软骨板而朝向股骨头中心**。」（p.753）

**注意"支持带"这个名字的用意**：

> 「支持带动脉即关节囊动脉，后一名词**易被误解为动脉走行于纤维性关节囊内**，因而采用支持带动脉这一名词，可以强调**与股骨颈周围支持带纤维相关**。」（p.753）

**这是全书里"命名纠错"最有价值的一处**：说"关节囊动脉"，会让人以为切开关节囊就切断了它；说"支持带动脉"，才知道它贴的是**滑膜反折**——所以**保留滑膜 = 保留血供**（p.789："股骨颈骨折时，如滑膜完整，对于骨折的愈合将起良好作用"）。

### Judet 的四组与"上组最重要"

| 组 | 走行 | 供应 |
| --- | --- | --- |
| **上组** | 经股骨颈上缘进入，起于旋股内侧动脉（或其与旋股外侧、闭孔、臀下动脉的吻合） | 头的 **2/3 或 3/4**（= Trueta 的"外侧骨骺动脉"）；"几乎所有股骨颈的松质骨可单独由上组动脉供应" |
| **下组** | 沿关节囊附着处走行，分**外下群**（小，供皮质）与**内下群**（供头下 1/3～1/4 及颈下内部） | 下部皮质 |
| **颈前、后动脉** | 行程不规则 | **不供应松质骨，仅终于皮质**，形成周围网 |

（p.754）

### 头凹动脉：一个"年龄依赖"的争议

| 年龄 | 是否进入股骨头 |
| --- | --- |
| 出生时 | 有时可看到，但"出生后 4 个月，正相当股骨头骨化中心出现时期，**骨骺的血供不由其供给**" |
| 幼儿期（4 月～4 岁） | **不参与** |
| 中间期（4～7 岁） | **仍不参加** |
| 少年前期（7～10 岁） | 伸入骨骺，与外侧骨骺动脉吻合 |
| 12～14 岁 | 骨化中心扩展至头凹，**始进入股骨头内** |
| 成人 | 进入率 **约 70%**；"成人头凹动脉进入股骨头内者约为**儿童的一倍**，血管直径平均 **0.326 mm**，其大小较儿童增加约 **80%**" |

（p.752～753、p.757）

> 「Trueta 认为，在供应股骨头 3 组动脉中，从出生到 3～4 岁，股骨头韧带动脉**不参与**股骨头的营养。4 岁后，干骺血管重要性减少，最后消失，而**股骨头韧带动脉亦尚未参与，惟一血供为外侧骨骺动脉**。」（p.753）

**这句话是本章最重要的一句临床推论**——见下节。

⚠️ 关于头凹动脉的价值，书里给了**四种互相冲突的立场**（Hyrtle 认为不进入骨内；Schmorl 认为 2 岁起生理性闭塞；Wolcott 认为儿童不进入、10 岁后始进入；Trueta 认为 8～9 岁参与），最后自己的小结是："股骨头韧带动脉对股骨骺仅为小的次要血供来源，**在儿童为 33%，成人为 70%**，随年龄增加，其口径亦增加"（p.757）。**读这段要注意：同一个结构，五个人五种结论，原因是注射技术不同。**

## 六、发育期血供五阶段：为什么 4～7 岁是危险窗

| 阶段 | 年龄 | 主要来源 |
| --- | --- | --- |
| 1 | 出生时 | 干骺动脉 10～15 个纵行向上，形成下干骺动脉及**外侧骨骺动脉**；有时可见头凹动脉 |
| 2 | 4 月～4 岁 | 骺动脉越骺板 + **外侧骨骺动脉亦甚重要**；头凹动脉不参与 |
| 3 | **4～7 岁** | **干骺血供减少至可忽略**（被骺软骨板所阻）；**外侧骨骺动脉为惟一来源**，位于头的后外侧；头凹动脉仍未参加 |
| 4 | 7～10 岁 | 头凹动脉伸入，与外侧骨骺动脉吻合；干骺动脉仍不供应 |
| 5 | 10～17 岁 | 17 岁骨骺愈合，具备成人 3 组来源 |

（Trueta 1957，p.751～752）

> 「儿童骨骺较成人更加依赖于支持带动脉，**4～7 岁时因股骨头韧带动脉缺如，干骺动脉也可缺如或发育不良**，这可说明儿童的缺血性坏死更为常见。Trueta 认为此时**惟一剩留的外侧骨骺动脉如因损伤或炎症被阻塞，即可发生 Legg-Perthes 病**。」（p.791）

**这就是"窗"的含义**：不是 4～7 岁的孩子更容易受伤，而是**这几年里，股骨头只有一条血管**。

配套的两条加固证据：

- **解剖上的"窄"**："在 **3～10 岁，股骨颈中部前侧及内侧血管较少**，这可能是容易产生股骨头缺血性坏死的原因"（p.752）；"儿童的**关节囊壁肥厚**，关节囊与大转子之间的间隙甚为狭窄，**外侧颈升动脉容易遭受损伤**而引起栓塞"（p.752）。
- **体位上的"压"**："**后上组动脉在髋关节强力外展及外旋时容易遭受髋臼及盂缘的压迫**，更易发生 Legg-Perthes 病"（p.791）。

**由此得到一条可执行的安全位**：

> 「**手法复位轻轻伸展内收肌、股骨作 45° 外展时，对支持带动脉可视为安全位**。如内收肌很紧张，**切断肌腱较应用股骨颈后上面作为支持点强力牵引似对股骨头血供更为安全**。」（p.791）

> 「正常关节固定于完全**外展、外旋位**亦可发生碎裂，但**关节不固定时不会发生**。」（p.791）

**"固定 + 外展外旋"才致病，"外展外旋"本身不致病**——这是把"体位"与"持续压迫"区分开的经典推理。人位石膏（hip spica）治疗 Perthes 的并发症，解剖学根源就在这里。

## 七、X 线：一套互相校验的定位系统

髋部 X 线不是"看一张片子"，而是**一组互证**：一条线破了，还有另一条。

### 七条线、一个三角、一个点

| 名称 | 定义 | 异常的读法 |
| --- | --- | --- |
| **Shenton 线** | 闭孔上缘与股骨颈内侧的连续弧线 | 弧线中断、外侧升高 = 向上脱位 |
| **Calve 线** | 股骨颈外侧与髂骨外缘形成的弧 | 同上 |
| **髂嵴连线** | 两侧髂嵴相连 | 通过 L4/5 间隙者 40.27%（女 55.36%）；通过 L4 下 1/3 者 35.58% |
| **Hilgenreiner 线（Y 线）** | 连接两侧髋臼 Y 形软骨 | H（干骺端顶点至该线垂距）正常 **1 cm**；D（交点至髋臼底）正常 **1.2 cm**；α（髋臼顶切线）正常新生儿 **30°** |
| **Perkin 线** | 自髋臼顶外缘所作垂线，与 Y 线分四象限 | 正常股骨头在**下内象限**；股骨颈喙突在**下外 = 半脱位**、**上外 = 完全脱位** |
| **Ombredanne 垂线** | 自髋臼外上缘向下垂线 | 正常在骨骺**外侧**；有脱位倾向时**经过骨骺** |
| **泪滴（Köhler U 像）** | 外半圆线（髋臼壁）+ 长直内缘（小骨盆侧壁）+ 短弓形线（髋臼切迹） | **a、b 线距离 = 骨性髋臼厚度，幼童约 3 mm**，先髋时加大 |

（p.763～768、p.769）

> 「婴儿的髋关节病变有时很不容易发现。投照时，如果两下肢位置不对称，一侧稍外旋，股骨颈显得较短，**可能被误诊为脱位，仔细观察 Shenton 线即可排除**。」（p.758）

**Shenton 线最实用的时刻，恰恰是"片子拍坏了"的时候。**

### 角度参数

| 参数 | 正常值 | 判读 |
| --- | --- | --- |
| **髋臼指数**（髋臼角） | 1 岁以下 **30°**；1～3 岁 **25°**；3 岁以上 **20°**；正常新生儿平均 **27.5°**，2 岁 **20°** | **>30° 多示脱位**；>25°～29° 即不正常；男性比同年龄女性小 **1°～4°** |
| **CE 角**（Wiberg） | 正常约 **30°**；3 岁至成人 **20° 为正常最小值** | **<20° 易脱位**；"CE 角越小，越容易脱位" |
| **Sharp 角** | 泪滴下缘连线与泪滴外缘-髋臼上缘连线夹角 | 显示髋臼倾斜度 |
| **ACM（Idelberger）角** | 髋臼上下缘中点垂线与中心连线夹角 | 小儿 Y 软骨闭合前 44.41°～49.97°；成人 42.83°～48.75°；**<50° 视为正常**，无性别差异 |
| **股骨头指数 r/R** | 正常 **50°** | 先髋时减小 |

（p.764～767）

### 一套"多参数联动"的儿童髋测量

> 「在骨盆及股骨上端正位片，可测量 **CDA**（颈干角）、**ATD**（关节转子间距）、**TTD**（转子间距）、**ALD**（关节小转子间距）、**CSD**（头心至小转子间距）、**FND**（股骨颈直径）及 **FHD**（股骨头直径）。儿童患髋与健侧比较，如 **CDA 相差 ≥10°、ATD ≥10 mm、TTD、ALD 及 CSD ≤5 mm，即被视为异常**。」（p.764）

**注意这个"≤5 mm 也算异常"**——因为 TTD/ALD/CSD 在正常情况下两侧应当**对称**，任何一侧缩小都意味着大转子相对上移。

还有一条量化风险：

> 「如髋臼位置即**髋旋转中心位置的高度及水平距离超过 30 mm，脱位的危险可能提高 4.1 倍**。」（p.764）

### 内侧关节间隙的"7 mm 规则"

> 「正常成人 CE 角应大于 20°，**内侧关节间隙加宽显示髋关节有半脱位**，CE 角减小。在任何年龄，**正常髋关节内侧关节间隙宽度不应超过外侧关节间隙 7 mm**。如股骨头与髋臼关节面圆周不相平行，则表示股骨头中心外移。」（p.766）

**这是一个不需要量角器、只需要比较左右与内外的判据**——在内侧间隙变化还不明显时，它比 CE 角更容易看出来。

### 一个"以髋测全身"的副产物

髂嵴骨化中心的出现与愈合，被用来判断**脊柱侧凸是否还会进展**：

> 「Risser 报告，**髂嵴骨骺骨化完成与椎骨骨化的完成同时发生，是时脊柱侧凸曲度变为稳定**。」（p.734）

> 「**髂嵴骨骺愈合时间较髂嵴骨骺完全出现对脊柱侧凸的预后更具有意义。脊椎骨骺环的愈合与髂嵴骨骺愈合的时间相当**。」（p.735）

还有一条更"民间"的用途：

> 「据 Bauhe 及 Pyle 报告，髂嵴骨化中心出现为 12.7 岁，**月经初潮期亦为 12.7 岁**，示指远节指骨骨骺愈合平均年龄为 12.5 岁，三者年龄相当，故**可以示指远节指骨的骨骺愈合年龄来判断一个儿童是否已进入青春发动期**。」（p.734）

⚠️ 但刘惠芳的数据与之不符（女性 13 岁、男性 15 岁出现；指骨骨骺最早愈合女 14、男 15）。**"一个指标替代另一个指标"的结论，在不同人群里可能整体平移 1～2 岁。**

## 八、骨性标志：三条线、一个三角、一个点

| 标志 | 做法 | 正常 | 异常 |
| --- | --- | --- | --- |
| **Nélaton 线** | 髂前上棘至坐骨结节的连线 | **经过股骨大转子** | 大转子升至该线**之上**（脱位、股骨颈骨折） |
| **Bryant 三角** | 髂前上棘垂线 + 大转子尖端垂于此线的线 | Bryant 线长约 **5 cm** | 线缩短、髂转子角减小 |
| **Shoemaker 线 / Kaplan 点** | 两侧髂前上棘与大转子连线向前腹壁延长，相交点 | 位于**脐部或脐以上** | 移至**脐以下** |
| **髂转子角** | 髂前上棘至大转子连线与两髂前上棘连线夹角 | **30°** | 改变 |

（p.769）

> 「这种测量虽然有时因**坐骨结节不易清楚摸得**，但在**设备简陋条件下**，对于检查尚能有些帮助。」（p.769）

**这句自评很重要**：这三条线在 X 线普及后已基本退居"无法拍片时"的备选，但它们背后的几何（大转子是否上移）仍然是判断"短缩发生在颈还是干"的核心。

> 「这样的测量虽然对下肢长短有所估计，但**不能鉴别长度的缩短系由股骨颈或由股骨骨干的病理变化所致**。要寻找它们之间的差别，必须另以**股骨大转子**做为起点再作测量，才能判明病源之所在。」（p.770）

### 三个"平面"标志，跨系统通用

- **髂嵴最高点 ≈ L4 棘突**（p.768）。
- **髂后上棘 ≈ 第 2 骶椎水平，适对骶髂关节的中点，同时相当于蛛网膜下腔的末端**（p.769）——**一个标志，三个系统**（骨科定位、骶髂关节、麻醉平面）。
- **坐骨结节下端与小转子在同一平面**，且"是股方肌及大收肌坐骨部的分界线"；**尾骨尖实际位于坐骨结节平面之上**，"约在肛门后 3～4 cm 处"（p.769）。

### 一个被忽略的体位陷阱

> 「某些病理情况下，因为患肢强直被固定于**内收位**，为了站立或行走，**骨盆必须向患侧提高**，这样患侧下肢就显得较短。这种错觉是因为**只测量了脐部至内踝的距离**，如果再比较两侧髂前上棘至内踝尖的距离，就会发现**两侧真正的长度是一样的**。」（p.770）

**测量起点决定结论**——脐不是中线恒定的点，髂前上棘才是。

髋关节结核的体位演变是这条原理的活标本："最初患肢**外展**，骨盆向患侧降低，患肢显得较长。以后……患肢由外展变为**内收**，患侧骨盆提高，患肢显得较短"（p.770）。**同一个病，早晚期一长一短，纯粹是骨盆倾斜方向变了。**

## 九、臀部软组织：一条神经的"六个固定点"

### 臀上皮神经：组成比教科书更杂

> 「一般认为，臀上皮神经来自 **L1～3 后外侧支**，据作者观察（1982），亦可来自 **T11～12 或 L4** 后外侧支，其中以**发自 T12 至 L3 神经者最为恒定**。」（p.770）

| 参与神经 | 出现率（左/右） |
| --- | --- |
| T11 | 30% / 20% |
| **T12** | **90% / 90%** |
| **L1、L2** | **100% / 100%** |
| L3 | 83% / 73% |
| L4 | 13% / 10% |

（p.770）

支数：1～6 支；**4 支最多占 50%**，5 支 30%，6 支与 3 支各 10%（作者观察）；苗华的统计则是 **3 支型最多（55.75±3.77%）**，2 支型 26.44%，4 支型 14.94%。**同一结构，两组数据的主型正好相反**——这是"样本来源不同"的典型。

### 穿出点：一个可以量出来的位置

> 「大致可以说，**竖脊肌的外缘与髂嵴的交点或其稍内侧为臀上皮神经自腰背筋膜后层穿出部位**。苗华观察，在**髂嵴上缘与竖脊肌外缘相交点内、外 20 mm 的范围内**，是臀上皮神经比较集中通过的部位，占 **93.35±1.15%**。」（p.771）

**"交点内外 2 cm"是一个可以直接用手指量出来的窗口。**

### 为什么它容易被卡：六个固定点 + 一条骨纤维管

> 「臀上皮神经在越过髂嵴进入臀部时，被坚强的由竖脊肌及腰背筋膜在髂嵴上缘附着处形成的**扁圆形骨纤维性管固定**，神经即由此隧道穿过，其中来自 **L3 和 L4** 的皮神经通过隧道翻越髂嵴者分别占 **71.26±4.85%** 和 **19.54±4.25%**。……这种骨纤维性管虽有保护神经免遭受压的作用，但**如此管变形、缩窄即能压迫神经**，或**腰部急性扭伤时，被牢固固定的神经受到牵拉**，即可引起损伤，但**不致于出现"筋出槽"**。」（p.772）

> 「脊神经后外侧支在整个行程中共有 **6 个固定点**，均可能是臀上皮神经易受压迫、遭致损伤的部位。」（p.772）

**这一段同时给出机制和一次"纠错"**：老百姓说的"筋出槽"，解剖上是**一条被骨纤维管固定住的皮神经被牵拉**——它不会"跑出去"，只会被拉伤。**承认机制，否认说法**，这是本书处理民间术语的一贯态度（与"倾倒茶杯""Finkelstein"等处的处理一致）。

> 「臀上皮神经入臀后，继续在浅筋膜中走行，**可达大腿后面下端，疼痛可串至腘窝**。」（p.772）

**这就是"臀上皮神经综合征"能被误诊为坐骨神经痛或腘窝囊肿的原因。**

### 血管的体表投影：两条线各取一段

| 血管 | 投影 |
| --- | --- |
| **臀上动脉** | 髂转子后线的**内、中 1/3 交界处**；或"由坐骨结节向上作纵垂线与髂嵴相交点所引一线之中点" |
| **臀下动脉** | 髂后上棘至坐骨结节连线的**下、中 1/3 交界处**；或"坐骨结节至大转子连线内、中 1/3 交点的**内侧约 1 cm**" |
| **坐骨神经** | 髂后上棘至坐骨结节连线上中 1/3 交界 → 大转子尖引线，其**内中 1/3 交界**为穿出处 |

（p.769～770、p.778、p.781）

**臀上动脉是本章最"致命"的一条血管**：

> 「在施行骶髂关节手术，操作进行至坐骨上切迹时，注意勿损伤臀上动脉，**因动脉被切断后往往向盆腔缩回，必要时可紧急剖腹，在腹膜后结扎髂内动脉，否则患者会因大量出血而死亡**。」（p.780）

**"向盆腔缩回"是这条血管的特殊性**——它从骨盆里穿出来，断端会缩回去，你在臀部找不到它。这与 [[骨盆及骶部]] 中"臀上动脉断裂需开腹结扎髂内动脉"是同一条，两处都写，说明这是本书认为最需要警惕的。

### 臀大肌：一块"位置决定功能"的肌

> 「臀大肌的主要功能为后伸和外旋髋关节。**髋关节伸直时，臀大肌位于髋关节矢状轴的下方，可协助内收；屈曲时则位于矢状轴的上方，又能协助外展**。」（p.774）

**同一块肌，屈髋时外展、伸髋时内收**——因为它在矢状轴的两侧"换边"。这是"肌肉功能取决于相对关节轴的位置"最干净的例子。

**臀肌挛缩的"蛙式位"**：

> 「臀大肌挛缩时，**不能在中立位进行屈髋，只有在外展外旋位使挛缩的肌纤维放松时，出现蛙式位才有可能屈髋**。」（p.774）

> 「对重症臀大肌挛缩，**单纯切断挛缩索带或 Z 形切断延长效果常不佳**，原因是术后仍残留病理索带，新的粘连和纤维变性。因此，需要将**深层一切挛缩组织包括臀中、小肌挛缩彻底切断松解**，还需将**髋外旋肌近止点处切断**和**切开挛缩的关节囊**，必要时甚至**在大转子上缘切断髂胫束**，才能取得满意松解效果。」（p.774）

**"单纯切一条带子不管用"的原因，是挛缩不止一条。** 这是"解剖层次决定手术范围"的范例。

### Trendelenburg 征的力学账

> 「臀小肌的支持力约为 **142 kg**，臀中肌约为 **130 kg**。所有朝上朝内肌肉（耻状肌、闭孔外肌、臀中肌、臀小肌及旋外肌）联合力估计为 **500 kg**，则臀中、小肌约担负 **60%**。一侧下肢站立，站立侧臀中、小肌能防止骨盆朝对侧下倾。在一体重为 70 kg 的成人，**臀中肌单独牵引力为 210 kg**，这一肌肉的效力**如减少 1/3，骨盆将不能平衡**。」（p.777）

⚠️ 原文这些"kg"是**力的量纲混用**（把肌力直接写成千克），不能当作精确值引用；但"**效力减少 1/3 即失代偿**"这个比例是可以用的——它说明**外展肌的储备只有约 1/3**，这也是为什么"大转子上移 1 cm"就足以让步态崩掉："这种情况系由于**大转子上升，肌纤维松弛**，遂使臀肌收缩无力"（p.777）。

## 十、梨状肌与坐骨神经：变异多到不能"按典型做"

> 「梨状肌大部起于**第 2～4 骶椎前面骶前孔外侧**……几乎充满坐骨大孔……出盆处宽度为 **39 mm**，在臀部的长度平均为 **93.66±10.02 mm**。」（p.777）

> 「梨状肌和肌腱常因坐骨神经的穿过而被分隔为**完全的二肌腹二肌腱（6%）、不完全的二肌腹一肌腱（24%）或一肌腹二肌腱（1%）**。」（p.777）

**约 1/3 的人梨状肌与坐骨神经的关系"不标准"。**

三个"变异要点"：

1. **坐骨神经可能在骨盆内就分成胫神经与腓总神经**，然后各走各的孔。赵集中的一例："两侧坐骨神经均在骨盆内就分为胫神经与腓总神经，其中**胫神经通过上、下梨状肌间隙，而腓总神经在臀中肌骨盆束与上梨状肌之间出骨盆**"（p.778）。
2. **臀下神经"经常与坐骨神经的腓总神经部分一同穿过梨状肌，甚至有时与臀上神经及腓总神经一同出梨状肌上孔"**（p.781）。
3. **股后皮神经**与梨状肌的关系"变化甚多，其情况大致同坐骨神经"，张怀韬分为 6 型：Ⅰ 型总干出下缘 76.38%、Ⅱ 型总干穿梨状肌 2.10%、Ⅲ 型总干出上缘 0.50%、Ⅳ 型两根均出下缘 3.52%、Ⅴ 型一根出下缘一根穿肌 15.58%、Ⅵ 型两根分别穿上、下缘 2.01%（p.785）。

**这些变异的临床结论只有一句**：**梨状肌不是"安全带"，是"变数区"。** 臀部注射、髋后路手术、梨状肌综合征的诊断，都不能假设标准解剖。

一条易被忽略的"占位"：

> 「在梨状肌腱止端的下方与髋关节囊之间，约 **5±2.18% 可见大小不等的滑膜囊，其炎症能刺激梨状肌而使其挛缩，引起坐骨神经痛**。」（p.777）

**"梨状肌综合征"里有一小部分，责任病灶其实是一个滑膜囊。**

### 梨状肌上下缘：一张"谁从哪里出去"的清单

| 出口 | 内容 |
| --- | --- |
| **梨状肌上缘** | 臀上动脉、臀上神经 |
| **梨状肌下缘** | 臀下动脉、臀下神经、坐骨神经、阴部内动脉、阴部神经、股后侧皮神经 |

（p.778）

**"上缘两条、下缘六条"**——这就是为什么**后路髋手术的安全区在梨状肌上缘以上**，而下方的一切操作都要先找到坐骨神经。

## 十一、髋关节：稳定性来自哪里

### 与肩的六点对照

> 「①髋关节**主要功能为负重**，盂肱关节主要功能为运动；②构成髋关节的骨骼**大而坚强**，构成盂肱关节的骨骼则细而脆弱；③围绕髋关节的肌肉**较大且较坚强**……但对关节稳定来说，**肌肉对髋关节远不如对盂肱关节重要**；④髋关节本身比较稳定，在尸体上即使除去周围肌肉，也不易使股骨头脱位；⑤**髋臼较肩胛骨的关节盂为深**……因外伤而引起脱位的机会远较盂肱关节为少。」（p.785）

**这张表的价值在于第 ③④ 条的"矛盾"**：肌肉更大更强，但肌肉对稳定的贡献更小。原因在下面这句：

> 「治疗髋关节的原则，主要为**恢复其稳固性**，如能同时兼顾运动，则效果更为满意。」（p.785）

**髋的手术，稳定优先于活动**——这与肩关节手术"活动优先"的原则正好相反。

### 关节囊：前面全包、后面只包 2/3

> 「关节囊近侧附着于髋臼缘、髋臼唇及髋臼横韧带，远侧在前面止于**转子间线**，向下达于小转子，后面在**转子间嵴内侧约 1.25 cm**，相当于股骨颈外中 1/3 交界处，故**股骨颈前面全部皆在关节囊内，而后面只有内侧 2/3 在关节囊内**。」（p.786）

**"1.25 cm"是本章最该记住的一个数字**：它决定了股骨颈骨折是**囊内**还是**囊外**：

> 「从股骨颈骨折发生的部位来说，**股骨头下骨折和颈中骨折位于关节囊内，而基底骨折位于关节囊外**，前 2 种骨折如果移位较多，**支持带及股骨头的血供均被断绝**，不仅愈合困难，且易发生股骨头缺血性坏死；基底骨折一般移位较少，**除由髓腔来的滋养血管断绝外，支持带血管大多保持完整**，故骨折愈合多不成问题。」（p.804）

**"囊内/囊外"不是解剖学名词的游戏，是"血管在不在囊内被撕断"的同义词。**

### 四条韧带的"分工"

| 韧带 | 起止 | 限制 |
| --- | --- | --- |
| **髂股韧带**（倒 V 形） | 髂前下棘及其后 2 cm 的髋臼缘 → 转子间线上、下部（外歧/内歧） | **后伸**；**内歧限制外展**；**外歧限制外展和外旋** |
| **耻股韧带** | 髂耻隆起、耻骨上支、闭孔嵴及闭孔膜 → 关节囊及髂股韧带内侧部 | 过度**外展及外旋** |
| **坐股韧带** | 髋臼后部与下部 → 大转子根部及轮匝带 | **内收及内旋** |
| **轮匝带** | 关节囊深部环行纤维，绕股骨颈中部 | 扶持（"仅股骨颈后部纤维较浅"） |
| **股骨头韧带** | 髋臼切迹及髋臼横韧带 → 股骨头凹 | "其功能甚难确定"，"在人类是**退化残余**的构造" |

（p.786～788）

**髂股韧带的尺寸会变，这一点很少被提到**：

> 「髋关节在中性位时，髂股韧带两歧长度在正常生理张力下分别为 **12 cm 及 8 cm**，股骨**外展 24°** 时，两歧变短并松弛，其长度分别为 **10 cm 及 5.5 cm**。」（p.787）

**"外展 24° 就松了 1/3"**——所以外展位牵引容易复位，而伸直位（韧带最紧）容易再脱位。这也解释了下一条：

> 「在髋关节所有动作中，**除屈曲外，髂股韧带均维持一定紧张状态**。整复髋关节脱位时，即利用此韧带作为**支点**。」（p.787）

### 髋关节复位的"四步"全部基于韧带张力

> 「在股骨颈骨折时，亦可利用髂股韧带进行整复，首先**加大外旋**，使交锁的骨折断端离开，同时**中度牵引**，使膝屈曲同时使髋**外展**，此动作可**紧张 Weitbrecht 支持带**，松弛任何可使远侧断端牵引向上的肌肉，并**松弛髂股韧带两歧**，随后在**外展牵引位内旋**，应用**支持带的合页作用**使骨折复位。复位后，再维持**内旋、内收**，使髂股韧带及髋部肌肉紧张，保持复位。」（p.787）

**这套动作的每一步都在改变某一个结构的张力**：外旋 → 解开骨端交锁；外展 → 松髂股韧带；屈膝 → 松股后肌；内旋 → 靠支持带合页扣上；内收 → 收紧韧带维持。**复位不是"拉回来"，是"依次放松再依次收紧"。**

### 为什么脱位总是往后下

> 「根据髋关节周围的韧带配布，可以发现**关节囊的内下侧与后下侧比较薄弱，股骨头脱位往往在此处发生**。关节囊在**屈曲、内收及轻度内旋时最为松弛**。」（p.788）

而**股骨头靠什么留在臼里**？

> 「其有无保持股骨头于髋臼的作用，仍属疑问，因后者**主要靠负压维持**。」（p.788）

**"负压"这个词解释了为什么髋关节脱位后会出现"真空现象"（vacuum phenomenon），也解释了为什么麻醉下复位比清醒时容易——肌张力一松，负压一破，球就出来了。**

### 关节内几个"被忘掉的结构"

- **哈弗腺（Haversian gland）**："在髋臼的非关节面部分，通常为**移动性脂肪**所占据，随着关节内压力的增大或减少，移动性脂肪**在屈曲时被吸入，而在伸直时又被挤出**，以维持关节内压力的平衡"（p.785）。**它是一个压力缓冲器，也是一个"复位后必须回位"的结构**——它卡在关节间隙里，就是"关节内游离体"的鉴别诊断之一。
- **Weitbrecht 支持带**："髋关节的滑膜构成皱襞……内侧与外侧皱襞恒定，前皱襞不恒定。这些皱襞具双重作用，一方面是**血管的径路**……另一方面又可作为**关节内韧带**"（p.789）。
- **穿刺点**："前侧宜在**腹股沟韧带下方及股动脉外侧**，后侧宜在**髂后下棘及大转子连线中点稍外**进入"（p.789）。

### 感觉神经：为什么髋病会"膝盖痛"

| 方位 | 神经 |
| --- | --- |
| 前 | **股神经**（主要来自耻骨肌支，其次股四头肌支）、**闭孔神经** |
| 后 | **臀上神经**、**坐骨神经**（经股方肌支） |

（p.793）

> 「总的来说，**髋关节大部由闭孔神经供给**，由于闭孔神经**亦同时支配膝关节**，因此有髋关节疾病的患者也往往感觉**膝关节疼痛**。」（p.793）

> 「髋关节结核的患者早期呈**屈曲及外展**畸形，在此位置，**关节囊最松弛**，但以后因闭孔神经受到刺激而变为**内收**畸形，在此位置**最易脱位**。」（p.793）

**"早期外展屈曲（囊最松）→ 晚期内收（最易脱位）"** 这一对变化，是"疼痛→肌痉挛→体位→再脱位"的完整链条。

闭孔神经的变异程度值得单独记一句：

> 「据 Polacek 的意见，**90% 的闭孔神经参与髋关节的神经支配**」；但"来自闭孔神经的关节支**有 40% 在闭孔管的近侧发出**"（Wertheimer），而 Larochelle 发现"起自闭孔神经本干者仅为 10% 左右，起自前支者占 7%，起自后支者占 **77%**，**闭孔神经不发支至髋关节者占 16%**"（p.793）。

**所以"切断闭孔神经治髋痛"的效果"并非完全一致"——16% 的人根本没有这条支。**

## 十二、活动度与"内旋扣紧"

| 运动 | 正常范围 | 主动肌 | 限制结构 |
| --- | --- | --- | --- |
| 屈曲 | **150°** | 髂腰肌、股直肌、缝匠肌、耻骨肌、臀中/小肌前部 | 屈膝时最大；**伸膝时只能 80°**（股后肌紧张） |
| 伸直 / 过伸 | 0° / **15°** | 臀大肌、股后肌、大收肌坐骨部 | 髂股韧带 |
| 内收 | **30°** | 各内收肌 | 髂股韧带外歧、关节囊上部 |
| 外展 | **45°** | 臀中/小肌、臀大肌上部、阔筋膜张肌、缝匠肌 | 耻股韧带、髂股韧带内歧 |
| 内旋 | **40°** | 臀中/小肌前部、阔筋膜张肌 | 屈髋时：坐股韧带 + 关节囊后部螺旋纤维；伸髋时：髂股韧带内歧 |
| 外旋 | **60°** | 梨状肌、闭孔内肌、上/下孖肌、股方肌、闭孔外肌、臀大肌后部、内收肌上部、缝匠肌 | 髂股韧带外歧 |

（p.795～796）

> 「髋关节**外旋肌较内旋肌数量多，力量强**，这是因为在**直立及行走行程中，需要采取八字姿势，使身体更好保持稳定**。」（p.796）

**外旋 60° > 内旋 40°，不是巧合，是直立的需求。** 这也解释了为什么"内旋受限"是髋关节病变最早、最敏感的体征（而外旋总是保留较多）。

### "螺旋拧紧"：一个比杠杆更好的模型

> 「将股骨标本直立，两髁放于水平面，如对股骨头关节面施加压力，**股骨将内旋**，这说明**股骨即使无肌肉、韧带管制，其对负重的反应表现为内旋扣紧**。股骨内旋时，髋关节因髂股、耻股及坐股韧带交锁，紧张围绕，此时**伸髋的稳定需肌肉力量最小**。」（p.797）

> 「髋关节的运动机制决定于：①**股骨对纵向负重的自然反应为内旋**；②内旋的交锁借**适当的关节面**而维持；③内旋受髋关节周围的**韧带**所限制；④在骨盆、股、胫骨之间，旋转的主要管制借**肌肉相互作用**。」（p.797）

**这段的实用价值**：膝关节"最后扣锁"（screw-home）不是膝独有的，**髋也在同步内旋扣紧**。"在膝关节伸直最后阶段，当股骨在胫骨上向内旋转，最后扣锁时，此动作在**髋关节也有反应**，表现为内旋扣紧"（p.797）。**所以膝的旋转畸形会改变髋的受力，反之亦然。**

### Massie 活动指数

> 屈-伸 155°×0.462 + 外展-内收 70°×0.3 + 外旋-内旋 85°×0.2

> 「如屈曲挛缩为 30°，活动范围为 45°～150°（总数 105°），其屈-伸指数为 **105×0.4 = 42%**（较正常 62 少 20）。」（p.796）

⚠️ 原文的权重在小数位上前后不完全一致（0.462 与后文 0.4），**只能用来做"同一患者前后对比"，不能当作绝对评分**。

### 融合后的代偿

> 「一侧髋关节融合后，其代偿机制为**骨盆额状及矢状旋转增加，健侧髋关节活动增加，患侧膝关节在所有步态中屈曲均增加**。如患者较年轻，腰椎、健侧髋关节及患侧膝关节活动良好，而且两下肢等长，被融合的髋关节**不过分内收**，则步态较好。」（p.797）

**四个条件，全是可术前评估的**——这是"关节融合术病人选择"的解剖学清单。

## 十三、载荷：2.5:1 的杠杆，3 倍体重

> 「由于**重力至外展肌的杠杆臂长度与重力至股骨头中心杠杆臂长度之比约为 2.5:1**，因此在单腿站立时，**外展肌必需有 2.5 倍于体重的力**才能维持骨盆稳定。在步态站立相时，估计**股骨头载荷应为外展肌与体重之和，至少为体重的 3 倍**，直腿抬高时，施加于股骨头的力量相等。**抬腿、跑步及跳跃时，载荷约为体重的 10 倍**。」（p.797）

### 力的方向

| 参数 | 数值 |
| --- | --- |
| 髋关节受力 R | 体重的 **2.7～3 倍**，通过股骨头中心，**由上内向下外** |
| R 与身体垂线 V 的夹角 | **16°** |
| 股骨轴线 A 与 V 的夹角 | **7°～9°** |
| R 与 A 的夹角 | **25°** |
| 股骨颈长度 | 约 **10 cm** |

（p.761）

> 「R 对股骨颈产生弯矩，在其**内侧产生压应力，外侧产生张应力**，由于 R 斜行作用于股骨颈，可以产生**剪应力**，其大小决定于 **R 与 A 的倾斜度**，**髋关节内翻时剪力大，但外翻时剪力小**。」（p.761）

**"内翻剪力大、外翻剪力小"** 这一句，是后面所有"外翻截骨"的逻辑起点。

### Pauwels：把"愈合难"变成一个角度

> 「如 **P > S**，骨折断端之间产生明显的压力，骨折**易于愈合**；相反，如 **P < S**，断端之间产生**剪力与张力**，骨折**愈合困难**。」

| 型 | 力学状态 |
| --- | --- |
| Ⅰ | 关节力产生断端间**功能性压缩** |
| Ⅱ | 主要产生**剪力**，压力较小 |
| Ⅲ | 产生**明显剪力和张力** |

> 「后 2 型均属不稳定骨折，通过**转子间截骨，改变骨折线的倾斜度**，使断端主要产生压应力，将有利于骨折愈合。」（p.762）

**手术目标被量化了**：

> 「对股骨颈骨折打钉时，术前在骨盆正位 X 线片上，标出人体纵轴线（V），作 a 线与 V 线垂直，b 线为骨折线，a、b 2 线相交即 **Pauwel 角（α 角）**。**尽量矫正 α 角，使其 ≤25°**，可在骨折线形成压应力。」（p.762）

> 「**Pauwel 角越大，剪力越大，压力越小，骨折越不容易愈合**。」（p.804）

### Garden 分型：用"骨小梁对线"而不是"移位毫米"

> 「在髋关节正位 X 线片，股骨头颈**压力骨小梁系统与股骨干内侧皮质约呈 160°～170° 角**，在侧位片上，股骨头、颈小梁方向一致呈直线，**应为 180°**，Garden 根据上述 2 个角度变化判断股骨颈骨折移位程度将其分为 4 类：①**不完全型**；②**完全型，但未移位**；③**完全型，部分移位，但两断端仍相接**；④**完全移位**。」（p.804）

**Garden 的高明处在于：它测的是"骨小梁还连不连"，而不是"移位多少毫米"。** 因为决定预后的不是位移，是**支持带是否还连着**：

> 「股骨颈骨折移位在很大程度上决定于**外旋肌的牵引及 Weitbrecht 支持带的完整性**。支持带由滑膜反折形成……骨折时，**支持带作用如同书夹，骨折底部敞开，如同书页**。」（p.804）

**"书夹"这个比喻极准确**：书脊（后下方）没断，书页还能合上；书脊一断，整本书散开。

### 三个"数字之外"的预后因素

1. **骨折线与骨干的夹角**："如骨折线与骨干纵轴呈**锐角（<40°）**，移位显著；如此角度大，移位中等度，不足以引起支持带动脉断裂，**后一种骨折较前一种更易愈合**"（p.792）；"Eyre-Brook 报告股骨颈骨折患者，**14.7% 有缺血性坏死者其骨折线与骨干纵轴呈角均 <37°**"（p.792）。
2. **复位手法本身会造成损伤**："采用**大重量牵引**进行复位时，由于可使原移位时处于松弛状态的外侧骨骺动脉受到牵扯，**造成更多损伤，因而增加了股骨头坏死机会**"（p.792）。
3. **负重与塌陷的关系**："**早期负重不是促成股骨头坏死的主要因素，但负重与头的塌陷则有直接关系**。当坏死的股骨头在修复期，其爬行替代过程尚未完成时，负重可造成头的塌陷"（p.792）。

**第 3 条把"坏死"和"塌陷"分成了两件事**——血管决定是否坏死，负重决定坏死之后是否塌。这是本章少有的、把因果链拆开讲清楚的地方。

## 十四、全髋假体：所有参数都是杠杆的算术

> 「在髋关节炎时，**体重与外展肌杠杆臂之比可为 4:1**。在无痛性步态，**重心移向患髋，重力杠杆臂缩短，2 个杠杆臂之比可变为 1:1**。理论上讲，这将**减少髋部整个载荷多达 30%**。」（p.798～799）

**这是"止痛本身就是一种治疗"的力学解释**：疼痛 → 步态改变 → 重心外移 → 杠杆比恶化 → 载荷增加 → 更痛。**打破这个环，载荷自动下降 30%。**

### Charnley 的四步构思

> 「Charnley 全髋关节假体的主要构思是**加深髋臼，造成股骨头中位，缩短重力杠杆臂**并在**大转子截骨后重新固定而延长外展机制杠杆臂**。这样由体重产生的力矩降低，而由外展机制需施加的抗衡力也减少。」（p.798）

**四个动作，两个目的**：缩短重力臂（内移旋转中心）+ 延长肌力臂（外移大转子）。

### 颈长与颈干角：一对反向的取舍

| 参数 | 变化 | 后果 |
| --- | --- | --- |
| 颈长（30～42 mm；原始 Charnley 约 35 mm） | **越长** | 杠杆臂/弯矩越大 → **易弯曲断裂**；肢体延长，有时达 **2.5 cm** |
| 颈干角 | **>140°（外翻）** | 弯矩减少、柄轴向载荷增加；但**过度外翻** → 下肢负重力线改变 → **膝部外翻扭伤**；还可能使髋向上脱位呈内收位（尤其髋臼杯纵向时） |
| 颈干角 | **内翻** | 弯矩增大；**外展肌杠杆臂加长**（看似有利），但**增加柄松动及失败**、股骨缩短、易脱位 |

（p.800）

> 「一般说，**轻度外翻位较内翻好，但颈干角不要超过 140°**。」（p.800）

**"外展肌杠杆臂加长"在理论上好，在工程上坏**——因为它是靠把柄放进内翻位换来的。**解剖上的"更有利"与力学上的"更危险"，在这里正好相反。**

### 柄长：应力遮挡 vs 水泥柱支持

> 「一般认为**长柄**很好固定于干骺端及骨干，有倾向将载荷从干骺端及股骨近端转移，**由于应力遮挡而产生骨质疏松**，结果使近侧水泥柱减少支持；相反，**短柄**可使载荷更多转移至股骨近侧及干骺端的水泥柱，这样可避免应力遮挡，**但可使骨水泥节裂及继发性柄部件的失败**。」（p.800）

**"长柄防松动、短柄防遮挡"是一个没有免费选项的取舍**——这也是为什么"柄长"至今没有统一答案。

### 头径：一个"活动度 vs 磨损"的对照

> 「与 **22 mm** 小头配套的杯深度较头半径为大，其**颈与杯的撞击只允许 90° 活动**，而用 **32 mm** 直径的头，其颈与配套杯的直径几乎相等，头颈直径比例较大，臼杯提供充分包容，**可允许 106° 活动**。颈呈卵圆形或梯形者可作 **116°** 屈伸运动。」（p.801）

> 「小头用的杯较厚，虽然臼较小但其外径相同，**较厚的杯磨损较大**，吸收能量亦较大，并使应力更均匀分布于周围骨。」（p.801）

**"22 mm 更耐磨"这个说法被数据修正了**："长期随访直径为 22 mm 的头并不较 32 mm 者磨损更大"（p.801）——**磨损主要不看头径，看杯厚与接触应力。**

### 柄断裂的位置，可以算出来

> 「如果部件全长均用骨水泥牢固固定，则**最大张应力区靠近或在从头颈中心划线与假体下半外侧缘交点处**……如果柄部件**近侧 1/3 未很好受到支持**，最大张应力区离坚强固定很短距离，柄部件将在此处断裂。如**仅柄部件远侧牢固固定**，则断裂更容易发生在**最远侧水平**，柄部件承受**悬臂梁力**。」（p.800）

> 「**股骨柄假体骨折总发生在其前外侧**。」（p.797）

**"总是前外侧"是因为冠状面与矢状面同时受力，前外缘同时承受扭力与最大张应力。** 这是"力学计算结果与临床统计一致"的一个漂亮例子。

## 十五、股骨颈骨折与脱位：两条不同的缺血路径

### 骨折

> 「股骨颈的上下径较前后直径大 1/3，老年人因骨质疏松，**股骨颈中部密度减低区或 Ward 三角以及水平面的骨小梁在体积及结构上均为股骨颈最软弱区**。轻微外伤，如平地滑倒，大转子着地，或患肢突然扭转，都可引起股骨颈骨折。」（p.803）

**Ward 三角 = 最弱点**，这与"股骨距是最强点"是同一张图的两端。而"老年人骨折多经股骨距的上、下端"（p.746）——**最强的骨反而成了骨折线的边界**。

### 脱位：三种类型的机制

| 类型 | 体位 | 股骨头去向 | 特殊损伤 |
| --- | --- | --- | --- |
| **后脱位**（最常见） | **屈曲、内收、内旋** + 强大外力 | 向后上，停留于坐骨切迹以前的髂骨翼上 | 可挤压**坐骨神经** |
| **前脱位** | **外展、外旋、过度伸直** | 前下方，朝向髂耻隆起，甚至耻骨结节 | 可压迫**股动、静脉** |
| **坐骨型** | 极度**外展**，大转子抵髋臼缘为支点 | 穿过关节囊下部，骨盆后方紧贴坐骨背面 | 大腿**内收、内旋**畸形；外展肌群可保持完整 |
| **闭孔型** | 屈曲 + 强度**外展、外旋** | 前下方，闭孔前方 | 大腿**外展、外旋、伸直**畸形 |

（p.804～805）

> 「不管何种类型髋关节脱位，由于**关节囊被部分撕裂，股骨头韧带亦多被撕脱，骺动脉必然受到一定损伤**，致使股骨头血供不足，如未及时复位，有可能发生股骨头缺血性坏死。」（p.805）

**一个反直觉的事实**：

> 「在损伤性髋关节脱位，**股骨头韧带必然切断**，其所引起的**缺血性坏死较股骨颈骨折为少**，故股骨头韧带动脉虽然在大部分病例供应股骨头，但一般仅作为其他动脉的补充。」（p.790）

**"韧带断了反而坏死少"**——因为它断的是一条"补充"血管，而支持带还完整。**这直接证明：决定预后的不是断了几条，是断了哪一条。**

## 十六、先天性髋关节脱位：一个"逐级发生"的病

> 「先天性髋关节脱位的发病率约为 **0.15%**，女多于男，约为 **5～9:1**……**约 10% 有家族史**，亦常伴有其他骨-肌肉系统异常，如**斜颈及马蹄外翻足**等。」（p.806）

> 「出生时如仔细检查，包括 **Ortolani 及 Barlow 试验**多能发现并易于复位，但**出生后 3～6 月即难以复位**，患儿因有**内收肌挛缩**，患髋外展受限，臀部皮肤皱襞可不对称，患侧股骨短缩，行走时出现**鸭步步态**。」（p.806）

**"3～6 个月"是本章给出的第一个时间窗**。为什么是这个时间？答案在后面：

> 「在 **1 岁末或 2 岁开始时，由于行走，髋臼变浅，其深度为中部直径的 3/10，而在正常新生儿，应为 5/10**。在半脱位时，**球窝的改变并非原发，更非致病原因，而系股骨头骨骺对球窝施加压力减少的结果**。」（p.806）

**"深度从 5/10 变成 3/10"** 是"用进废退"的量化；而**"球窝改变是继发的"** 这一判断，直接决定了治疗方向——**先复位，让压力回来，臼会自己长深**。

> 「所谓 **Putti 三联症**即出生后不久**球窝变浅**、1 岁后**股骨头骨骺移位**、稍后**股骨头骨骺发生变形**。」（p.806）

### 病理改变的五条线

| 结构 | 改变 |
| --- | --- |
| **髋臼** | 球窝缩小、增生；髋臼缘游离缘朝向窝内，在窝上部下缘形成**横位新月形穹窿**；**枕部（pulvinar，窝底围绕股骨头韧带的脂肪垫及结缔组织）肥厚**并覆盖月状面一部 |
| **股骨头** | **所有直径均减小**，后内侧扁平；"作蕈状，有时甚至与股骨颈完全消失，仅在大转子内侧遗留一个小突起" |
| **股骨颈** | 一般**髋内翻**（可减至直角），但**亦有时髋外翻**；颈缩短；**前倾角显著增大，股骨头直接朝前，几呈 90°** |
| **骨盆** | 双侧者：上口呈**横卵圆形**（横径增大 15 mm 或更多）、耻骨弓变扁、**骨盆矢径减小**；单侧者：两侧不对称，**脱位侧较低、腔隙较大** |
| **关节囊及韧带** | 在髋臼上缘形成**"管"及其峡部**；"关节囊壁随脱位上升而愈益加厚，**有时甚至可达 1 cm 或更多**"；下部形成**"关节袋"** |

（p.807～808）

**"关节囊增厚到 1 cm"和"峡部"是复位失败的两个直接原因**——不是骨头拉不回来，是**软组织把路封住了**：

> 「**髂腰肌腱围绕关节囊的前壁，紧压髋臼边缘，作环状，更使缩窄加重**。」（p.808）

> 「**关节囊不附着于股骨颈而附着于骨骺，将妨碍股骨头的复位**。」（p.808）

### 一个"阶段论"的总结

> 「先天性髋关节脱位的病理变化**并非一次形成，而系从胚胎期到出生后一系列继发改变的结果**，一般经过**髋关节发育不良、脱位前期、半脱位而至完全脱位**阶段，其中有的可以**停留在某一阶段甚至自愈**。临床上所以出现许多不同表现及病理变化，**主要系不同阶段的不同表现，不是一成不变**。」（p.809）

**"可以停留在某一阶段甚至自愈"** 这句话，是"新生儿髋臼发育不良可以观察"的解剖学依据，也是"过度治疗"和"延误治疗"两种错误同时存在的根源。

### 一个容易误诊的影像

> 「先天性髋内翻……X 线显示，患儿**股骨头颈骺线呈垂直状，其外侧有一与之平行的透光带，并在透光带下方有一三角形骨块，可误认为股骨颈骨折**。」（p.809）

**"垂直骺线 + 平行透光带 + 三角骨块"三联**，是先天性髋内翻与股骨颈骨折的鉴别点——一个是发育异常，一个是创伤，处理完全不同。

## 十七、股骨头骨骺滑脱与 Perthes 病

### 滑脱：X 线上的百分比很"软"

> 「股骨头骨骺滑脱……好发于 **12～17 岁**……患者多有跛行，**髋关节屈曲时多呈外旋**，甚至在外旋姿势下行走。」（p.801～802）

| 征象 | 比例 |
| --- | --- |
| 正位：骺板加宽而不整齐 | **82%** |
| 正位：头的干骺缘清楚 | — |
| 正位：髋部普遍性萎缩 | **72%** |
| 正位：向下或向内滑脱明显 | 仅 **68%** |
| 正位：头颈下连接处骨膜反应增生 | **71%** |
| 侧位：股骨头向后移位 | **98%** |
| 侧位：颈前缘变直 | 69% |
| 侧位：后连接处骨膜反应 | 79% |

（p.802）

**正位片最敏感的征象只有 68%，侧位片有 98%**——**"正位正常"不能排除滑脱。** 这是本章最实用的一条影像警示。

> 「在正位 X 线像上，**自 3 岁以后至成年，股骨颈上缘近侧延长线将经过股骨头**。此分割线在前后位像上，**诊断早期股骨头骨骺滑脱甚为重要**。」（p.759）

**"线不经过股骨头"就是滑脱**——这是所有滑脱筛查里最简单的一条。

### Perthes：一个"分期决定预后"的病

| 期 | 表现 |
| --- | --- |
| Ⅰ | 有症状，但**无 X 线表现** |
| Ⅱ | 放射前期表现，但无明显改变 |
| Ⅲ | **弥漫性空隙、硬化或囊肿** |
| Ⅳ | **股骨头外形断裂，出现死骨**，但关节间隙正常 |
| Ⅴ | 外形扁平，**关节间隙变窄，头萎陷** |

（p.803）

**髓蕊减压的长期效果**（Fairbank 1993，90 例 128 髋，15 年随访）：

| 期 | 1 年 | 5 年 | 15 年 | 不需进一步手术者 |
| --- | --- | --- | --- | --- |
| Ⅰ | 100% | 96% | **90%** | 88% |
| Ⅱ | 85% | 74% | **66%** | 72% |
| Ⅲ | 58% | 35% | **23%** | 26% |

（p.803）

> 「尽管一般有效，**仍有 56% 的髋病程进展 1 级**，髓蕊减压术能**延迟**对全髋置换术的需要。」（p.803）

**"延迟"而不是"避免"**——这个措辞比任何成功率都诚实。

**术中/穿刺的判据**：

> 「经大转子插入套针，如**静止压超过 3.99 kPa（30 mmHg）可视为异常**，注入 5 ml 生理盐水应力加压，如**压力上升达 1.33 kPa（10 mmHg）或以上，或维持 5 min 以上**可视为异常。静脉造影 5 min 后，**臀血管仍充盈不良、骨干返流及造影剂清除延迟**。」（p.803）

## 十八、一个"关节软骨版本"的骨关节炎

> 「关节内软骨**正常无血液供应，一旦血管进入软骨，将转变为纤维组织或骨组织**。」（p.810）

> 「骨关节炎病变**并不发生在负重区，而是发生在非负重区**……在**非负重区**，由于新血管可以穿入软骨，因此转变为骨，形成**骨刺**；相反，在**负重区**，关节面并无新骨形成，关节间隙减小，直至完全消失。」（p.810）

> 「髋关节骨性关节炎中，**71% 股骨头的非压力区显退化，而仅 3% 局限于压力区**，其余 26% 同时发生于 2 个区域。」（p.810）

**"71% vs 3%" 直接推翻了"磨损致病"的直觉**：

> 「软骨退化**最常见于关节承受最少应力与应变部分，而非由于不断磨损引起**。**压力缺乏较过多压力更易引起软骨退化**。」（p.810）

> 「软骨需要**不断使用及受到压迫**才能维持功能……**压力与休息的交替对关节软骨的适当营养是不可少的**，但如关节压力过大或持续时间过多，将妨碍软骨的体液交换与正常代谢，促进退化。」（p.810）

**所以骨关节炎不是"用坏了"，是"营养坏了"**——而这个营养既需要压力、又怕过量压力。**"适度使用"在这里第一次有了机制层面的定义。**

配套的结论："关节软骨退化与年龄无直接关系，**将这种退化笼统称为老年性退化不合适**"（p.810）。

> 「在髋关节骨关节炎，**股骨头均发生囊肿，限于压力区的上面**，在象牙关节面深部致密骨内，囊肿甚少单发，常有几个，呈杯状或梨状。」（p.811）

> 「骨关节炎病变严重者**并非是软骨退化，而是由于新生骨刺及过度血供，使本已软弱的结构承受更多负担**。」（p.812）

**"骨刺不是敌人，是修补失败的痕迹"**——这个视角把"切除骨刺"从治疗目标里剔了出去。

## 十九、手术入路：三条路线，一个共同风险

| 入路 | 关键步骤 | 优点 | 风险 |
| --- | --- | --- | --- |
| **前侧（Smith-Petersen）** | 缝匠肌与阔筋膜张肌之间 → 髂骨翼骨膜下剥离 → 切断股直肌直头及反折头 → 骨膜下推开耻骨肌 | **显露广泛，下肢可任意活动**；用于开放复位、融合、置换、结核清除 | **股外侧皮神经**（髂前上棘下方 10 cm 处寻出）；**股动脉**（"在髋关节有疾患时，其位置往往外移"）；旋股外侧动脉升支（髋关节下 4～5 cm） |
| **外侧（Hardinge，大转子前方部分切骨）** | 臀中肌**前 2/5 与后 3/5 之间**纵行切开肌膜；骨膜剥离器分开臀中肌；前方凿断大转子厚约 **5 mm** | **保留臀中肌前侧与股外侧肌的连续性**，切骨块不会上下移动，很少不愈合；保留关节囊与外旋肌 | **臀上神经**（"在臀中肌深面中 1/3 走行，在**大转子上方 4 cm 以内**分离一般比较安全"） |
| **后侧 / 后外侧** | 沿臀大肌外缘至大转子底，再沿臀纹延伸 8～10 cm | **解剖层次少、显露迅速**，后上部显露好；适合后部结核、陈旧后脱位、人工股骨头 | **离肛门近，可致大肠杆菌感染**；需改变体位（屈髋时困难） |

（p.814～819）

### 大转子截骨"为什么不愈合"——一个完整的解剖学解释

> 「大转子血供从**上方及内、外侧**进入，在松质骨内形成丰富的血管网，但**与股骨颈及股骨干的血管网分离**，从**转子窝至股方肌结节由内上斜向外下有一分界线隔开，其间只有少量血管吻合**。此分界线**正相当于大转子发育时期的骺板**，大转子属**牵引骨骺**。」（p.817）

> 「Churchill（1992）对尸体死后 48 h 内应用血管灌注技术……发现**甚至在骨骺愈合后，大转子与相邻骨干间仍少血管吻合，两者之间似存在一个相对缺血界面**，在这种情况下，大转子的血供必然**主要依靠骨外血管**。」（p.818）

四个失败因素叠加：

1. 截骨线**正相当于缺血界面**；
2. 可能**损伤旋股动脉分支**，剩下只有臀动脉分支，"显然不足"；
3. 术中**扩髓或置入骨水泥**进一步破坏血供；
4. 再植部位为**疏松皮质骨区**。

> 「因此，目前**仅对比较困难或翻修者才采取大转子截骨**，以避免出现合并症。」（p.818）

> 「在进行全髋置换术时，由于显露需要，经常需凿断股骨大转子，**术后 4%～26% 病人可出现各种合并症**，如滑膜囊炎、截骨固定物断裂、大转子上移及髋外展无力等。」（p.817）

**"缺血界面"这个概念值得推广**：骨的血供不连续，不等于"到处都有吻合"。**大转子是一个被血管分界线围起来的"孤岛"，而截骨线正好画在这条分界线上。**

### 打钉的角度

> 「打钉的部位可在大转子下缘，亦即在**股外侧肌起点下 4～5 cm** 进行。由于股骨颈的颈干角有很大不同，因此进钉与股骨骨干所成的角度亦不一定，一般在 **35°～45°** 之间，虽然前倾角正常为 12°～15°，但因**手法整复内旋的结果，前倾角已缩小或甚至为零**。」（p.818）

**"复位之后前倾角就不再是 12°～15° 了"**——这是本章第三次提醒"角度随体位变"，也是术中导航/透视必须重新测量而非套用正常值的原因。

## 二十、缺口

**本章的边界与硬伤：**

1. **第一节的开头不在本章文件里**。第 12 章起于 p.727，但"第十二章""第一节 构成髋部的骨骼"两个标题及 p.727 全部正文，被切到 `11 第11章 手` 文件的末尾。本章文件从 p.728 的图题起头。
2. **p.728 只有图题**；**p.739、p.751、p.794 等页为整页图**，无正文；**p.822 起为参考文献**，p.824 起已是**第十三章 第一节 股骨干**，p.825 全是股骨滋养孔内容。**本章实际正文止于 p.822。**
3. **表 12-1～12-8 全为图片**：表 12-1（髂嵴骨化中心年龄）、表 12-2/12-3（髂嵴骨骺与脊柱侧凸）、表 12-4（股骨上端测量）、表 12-5（各家前倾角）、表 12-6（正常与骨软骨病的颈干角/前倾角）、表 12-7（支持带动脉口径）、表 12-8（幼儿髋臼角）——**数值全部不可读**。这也是为什么本章只能引"某作者某数值"而不能做横向对照表。
4. **没有任何 Tile/AO/Letournel-Judet 髋臼骨折分型**。书里给了 Judet 三个投照位与六条线（髂耻线、髂坐线、泪点线、臼顶线、前唇线、后唇线），却没有把这些线接到分型体系上。**读得出"前柱断了"，读不出"这是哪一型、该不该手术"。**
5. **没有 Letournel 的"十种骨折"、没有髋臼骨折的手术指征、没有前后路选择逻辑**（只有 Smith-Petersen / Hardinge / 后侧的"通用入路"描述）。
6. **成人股骨头缺血性坏死（原文简称 INFH）缺分期体系**。书里只给了零星一段 I～V 期描述（"有症状但无 X 线表现"→"弥漫性空隙、硬化或囊肿"→"外形断裂、出现死骨"→"扁平、间隙变窄、头萎陷"，p.803），**既未标明这是哪家的分期，也没有 ARCO 分期、JIC 分型、也没有"塌陷前/后"的干预分界**；保头手段只有髓蕊减压一种，无截骨、无带血管蒂骨瓣、无钽棒。**注意：全书"椎体成形"零命中，本章也无"腓骨移植"。**
7. **没有直接前入路（DAA）**、没有比基尼切口（bikini）、没有微创后路（MIS-THA）、没有导航/机器人辅助。所有入路都是 20 世纪中期的经典描述。
8. **没有髋关节镜**。既无入路（前外侧、后外侧、中前），也无适应证（FAI、盂唇损伤）——而本章的"关节囊内下侧与后下侧薄弱""股骨头韧带退化残余""哈弗腺"这些内容，恰恰是髋关节镜最需要的基础。
9. **没有骨盆骨折的血流动力学**（骶前静脉丛、腹膜后血肿、填塞、Angioembolization），也没有"骨盆兜/外固定架"的力学。这些都落在 [[骨盆及骶部]] 的缺口里，两处都没有。
10. **先髋缺现代分类与筛查流程**。有 Ortolani/Barlow、有 Putti 三联症、有发育-半脱位-脱位阶段论，但**没有 Graf 超声分型、没有 Tonnis 分级、没有 Pavlik 吊带的适用界限**——而 Graf 恰恰是把本章"髋臼指数""软骨性臼顶"这些概念变成可操作分型的桥梁。
11. **没有骨密度与骨折风险的工具化**。提及 Singh 6 度（p.746），但无 FRAX、无 DXA 部位选择、无"股骨距是否参与骨密度测量"的讨论。

**跨书对读时的落差：**

本章对"应力遮挡"只写到现象（"长柄……由于应力遮挡而产生骨质疏松"，p.800），而基础科学对"应力与骨改建"有完整的细胞学解释（见 [[Wolff 定律与力学适应]]、[[骨塑形与骨改建]]）。**解剖书告诉你"会发生"，基础科学告诉你"为什么会"。**

同样，本章说"软骨需要压力与休息交替才能获得营养"（p.810），但**没有讲机制**——而基础科学第 24 章之外的软骨营养章节（[[软骨的营养途径]]）给出的"关节活动驱动滑液对流"才是这句话的底层。**读本章时如果不接这一段，"压力缺乏比压力过多更伤软骨"就只能死记。**

## 原文摘录

> 「髋关节本身比较稳定，在尸体上即使除去周围肌肉，也不易使股骨头脱位。」（解剖 p.785）

> 「关节囊……远侧在前面止于转子间线，向下达于小转子，后面在**转子间嵴内侧约 1.25 cm**……故**股骨颈前面全部皆在关节囊内，而后面只有内侧 2/3 在关节囊内**。」（解剖 p.786）
